## 快速开始

SGLang 是面向生产级推理服务的框架，
旨在从单张 GPU 到大规模分布式集群的各种场景下，提供低延迟、高吞吐的推理能力。

<CardGroup cols={2}>
<Card title="安装 SGLang" icon="angles-down" href="./docs/get-started/install">
  在你的目标硬件平台上，通过 pip、源码或 Docker 安装 SGLang。
</Card>

<Card title="快速上手" icon="zap" href="./docs/get-started/quickstart">
  用兼容 OpenAI 的 API 在几分钟内启动第一个模型服务并发送请求。
</Card>
</CardGroup>
