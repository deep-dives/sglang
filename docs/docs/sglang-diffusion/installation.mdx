---
title: 安装 SGLang Diffusion
description: 在 NVIDIA、AMD、MUSA 与 Ascend 平台上安装 SGLang Diffusion。
---
你可以通过以下任一方式安装 SGLang-Diffusion。标准安装已经包含 SGLang 的优化内核栈，包括扩散工作负载用到的 `sgl-kernel` 与 JIT kernel。

<Note>
💡 AI Infra 学习笔记：SGLang Diffusion 的"安装"不只是装一个 Python 包——它还捆绑了 `sgl-kernel`（针对扩散模型关键算子预编译的 CUDA 扩展）与 JIT kernel（按需即时编译的内核）。这种"预编译 + JIT"的组合是推理引擎的常见架构：预编译算子保证热路径性能，JIT 内核补足灵活性，代价是安装与启动时多一层编译/调度逻辑。
</Note>

## 标准安装（NVIDIA GPU）

### 方法一：使用 pip 或 uv

推荐使用 uv 安装，速度更快：

```bash Command
pip install --upgrade pip
pip install uv
uv pip install "sglang[diffusion]" --prerelease=allow
```

### 方法二：从源码安装

```bash Command
# Use the latest release branch
git clone https://github.com/sgl-project/sglang.git
cd sglang

# Install the Python packages
pip install --upgrade pip
pip install -e "python[diffusion]"

# With uv
uv pip install -e "python[diffusion]" --prerelease=allow
```

### 方法三：使用 Docker

Docker 镜像发布在 Docker Hub 的 [lmsysorg/sglang](https://hub.docker.com/r/lmsysorg/sglang)，由 [Dockerfile](https://github.com/sgl-project/sglang/blob/main/docker/Dockerfile) 构建。
把下面的 `<secret>` 替换成你的 HuggingFace Hub [token](https://huggingface.co/docs/hub/en/security-tokens)。

```bash Command
docker run --gpus all \
    --shm-size 32g \
    -p 30000:30000 \
    -v ~/.cache/huggingface:/root/.cache/huggingface \
    --env "HF_TOKEN=<secret>" \
    --ipc=host \
    lmsysorg/sglang:dev \
    zsh -c '\
        echo "Installing diffusion dependencies..." && \
        pip install -e "python[diffusion]" && \
        echo "Starting SGLang-Diffusion..." && \
        sglang generate \
            --model-path black-forest-labs/FLUX.1-dev \
            --prompt "A logo With Bold Large text: SGL Diffusion" \
            --save-output \
    '
```

## 平台专用：ROCm（AMD GPU）

对于 AMD Instinct GPU（例如 MI300X），请使用 [lmsysorg/sglang](https://hub.docker.com/r/lmsysorg/sglang) 提供的支持 ROCm 的 Docker 镜像。下面的标签是针对 MI300X 上 ROCm 7.0 的示例，可能滞后于最新发布标签：

```bash Command
docker run --device=/dev/kfd --device=/dev/dri --ipc=host \
  -v ~/.cache/huggingface:/root/.cache/huggingface \
  --env HF_TOKEN=<secret> \
  lmsysorg/sglang:v0.5.5.post2-rocm700-mi30x \
  sglang generate --model-path black-forest-labs/FLUX.1-dev --prompt "A logo With Bold Large text: SGL Diffusion" --save-output
```

关于 ROCm 系统配置与源码安装的详细信息，请参考 [AMD GPU](../hardware-platforms/amd_gpu)。

## 平台专用：MUSA（摩尔线程 GPU）

对于使用 MUSA 软件栈的摩尔线程 GPU（MTGPU），请先按平台指南操作。如果源码树仍需要备用平台的 `pyproject` 回退方案，切换前请先备份默认文件：

```bash Command
# Clone the repository
git clone https://github.com/sgl-project/sglang.git
cd sglang

# Install the Python packages
pip install --upgrade pip
mv python/pyproject.toml python/pyproject.toml.bak
cp python/pyproject_other.toml python/pyproject.toml
pip install -e "python[all_musa]"
```

## 平台专用：Intel XPU

对于 Intel Data Center GPU Max 或 Arc GPU，请先按 [XPU 安装指南](../hardware-platforms/xpu) 搭建基础环境，然后安装扩散模型依赖：

```bash Command
pip install -e "python[diffusion]"
```

## 平台专用：Ascend NPU

对于 Ascend NPU，请按 [NPU 安装指南](../hardware-platforms/ascend-npus/getting-started/installation) 操作。

快速测试：

```bash Command
sglang generate --model-path black-forest-labs/FLUX.1-dev \
    --prompt "A logo With Bold Large text: SGL Diffusion" \
    --save-output
```

## 平台专用：Apple MPS

对于 Apple MPS，请按以下步骤从源码安装。如果源码树仍需要备用平台的 `pyproject` 回退方案，切换前请先备份默认文件：

```bash Command
# Install ffmpeg
brew install ffmpeg

# Install uv
brew install uv

# Clone the repository
git clone https://github.com/sgl-project/sglang.git
cd sglang

# Create and activate a virtual environment
uv venv -p 3.12 sglang-diffusion
source sglang-diffusion/bin/activate

# Install the Python packages
uv pip install --upgrade pip
mv python/pyproject.toml python/pyproject.toml.bak
cp python/pyproject_other.toml python/pyproject.toml
uv pip install -e "python[all_mps]"
```
