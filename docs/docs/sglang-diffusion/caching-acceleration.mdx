SGLang 为扩散 Transformer（DiT）模型提供了三种互补的缓存策略。它们都通过跳过冗余计算来降低去噪成本，但作用在不同层级。

<Note>
💡 AI Infra 学习笔记：这些"缓存加速"和 LLM 的前缀缓存（RadixAttention）思路不同——LLM 缓存的是 KV 状态以复用公共前缀，而扩散模型的缓存是"跳过计算"：既然去噪过程中相邻块/相邻步的输出变化很小，就干脆复用旧结果，省下整块或整步的前向。Cache-DiT 按块跳过、TeaCache/Spectrum 按时间步跳过，粒度不同，速度与质量的取舍也不同。
</Note>

## Cache-DiT

[Cache-DiT](https://github.com/vipshop/cache-dit) 提供块级缓存，带有 DBCache 与 TaylorSeer 等高级策略，最高可实现 **1.69x 加速**。

详细配置见 [Cache-DiT](./cache_dit)。

<Note>
Cache-DiT 目前无法与 `--use-fsdp-inference` 组合使用。启用 Cache-DiT 时请保持 FSDP 关闭，改用其他驻留/卸载控制手段。
</Note>

### 快速上手

```bash
SGLANG_CACHE_DIT_ENABLED=true \
sglang generate --model-path Qwen/Qwen-Image \
    --prompt "A beautiful sunset over the mountains"
```

### 核心特性

- **DBCache**：基于残差差异的动态块级缓存
- **TaylorSeer**：基于泰勒展开的校准，优化缓存决策
- **SCM**：步骤级计算掩码，进一步提升速度

## TeaCache

TeaCache（基于时间相似性的缓存）通过检测连续去噪步骤是否足够相似、从而完全跳过计算，来加速扩散模型推理。

详细文档见 [TeaCache](./teacache)。

### 快速概览

- 跟踪跨时间步的调制输入之间的 L1 距离
- 当累积距离低于阈值时，复用缓存的残差
- 对受支持的 CFG 模型家族使用独立的正/负缓存

### 支持的模型

- Wan2.1
- Z-Image
- Wan2.2：系数尚未标定；启用 TeaCache 会被接受，但目前不起作用
- HunyuanVideo：暂不支持

对于 Flux 与 Qwen 模型，当启用 CFG 时 TeaCache 会自动禁用。

## Spectrum

Spectrum 会预测 DiT 特征，并跳过选定的去噪步骤。它是近似方法，目前仅适用于部分原生实现路径。

支持的模型家族、限制与请求控制见 [Spectrum 加速](./spectrum)。
