SGLang Diffusion 是一个用于图像与视频生成的高性能推理框架。它提供原生的 SGLang 管线、diffusers 后端支持、兼容 OpenAI 的服务端，以及一套基于预编译 `sgl-kernel` 算子与 JIT kernel 构建的优化内核栈，覆盖关键推理路径。

## 核心特性

- 广泛支持 Wan、Hunyuan、Qwen-Image、FLUX、Z-Image、GLM-Image 等模型
- 借助 `sgl-kernel`、JIT kernel、调度器改进与缓存加速，实现快速推理
- 多种接口：`sglang generate`、`sglang serve`，以及兼容 OpenAI 的 API
- 多平台支持：NVIDIA、AMD、Intel XPU、Ascend、Apple Silicon 与摩尔线程

## 快速上手

```bash
uv pip install "sglang[diffusion]" --prerelease=allow
```

```bash
sglang generate --model-path Qwen/Qwen-Image \
  --prompt "A beautiful sunset over the mountains" \
  --save-output
```

```bash
sglang serve --model-path Qwen/Qwen-Image --port 30010
```

<Note>
💡 AI Infra 学习笔记：扩散模型推理与 LLM 推理的工作方式很不一样——LLM 是自回归式逐 token 生成（一次前向只产生一个 token），而扩散模型是迭代式去噪：固定步数内对同一份潜变量反复做全量前向，逐步把噪声"打磨"成图像/视频。因此扩散推理的优化重点是减少单步前向成本（如 Attention 后端、并行、缓存），而不是 KV 缓存或投机解码那一套。这也是评估 SGLang Diffusion 优化手段时的基本坐标系。
</Note>
