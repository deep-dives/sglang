<Note>
💡 AI Infra 学习笔记：多 GPU 训练/推理的集合通信通常走 NCCL，但 NCCL 会引入内核启动、调度和可能绕远的路由开销。CUDA-IPC 是同一主机上 peer 可访问 GPU 之间的直连机制——进程通过 IPC 句柄直接映射对方 GPU 上的显存，在规模很小（TP1 + 两 rank Ulysses）的 all-to-all 场景下比走 NCCL 更低延迟。这也是为什么这类环境变量常常标记"同主机、peer 可访问"条件：跨节点或拓扑不支持时只能回退 NCCL。理解这个取舍，有助于在剖析通信热点时判断瓶颈到底在内核计算还是集合通信。
</Note>
