Spectrum 会预测 DiT 特征，并跳过选定的去噪步骤。它是一种近似方法：请在你要部署的确切模型、形状、硬件与采样配置上验证视觉/视频质量与延迟表现。

## 快速上手

```bash
sglang generate \
  --model-path Wan-AI/Wan2.1-T2V-1.3B-Diffusers \
  --prompt "A paper boat floating through a misty mountain lake" \
  --enable-spectrum \
  --save-output
```

## 适用范围与限制

- 仅适用于原生 FLUX.1、Wan、HunyuanVideo 和 SD3 实现路径。它不是 `--backend diffusers` 的功能，目前也不覆盖 FLUX.2。
- 请求级控制可通过 `sglang generate` 与 Python 采样参数使用。目前还不能作为 `sglang serve` 或 OpenAI 服务端的请求选项。
- Spectrum 与 `--enable-teacache` 互斥。
- 先从默认参数开始。`--debug` 会额外做影子预测校验工作，因此它的延迟不能代表 Spectrum 正常运行时的表现。

<Note>
💡 AI Infra 学习笔记：Spectrum 属于"缓存/预测类"近似加速——它不直接复用上一次的结果，而是用一个轻量预测器（Chebyshev 展开 + 局部泰勒预测器）预判 DiT 特征，从而整步跳过某些去噪步骤。这类方法用"算得少"换"算得快"，代价是输出与全量去噪不完全一致，所以文档强调要在目标配置上做质量验证。
</Note>

## 高级控制

显式使用 `--enable-spectrum`。提供任意 Spectrum 覆盖参数也会隐式启用它，但这种隐式行为是为脚本准备的，新命令里应该显式声明。

| 参数 | 默认值 | 用途 |
| --- | --- | --- |
| `--spectrum-window-size` | `2.0` | 初始的跳步窗口 |
| `--spectrum-flex-window` | `0.75` | 真实前向之后的窗口增长 |
| `--spectrum-warmup-steps` | `5` | 初始精确 DiT 前向次数 |
| `--spectrum-m` | `4` | Chebyshev 基数量 |
| `--spectrum-lam` | `0.1` | 岭正则化 |
| `--spectrum-tau-num-steps` | `50` | Chebyshev 时间范围 |
| `--history-size` | `100` | 近期特征历史容量 |
| `--taylor-order` | `1` | 局部预测器阶数（`1`、`2` 或 `3`） |
| `--w` | `1.0` | Chebyshev/泰勒混合权重 |

<Warning>
这些控制项是在速度与输出保真度之间做权衡。请一次只改一个控制项，并保留一个无损基线用于对比。
</Warning>
