TeaCache（基于时间相似性的缓存）通过检测连续去噪步骤是否足够相似来直接跳过计算，从而加速扩散模型推理。

## 概览

TeaCache 的工作方式：

1. 跟踪连续时间步之间调制输入的 L1 距离
2. 跨步骤累积缩放后的 L1 距离
3. 当累积距离低于阈值时，复用缓存的残差
4. 对受支持的 CFG 模型家族使用独立的正/负缓存

<Note>
💡 AI Infra 学习笔记：TeaCache 属于"时间步级"的缓存——它假设扩散去噪过程中相邻步的输出变化很小（尤其在噪声接近收敛的阶段），于是用输入之间的 L1 距离作为"步间变化量"的廉价代理，变化量小就整步复用上一次的残差，跳过一次完整 DiT 前向。这比 Cache-DiT 的块级跳过更粗粒度，实现更简单，但同样以质量损失换速度。
</Note>

## 工作原理

### L1 距离跟踪

在每个去噪步骤，TeaCache 计算当前与上一次调制输入之间的相对 L1 距离：

```text
rel_l1 = |current - previous|.mean() / |previous|.mean()
```

该距离随后用多项式系数缩放并累积：

```text
accumulated += poly(coefficients)(rel_l1)
```

### 缓存决策

- 如果 `accumulated >= threshold`：强制执行计算，重置累加器
- 如果 `accumulated < threshold`：跳过计算，使用缓存的残差

### CFG 支持

对于支持 CFG 缓存分离的模型，TeaCache 为正负两个分支分别维护缓存：
- 正分支：`previous_modulated_input` / `previous_residual`
- 负分支：`previous_modulated_input_negative` / `previous_residual_negative`

对于不支持 CFG 分离的模型，当启用 CFG 时 TeaCache 会自动禁用。

## 配置

TeaCache 通过采样参数中的 `TeaCacheParams` 配置：

```python
from sglang.multimodal_gen.configs.sample.teacache import TeaCacheParams

params = TeaCacheParams(
    teacache_thresh=0.1,           # Threshold for accumulated L1 distance
    coefficients=[1.0, 0.0, 0.0],  # Polynomial coefficients for L1 rescaling
)
```

### 模型专用配置

不同模型可能有不同的最优配置。系数通常按模型单独调优，以平衡速度与质量。
