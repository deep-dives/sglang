本文档介绍 sglang diffusion（`sglang.multimodal_gen`）中可用的 Attention 后端以及如何选择它们。

## 概览

Attention 后端由 `AttentionBackendEnum`（`sglang.multimodal_gen.runtime.platforms.interface.AttentionBackendEnum`）定义，并通过 CLI 参数 `--attention-backend` 选择。

后端选择由共享的注意力层执行（例如 `sglang.multimodal_gen.runtime.layers.attention.layer` 中的 `LocalAttention` / `USPAttention` / `UlyssesAttention`），因此适用于使用这些层的任何模型组件（例如扩散 transformer / DiT 与编码器）。

使用 diffusers 后端时，`--attention-backend` 会透传给 diffusers 的 `set_attention_backend`（例如 `flash`、`_flash_3_hub`、`sage`、`xformers`、`native`）。

- **CUDA**：支持时优先使用 FlashAttention（FA3/FA4），否则回退到 PyTorch SDPA。在 SM100/B200 上，稠密非因果的 fp16/bf16 原生注意力优先使用 cuDNN SDPA，若 cuDNN 没有兼容 kernel 则回退到 FA4。
- **ROCm**：可用时使用 FlashAttention，否则回退到 PyTorch SDPA。
- **Intel XPU**：使用 XPU Flash Attention 后端（fp16/bf16，头大小 64/96/128/192/256），否则回退到 PyTorch SDPA。
- **MUSA**：可用时使用 FlashAttention；安装后也支持 Sage Attention；否则回退到 PyTorch SDPA。
- **MPS**：始终使用 PyTorch SDPA。
- **NPU**：环注意力使用 FA，其余使用 PyTorch SDPA。

## 后端选项

对于 SGLang 原生管线，CLI 接受 `AttentionBackendEnum` 的小写名称。下表列出内置平台实现的后端。`fa3`/`fa4` 可作为 `fa` 的别名。

<Note>
💡 AI Infra 学习笔记：Attention 后端是扩散推理引擎的核心性能组件——DiT 的注意力计算占去噪步骤的大部分时间，不同后端（FlashAttention、PyTorch SDPA、SageAttention、各类稀疏注意力等）在支持的 GPU 架构、精度与稀疏度上差异很大。选错后端可能带来数倍性能差异，这也是推理引擎性能优化的高频关注点：理解每个后端"用什么 kernel、在什么硬件上快、代价是什么"。
</Note>

## 选择优先级

`runtime/layers/attention/selector.py` 中的选择顺序为：

1. `global_force_attn_backend(...)` / `global_force_attn_backend_context_manager(...)`
2. 构造该组件时，来自 `--component-attention-backends` 的组件级覆盖
3. CLI 参数 `--attention-backend`（`ServerArgs.attention_backend`）
4. 自动选择（平台能力、dtype 与已安装的包）

## 配置

部分后端需要额外配置。你可以通过 `--attention-backend-config` 传入这些参数。该参数接受：
- JSON 或 YAML 配置文件的路径。
- JSON 字符串（例如 `'&#123;"sparsity": 0.5&#125;'`）。
- 键值对（例如 `"sparsity=0.5,enable_x=true"`）。

## 用法

### 通过 CLI 选择后端

```bash
sglang generate \
  --model-path <MODEL_PATH_OR_ID> \
  --prompt "..." \
  --attention-backend fa
```

```bash
sglang generate \
  --model-path <MODEL_PATH_OR_ID> \
  --prompt "..." \
  --attention-backend torch_sdpa
```

### 覆盖单个组件

当某个模块需要与主 transformer 不同的注意力语义时，使用组件级覆盖：

```bash
sglang generate \
  --model-path <MODEL_PATH_OR_ID> \
  --prompt "..." \
  --attention-backend fa \
  --component-attention-backends text_encoder=torch_sdpa
```

组件键与 `model_index.json` 中的管线模块名对应，例如 `text_encoder`、`text_encoder_2`、`transformer`、`transformer_2` 或 `connectors`。

### 使用滑窗块注意力（STA）

```bash
# Pass the mask strategy file path via config
sglang generate \
  --model-path <MODEL_PATH_OR_ID> \
  --prompt "..." \
  --attention-backend sliding_tile_attn \
  --attention-backend-config "mask_strategy_file_path=/abs/path/to/mask_strategy.json"
```

### ROCm / MPS 注意事项

- ROCm：根据环境中可用的后端选择 `--attention-backend torch_sdpa` 或 `fa`。
- MPS：平台实现始终使用 `torch_sdpa`。
