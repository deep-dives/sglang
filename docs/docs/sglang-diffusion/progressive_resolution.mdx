渐进式分辨率放大是部分 SGLang Diffusion 管线的实验性功能。它在更粗糙的潜变量分辨率下运行早期去噪步骤，并在全分辨率步骤之前对潜变量做频谱上采样。在下面的基准测试配置下，它降低了 DiT transformer 的平方级注意力开销，在 **FLUX.1 上最高提速 1.63×**、**FLUX.2 上 1.93×**、**Z-Image 上 2.33×**、**Wan 2.1 T2V 上 2.78×**、**Qwen-Image 上 1.69×**、**Ideogram 4 上 1.56×**。

基于 [Spectral Progressive Diffusion（arXiv 2605.18736）](https://arxiv.org/abs/2605.18736)。

## 概览

DiT 注意力对序列长度的复杂度是 O(n²)。把前 N 个去噪步骤在空间分辨率减半的条件下运行，这些步骤的注意力开销就能降到约 6%。

转换点——每个分辨率各运行多少步——由**贝叶斯最优频率-激活判据**计算得出：在粗尺度下无法分辨的频率，就不会在那里被去噪。该方法设计为在该判据下保持质量，但生成输出仍可能与全分辨率基线存在差异。

| 模型 | 全分辨率 token 数 | 半分辨率 token 数 | token 步数比 |
|-------|----------------|----------------|-----------------|
| FLUX.1 1024×1024 | 4,096 | 1,024 | 4.0× |
| FLUX.2 1024×1024 | 4,096 | 1,024 | 4.0× |
| Z-Image 1024×1024 | 4,096 | 1,024 | 4.0× |
| Wan 2.1 T2V 480×832（81 帧） | 6,240 | 1,560 | 4.0× |
| Ideogram 4 1024×1024 | 4,096 | 1,024 | 4.0× |

<Note>
💡 AI Infra 学习笔记：扩散模型里 DiT 的注意力成本是序列长度的 O(n²)，而空间分辨率减半会让 token 数降到约 1/4，注意力开销自然约降到 1/16（相对该步骤）。渐进式分辨率的核心洞察是：去噪早期主要塑造低频（大尺度）结构，此时高分辨率是浪费——所以先在半分辨率跑前几步，再用频谱上采样把潜变量插值回全尺寸。这是典型的"计算跟着信号复杂度走"的思路，代价是输出与全分辨率基线不完全一致。
</Note>

## 参数

| 参数 | CLI 参数 | 默认值 | 描述 |
|-----------|----------|---------|-------------|
| `progressive_mode` | `--progressive-mode` | `"fullres"` | `"fullres"` 表示禁用（与标准生成一致）。`"dct_rewind"` 启用带调度器回卷的频谱上采样（推荐）。`"dct"` 启用不带回卷的上采样。 |
| `progressive_levels` | `--progressive-levels` | `1` | 分辨率减半的层数。`1` = 一个粗分辨率阶段（64×64 latent → 128×128）。`2` = 两个粗分辨率阶段（32×32 → 64×64 → 128×128）。 |
| `progressive_delta` | `--progressive-delta` | `0.01` | 噪声主导容差 δ。控制粗分辨率运行多少步。δ 越大 = 粗分辨率步数越多 = 加速越多。 |

> **提示：** 添加 `--dit-cpu-offload false` 让 transformer 常驻 GPU。开启 CPU 卸载时，每一步都需支付固定的 PCIe 传输开销，与序列长度无关，这会稀释加速收益。

## FLUX.1

### 用法

```bash
sglang generate \
    --model-path black-forest-labs/FLUX.1-dev \
    --prompt "A serene mountain lake at golden hour, photorealistic" \
    --num-inference-steps 50 \
    --dit-cpu-offload false \
    --progressive-mode dct_rewind \
    --progressive-levels 1 \
    --progressive-delta 0.05
```

### 如何选择 δ

| δ | 粗分辨率步数（共 50 步） | 去噪加速比 |
|---|------------------------|-------------------|
| `0.01` | 18 @ 64² + 32 @ 128² | **1.32×** |
| `0.05` | 28 @ 64² + 22 @ 128² | **1.63×** |

对大多数提示词推荐 `0.05`——它在无可见质量下降的情况下给出最大加速。

### 基准测试

硬件：RTX A6000 48 GB，`--dit-cpu-offload false`。计时 = 仅去噪循环。

| 配置 | 阶段拆分 | 去噪耗时 | 加速比 |
|--------|-------------|---------|---------|
| 全分辨率（基线） | 50 @ 128² latent | 36.65 s | 1.00× |
| dct_rewind L1 δ=0.01 | 18@64² + 32@128² | 27.67 s | **1.32×** |
| dct_rewind L1 δ=0.05 | 28@64² + 22@128² | 22.58 s | **1.62×** |
| dct_rewind L2 δ=0.01 | 10@32² + 8@64² + 32@128² | 26.48 s | **1.38×** |

### Python API

```python
from sglang.multimodal_gen import DiffGenerator

gen = DiffGenerator.from_pretrained(
    model_path="black-forest-labs/FLUX.1-dev",
    dit_cpu_offload=False,
)
result = gen.generate(sampling_params_kwargs={
    "prompt": "A serene mountain lake at golden hour, photorealistic",
    "num_inference_steps": 50,
    "height": 1024,
    "width": 1024,
    "progressive_mode": "dct_rewind",
    "progressive_levels": 1,
    "progressive_delta": 0.05,
})
```

## Wan 2.1 T2V

支持 `Wan-AI/Wan2.1-T2V-1.3B-Diffusers` 与 `Wan-AI/Wan2.1-T2V-14B-Diffusers`。

> **注意：** 渐进式生成只放大**空间** H×W 维度。时间维度 T（潜变量帧数）在所有阶段保持不变。

### 用法

```bash
sglang generate \
    --model-path Wan-AI/Wan2.1-T2V-1.3B-Diffusers \
    --prompt "A cheetah sprinting across the Serengeti at sunset, slow motion, photorealistic" \
    --num-inference-steps 50 \
    --num-frames 81 \
    --height 480 \
    --width 832 \
    --guidance-scale 5.0 \
    --flow-shift 5.0 \
    --dit-cpu-offload false \
    --progressive-mode dct_rewind \
    --progressive-levels 1 \
    --progressive-delta 0.05
```

### 如何选择 δ

| δ | 粗分辨率步数（共 50 步） | 去噪加速比 |
|---|------------------------|-------------------|
| `0.01` | 23 @ 30×52 + 27 @ 60×104 | **1.65×** |
| `0.02` | 27 @ 30×52 + 23 @ 60×104 | **1.86×** |
| `0.05` | 33 @ 30×52 + 17 @ 60×104 | **2.32×** |
| `0.10` | 37 @ 30×52 + 13 @ 60×104 | **2.78×** |

对大多数提示词推荐 `0.05`。`0.10` 提供最大加速，但应在运动剧烈的场景上验证。

### Python API

```python
from sglang.multimodal_gen import DiffGenerator

gen = DiffGenerator.from_pretrained(

    dit_cpu_offload=False,
    flow_shift=5.0,
)
result = gen.generate(sampling_params_kwargs={
    "prompt": "A cheetah sprinting across the Serengeti at sunset, slow motion, photorealistic",
    "num_inference_steps": 50,
    "num_frames": 81,
    "height": 480,
    "width": 832,
    "guidance_scale": 5.0,
    "progressive_mode": "dct_rewind",
    "progressive_levels": 1,
    "progressive_delta": 0.05,
})
```

## Z-Image

支持 `Tongyi-MAI/Z-Image`。Z-Image 与 FLUX.1 使用相同的 VAE（`FluxVAEConfig`），因此幂律谱常量一致。渐进式阶段通过 squeeze/unsqueeze 钩子处理 Z-Image 的 5 维潜变量格式 `[B, C, 1, H, W]`，并在每次阶段转换时重算 caption+image 的 RoPE 位置嵌入。

> **注意：** 请始终指定 `--height 1024 --width 1024`（或其他 H_lat 与 W_lat 都能被 2 整除的分辨率）。Z-Image 的默认分辨率（360×640）会生成 45×80 的潜变量，其中 H=45 不能被 patch size 整除。

### 用法

```bash
# Standard fullres — unchanged behavior
sglang generate --model-path Tongyi-MAI/Z-Image \
    --prompt "A serene mountain lake at golden hour, photorealistic" \
    --height 1024 --width 1024

# Progressive dct_rewind L1 δ=0.10 → 2.33× denoising speedup
sglang generate --model-path Tongyi-MAI/Z-Image \
    --prompt "A serene mountain lake at golden hour, photorealistic" \
    --height 1024 --width 1024 \
    --num-inference-steps 50 \
    --dit-cpu-offload false \
    --progressive-mode dct_rewind \
    --progressive-levels 1 \
    --progressive-delta 0.10
```

### 如何选择 δ

| δ | 粗分辨率步数（共 50 步） | 去噪加速比 |
|---|------------------------|-------------------|
| `0.01` | 26 @ 64² + 24 @ 128² | **1.53×** |
| `0.05` | 35 @ 64² + 15 @ 128² | **2.03×** |
| `0.10` | 42 @ 64² + 8 @ 128² | **2.33×** |

Z-Image 在相同 δ 下比 FLUX.1 取得更高的渐进式加速，因为它使用双 CFG（每步两次前向），在粗分辨率下把绝对注意力节省翻倍。`0.10` 是推荐的权衡点。

### Python API

```python
from sglang.multimodal_gen import DiffGenerator

gen = DiffGenerator.from_pretrained(
    model_path="Tongyi-MAI/Z-Image",
    dit_cpu_offload=False,
)
result = gen.generate(sampling_params_kwargs={
    "prompt": "A serene mountain lake at golden hour, photorealistic",
    "num_inference_steps": 50,
    "height": 1024,
    "width": 1024,
    "progressive_mode": "dct_rewind",
    "progressive_levels": 1,
    "progressive_delta": 0.10,
})
```

## Qwen-Image

Qwen-Image 与 FLUX.1 使用相同的 2×2 patchify 约定（in_channels=64，C=16），因此相同的渐进式阶段通过模型专属钩子接入 RoPE（`freqs_cis`）与空间元数据（`img_shapes`）。

```bash
# Standard fullres — unchanged behavior
sglang generate --model-path Qwen/Qwen-Image \
    --prompt "A serene mountain lake at golden hour"

# Progressive dct_rewind L1 δ=0.20 → 1.69× denoising speedup
sglang generate --model-path Qwen/Qwen-Image \
    --prompt "A serene mountain lake at golden hour" \
    --progressive-mode dct_rewind --progressive-levels 1 --progressive-delta 0.20 \
    --num-inference-steps 30 --dit-cpu-offload false
```

硬件：RTX A6000 48 GB，`--dit-cpu-offload false`。计时 = 仅去噪循环。

| 配置 | 阶段拆分 | 去噪耗时 | 加速比 |
|--------|-------------|---------|---------|
| 全分辨率（基线） | 30 @ 128² | 43.00 s | 1.00× |
| dct_rewind L1 δ=0.05 | 13@64² + 17@128² | 33.25 s | **1.29×** |
| dct_rewind L1 δ=0.10 | 16@64² + 14@128² | 33.86 s | **1.27×** |
| dct_rewind L1 δ=0.20 | 19@64² + 11@128² | 25.40 s | **1.69×** |

## Ideogram 4

支持 `ideogram-ai/ideogram-4`。Ideogram 4 使用**双 transformer 架构**：一个条件 transformer（文本 + 图像 token）与一个独立权重的无条件 transformer（仅图像 token，LLM 特征为零）。两个 transformer 在粗分辨率下都会缩小，提供与单 transformer 模型相同的 token 比收益。

> **注意：** Ideogram 4 的 logit-normal 噪声调度（`std=1.75`，`mu=0`）把步骤集中在中间 sigma 区间。相比 FLUX，落在高 sigma 的粗分辨率可用区间的步骤更少，这限制了给定 δ 下可达到的加速比。

### 用法

**20 步（V4_DEFAULT_20 预设）**

```bash
sglang generate \
    --model-path ideogram-ai/ideogram-4 \
    --prompt "A serene mountain lake at golden hour, photorealistic" \
    --height 1024 --width 1024 \
    --num-inference-steps 20 \
    --dit-cpu-offload false \
    --progressive-mode dct_rewind \
    --progressive-levels 1 \
    --progressive-delta 0.05
```

**48 步（V4_QUALITY_48 预设）**

```bash
sglang generate \
    --model-path ideogram-ai/ideogram-4 \
    --prompt "A serene mountain lake at golden hour, photorealistic" \
    --height 1024 --width 1024 \
    --num-inference-steps 48 \
    --dit-cpu-offload false \
    --progressive-mode dct_rewind \
    --progressive-levels 1 \
    --progressive-delta 0.05
```

## 限制

- **与序列并行不兼容。** 不能与 `--ulysses-degree` 或 `--ring-degree` 组合。启用 SP 时该阶段会抛出 `RuntimeError`。
- **与 torch.compile 不兼容。** 编译后的 kernel 序列长度固定；分辨率转换会导致重新编译或报错。请在不加 `--enable-torch-compile` 的情况下使用渐进式。
- **与 Cache-DiT 的交互属于实验性质。** 该阶段在分辨率转换时会刷新 Cache-DiT 上下文，但在依赖该组合之前，应先基准测试质量与加速效果。
