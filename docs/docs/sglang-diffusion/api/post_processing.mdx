    description: "使用 SGLang Diffusion 后处理在生成之后进行帧插值和空间超分辨率。"
---

SGLang 扩散模型支持可选的生成后处理步骤，用于改善时间平滑度（帧插值）或空间分辨率（超分辨率）。这些步骤与扩散模型相互独立，可以在一次运行中组合使用。

两者都启用时，**先做帧插值**（增加帧数），然后**对每一帧做超分辨率**（提升空间分辨率）。

<Note>
💡 AI Infra 学习笔记：把帧插值（RIFE）和超分辨率（Real-ESRGAN）设计成与扩散模型解耦的后处理步骤，是个很划算的取舍——它们不依赖具体模型，也不需要重新跑昂贵的 DiT 去噪循环。插值利用的是视频帧间的时间冗余（相邻帧差异小，用光流估计中间帧），超分辨率用轻量网络放大空间分辨率。代价是要额外加载/推理这些网络，而且任何后处理都可能引入伪影，所以默认关闭、按需开启。这与推理引擎里"生成 vs 后处理分离、可独立开关"的服务化设计思路一致。
</Note>

## 帧插值（仅视频）

帧插值在每对相邻生成帧之间合成新帧，在不重新运行扩散模型的前提下产生更平滑的运动。

`--frame-interpolation-exp` 参数控制应用几轮插值：每轮都会在相邻帧的每个空隙里插入一个新帧，因此输出帧数遵循公式：

> **(N − 1) × 2^exp + 1**
>
> 例如 5 个原始帧搭配 `exp=1` → 4 个空隙 × 1 个新帧 + 5 个原始帧 = **9** 帧；
> 搭配 `exp=2` → **17** 帧。

### 受支持的模型

帧插值使用 [RIFE](https://github.com/hzwer/Practical-RIFE)（Real-Time Intermediate Flow Estimation，实时中间光流估计）架构。只支持 **RIFE 4.22.lite**（使用 4 尺度 `IFBlock` 骨干的 `IFNet`）。网络拓扑是硬编码的，所以通过 `--frame-interpolation-model-path` 提供的自定义权重，必须是与该架构兼容的 `flownet.pkl` 检查点。

其它 RIFE 版本（例如块数不同的旧 `v4.x` 变体）或完全不同的帧插值方法（FILM、AMT 等）**不受支持**。

### 示例

生成 5 帧视频并插值到 9 帧（(5 − 1) × 2¹ + 1 = 9）：

```bash
sglang generate \
  --model-path Wan-AI/Wan2.2-T2V-A14B-Diffusers \
  --prompt "A dog running through a park" \
  --num-frames 5 \
  --enable-frame-interpolation \
  --frame-interpolation-exp 1 \
  --save-output
```

## 超分辨率（图像和视频）

超分辨率使用 [Real-ESRGAN](https://github.com/xinntao/Real-ESRGAN) 提升生成图像或视频帧的空间分辨率。模型权重会在首次使用时自动下载，并在后续运行中缓存。

默认权重文件是
[`ai-forever/Real-ESRGAN`](https://huggingface.co/ai-forever/Real-ESRGAN) 的
`RealESRGAN_x4.pth`（SRVGGNetCompact，原生 4 倍缩放）。

其它超分模型（例如 SwinIR、HAT、BSRGAN）**不受支持**——只有使用上面两种架构的 Real-ESRGAN 检查点才兼容。

### 示例

生成 1024×1024 图像并超分到 4096×4096：

```bash
sglang generate \
  --model-path black-forest-labs/FLUX.2-dev \
  --prompt "A cat sitting on a windowsill" \
  --output-size 1024x1024 \
  --enable-upscaling \
  --save-output
```

生成视频并对每一帧做 4 倍超分：

```bash
sglang generate \
  --model-path Wan-AI/Wan2.1-T2V-1.3B-Diffusers \
  --prompt "A curious raccoon" \
  --enable-upscaling \
  --upscaling-scale 4 \
  --save-output
```

## 组合帧插值与超分辨率

帧插值和超分辨率可以在一次运行中组合。先应用插值（增加帧数），再对每一帧应用超分辨率（提升空间分辨率）。

示例——生成 5 帧、插值到 9 帧、每帧 4 倍超分：

```bash
sglang generate \
  --model-path Wan-AI/Wan2.1-T2V-1.3B-Diffusers \
  --prompt "A curious raccoon" \
  --num-frames 5 \
  --enable-frame-interpolation \
  --frame-interpolation-exp 1 \
  --enable-upscaling \
  --upscaling-scale 4 \
  --save-output
```
