<Note>
💡 AI Infra 学习笔记：HiCache 是 SGLang 的分层 KV 缓存方案——KV 缓存不只放在 GPU 显存里，还能扩展到 CPU 内存和外部存储，形成 GPU → CPU → 存储三级层次。长上下文或多轮对话场景下 KV 缓存会非常巨大，放不下的部分可以"溢出"到速度较慢但容量大、成本低的存储，这是突破单卡显存限制、降低长上下文推理成本的关键思路。
</Note>
