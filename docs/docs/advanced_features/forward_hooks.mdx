## 模型钩子

SGLang 支持给已加载模型中的特定子模块挂载 PyTorch 前向钩子，完全通过 `server_args` 的 JSON 配置实现。

它的用途包括：

* 记录中间激活值
* 调试模型内部
* 把隐藏状态导出到外部工具

钩子在 `ModelRunner.initialize` 时挂载一次，之后的每次前向传播都会执行。

<Note>
💡 AI Infra 学习笔记：前向钩子（forward hook）是 PyTorch 提供的"观察/拦截"机制——在某个子模块的前向计算结束后自动调用你注册的回调，参数是 `(module, inputs, output)`，你可以记录中间张量的 shape/数值，甚至替换输出。对推理引擎来说，这是"零侵入观测模型内部"的重要手段：不需要改模型代码，就能拿到每一层/每个子模块的激活值、hidden state，用于调试、诊断、或对接外部可解释性工具。理解它能帮你回答"推理引擎里如何观测中间结果"这类工程问题。
</Note>

***
### 配置概览

钩子通过一个 `ServerArgs` 字段配置：

```python Example
class ServerArgs:
    ...
    # For forward hooks
    forward_hooks: Optional[List[dict[str, Any]]] = None
````

用 JSON 表示时，一个最小配置长这样：

```jsonc Example
{
  "forward_hooks": [
    {
      "name": "outer_linear_hooks",
      "target_modules": ["outer.0", "outer.1"],
      "hook_factory": "my_project.hooks:dummy_hook_factory",
      "config": {
        "tag": "outer-layer"
      }
    }
  ]
}
```

#### 顶层字段

* `forward_hooks`（可选的对象列表）
  每个元素是一个钩子描述，说明：

  * 要挂到哪些模块上
  * 要调用哪个 Python 工厂函数
  * 给该工厂函数传什么配置

***
### 钩子描述 schema

`forward_hooks` 里的每一项都是一个 JSON 对象，形状如下：

```jsonc Example
{
  "name": "optional-descriptive-name",
  "target_modules": ["pattern1", "pattern2", "..."],
  "hook_factory": "module.submodule:factory_name",
  "config": {
    "...": "arbitrary JSON"
  }
}
```

#### `name`（可选）

* 用于日志的可读名称。
* 只出现在日志消息里，例如：

  ```text Output
  Registered forward hook 'outer_linear_hooks' on outer.0
  ```

#### `target_modules`（必填）

* 一组**模块名模式**，用来匹配 `model.named_modules()` 里的条目。
* 模式用 `fnmatch.fnmatch` 匹配，所以：

  * `"outer.0"` 精确匹配 `"outer.0"`。
  * `"outer.*"` 匹配 `"outer.0"`、`"outer.1"`、`"outer.inner"` 等。
  * `"outer.inner.*"` 匹配 `outer.inner` 下的子模块。

> 如果没有模块匹配给定模式，钩子注册**不会失败**。
> 而是记录一条警告并继续：
>
> ```text
> No modules matched hook spec 'name' patterns=['...']
> ```

#### `hook_factory`（必填）

* 指向创建钩子的 Python 工厂函数的字符串路径。
* 支持的格式：

  * `"package.module:factory_name"`
  * `"package.module.submodule.factory_name"`

路径通过以下方式解析：

```python Example
def resolve_callable(path: Optional[str]) -> Optional[Callable]:
    if path is None:
        return None

    if ":" in path:
        module_name, fn_name = path.split(":", 1)
    else:
        parts = path.split(".")
        if len(parts) < 2:
            raise ValueError(
                f"Invalid hook callable path '{path}'. "
                "Expected 'module.submodule:factory' or 'module.submodule.factory'."
            )
        *mod_parts, fn_name = parts
        module_name = ".".join(mod_parts)

    module = importlib.import_module(module_name)
    try:
        return getattr(module, fn_name)
    except AttributeError as e:
        raise AttributeError(
            f"Module '{module_name}' has no attribute '{fn_name}' "
            f"(from hook path '{path}')"
        ) from e
```

**失败模式**：

* 路径格式错误（点不够且没有 `:`），启动时会抛出 `ValueError`。
* 模块能导入但属性不存在，会抛出带清晰错误信息的 `AttributeError`。
* 钩子工厂返回 `None`，会记录一条警告，并且该描述不注册钩子（初始化继续）。

前两种情况会让初始化带明确的错误信息快速失败；最后一种不致命。

#### `config`（可选）

* 任意 JSON 对象。
* 作为 Python `dict` 直接传给钩子工厂。
* 这让你能从配置里参数化钩子的行为（例如标签、日志级别、采样率等）。

### 钩子的生命周期与行为

钩子在 `ModelRunner.initialize()` 里注册：

```python Example
if server_args.forward_hooks:
    register_forward_hooks(self.model, server_args.forward_hooks)
```

实际注册逻辑由 `register_forward_hooks` 实现：

```python Example
def register_forward_hooks(model: nn.Module, hook_specs: List[dict[str, Any]]) -> None:
    """
    hook_specs is a list of dicts from server_args.forward_hooks.
    Attaches forward hooks to the matching modules.
    """
    name_to_module = dict(model.named_modules())

    for spec in hook_specs:
        spec_name = spec.get("name", "")
        target_patterns = spec.get("target_modules", [])
        if not target_patterns:
            logger.warning(
                f"Hook spec '{spec_name}' has no 'target_modules', skipping"
            )
            continue

        hook_factory_path = spec.get("hook_factory")
        if not hook_factory_path:
            logger.warning(
                f"Hook spec '{spec_name}' has no 'hook_factory', skipping"
            )
            continue

        config = spec.get("config") or {}
        hook_factory = resolve_callable(hook_factory_path)

        hook = hook_factory(config) if hook_factory else None
        if hook is None:
            logger.warning(
                f"Hook factory '{hook_factory_path}' for spec '{spec_name}' "
                "returned None, not registering any hook"
            )
            continue

        # Resolve patterns like "model.layers.*.mlp"
        matched = []
        for name, module in name_to_module.items():
            if any(fnmatch.fnmatch(name, pattern) for pattern in target_patterns):
                matched.append((name, module))

        if not matched:
            logger.warning(
                f"No modules matched hook spec '{spec_name}' "
                f"patterns={target_patterns}"
            )
            continue

        for module_name, module in matched:
            if hook:
                _ = module.register_forward_hook(hook)
                logger.info(
                    f"Registered forward hook '{spec_name}' "
                    f"on {module_name}"
                )
```

关键点：

* 钩子**只支持前向钩子**（通过 `module.register_forward_hook`）。
* 初始化时挂载一次。
* 钩子句柄目前不存储在 `ModelRunner` 上（之后无法通过这个 API 移除）。
* 没有匹配到任何模块不致命；只记录一条警告。
* 钩子工厂返回 `None` 时记录警告，并跳过该描述。

### 编写钩子工厂

钩子工厂是一个普通的 Python 函数：

* 接收 `config: dict`（来自 JSON）
* 返回一个签名为 `(module, inputs, output)` 的前向钩子函数

示例：

```python Example
HOOK_CALLS = []

def dummy_hook_factory(config):
    """Factory that returns a forward hook capturing a tag from config."""
    tag = config.get("tag", "default")

    def hook(module, inputs, output):
        HOOK_CALLS.append(
            {
                "module_type": type(module).__name__,
                "tag": tag,
                "shape": tuple(output.shape),
            }
        )
        return output  # must return output if you don’t want to modify the tensor

    return hook
```

在 JSON 中：

```jsonc Example
{
  "forward_hooks": [
    {
      "name": "capture_outer",
      "target_modules": ["outer.0", "outer.1"],
      "hook_factory": "my_project.hooks:dummy_hook_factory",
      "config": {
        "tag": "outer"
      }
    }
  ]
}
```

这会：

* 把 `my_project.hooks:dummy_hook_factory` 解析成一个 Python 可调用对象。
* 用 `config = {"tag": "outer"}` 调用它。
* 把返回的钩子用到所有匹配 `outer.0` 和 `outer.1` 的模块上。
* 把每次调用的元数据追加到 `HOOK_CALLS`。

***
### 总结

* 在 `ServerArgs` 里把 `forward_hooks` 定义成描述列表即可开启该特性。

* 每个描述：

  * 通过 `target_modules`（对 `model.named_modules()` 的 glob 模式）选择模块，
  * 通过 `hook_factory` 指向一个钩子工厂，
  * 把任意 `config` 传进该工厂。

* 钩子工厂通过 `resolve_callable` 解析，支持 `module:factory` 和 `module.submodule.factory` 两种格式。

* 钩子是标准的 PyTorch 前向钩子，启动时挂载一次，之后每次前向传播都会执行。

* 配置错误要么是：

  * **致命且明确的**（路径错误 / 属性缺失），要么是
  * **非致命但有清晰警告的**（没有目标匹配，或工厂返回 `None`）。
