SGLang 支持为 [DeepSeek R1](https://huggingface.co/deepseek-ai/DeepSeek-R1) 这类推理模型，把"思维"（reasoning）内容从"正常"内容中解析出来。

<Note>
💡 AI Infra 学习笔记：推理模型（reasoning model）在给出最终答案前会先生成一段"思维链"（chain-of-thought），通常用特殊标签包起来（如 `<think>...</think>`），这段内容对用户其实没有直接价值，只占 token 和费用。推理解析器的职责就是识别这些标签，把思维内容和正式答案分到两个字段（`reasoning_content` 和 `content`），让客户端可以只展示答案、隐藏思维过程。对服务方来说，这段思维往往占生成 token 的一半以上，理解"如何解析"直接关系到 API 设计（参照 DeepSeek 的 `separate_reasoning` 约定）和 token 计费口径。
</Note>

### 各模型的具体行为

**Apertus 2509：**
- 用 `<|inner_prefix|>` 和 `<|inner_suffix|>` 定界思维内容。用于 agent 式工具调用时，还要指定 `--tool-call-parser apertus2509`。

**DeepSeek-R1 家族：**
- DeepSeek-R1：没有 `<think>` 开始标签，直接跳到思维内容
- DeepSeek-R1-0528：会生成 `<think>` 开始和 `</think>` 结束两个标签
- 两者都由同一个 `deepseek-r1` 解析器处理

**DeepSeek-V3 家族：**
- DeepSeek-V3.1/V3.2：混合模型，同时支持思考和不思考两种模式，用 `deepseek-v3` 解析器和 `thinking` 参数（注意：不是 `enable_thinking`）

**Qwen3 家族：**
- 标准 Qwen3（如 Qwen3-2507）：用 `qwen3` 解析器，对话模板里支持 `enable_thinking`
- Qwen3-Thinking（如 Qwen3-235B-A22B-Thinking-2507）：用 `qwen3` 或 `qwen3-thinking` 解析器，总是思考

**Kimi K2：**
- Kimi K2 Thinking：使用特殊的 `◁think▷` 和 `◁/think▷` 标签。用于 agent 式工具调用时，还要指定 `--tool-call-parser kimi_k2`。

**GPT OSS：**
- GPT OSS：使用特殊的 `<|channel|>analysis<|message|>` 和 `<|end|>` 标签


## 使用方法

### 启动服务端


指定 `--reasoning-parser` 选项。



```python Example
import requests
from openai import OpenAI
from sglang.test.doc_patch import launch_server_cmd
from sglang.utils import wait_for_server, print_highlight, terminate_process

server_process, port = launch_server_cmd(
    "python3 -m sglang.launch_server --model-path deepseek-ai/DeepSeek-R1-Distill-Qwen-7B --host 0.0.0.0 --reasoning-parser deepseek-r1 --log-level warning"
)

wait_for_server(f"http://localhost:{port}")
```

注意，`--reasoning-parser` 定义了用来解释响应的解析器。


### OpenAI 兼容 API

使用 OpenAI 兼容 API 时，契约遵循随 DeepSeek-R1 发布确立的 [DeepSeek API 设计](https://api-docs.deepseek.com/guides/reasoning_model)：

- `reasoning_content`：思维链（CoT）的内容。
- `content`：最终答案的内容。



```python Example
# Initialize OpenAI-like client
client = OpenAI(api_key="None", base_url=f"http://0.0.0.0:{port}/v1")
model_name = client.models.list().data[0].id

messages = [
    {
        "role": "user",
        "content": "What is 1+3?",
    }
]
```

#### 非流式请求



```python Example
response_non_stream = client.chat.completions.create(
    model=model_name,
    messages=messages,
    temperature=0.6,
    top_p=0.95,
    stream=False,  # Non-streaming
    extra_body={"separate_reasoning": True},
)
print_highlight("==== Reasoning ====")
print_highlight(response_non_stream.choices[0].message.reasoning_content)

print_highlight("==== Text ====")
print_highlight(response_non_stream.choices[0].message.content)
```

#### 流式请求



```python Example
response_stream = client.chat.completions.create(
    model=model_name,
    messages=messages,
    temperature=0.6,
    top_p=0.95,
    stream=True,  # Non-streaming
    extra_body={"separate_reasoning": True},
)

reasoning_content = ""
content = ""
for chunk in response_stream:
    if chunk.choices[0].delta.content:
        content += chunk.choices[0].delta.content
    if chunk.choices[0].delta.reasoning_content:
        reasoning_content += chunk.choices[0].delta.reasoning_content

print_highlight("==== Reasoning ====")
print_highlight(reasoning_content)

print_highlight("==== Text ====")
print_highlight(content)
```

可选地，你可以把思维内容缓冲到最后一个思维 chunk（或思维内容之后的第一个 chunk）。



```python Example
response_stream = client.chat.completions.create(
    model=model_name,
    messages=messages,
    temperature=0.6,
    top_p=0.95,
    stream=True,  # Non-streaming
    extra_body={"separate_reasoning": True, "stream_reasoning": False},
)

reasoning_content = ""
content = ""
for chunk in response_stream:
    if chunk.choices[0].delta.content:
        content += chunk.choices[0].delta.content
    if chunk.choices[0].delta.reasoning_content:
        reasoning_content += chunk.choices[0].delta.reasoning_content

print_highlight("==== Reasoning ====")
print_highlight(reasoning_content)

print_highlight("==== Text ====")
print_highlight(content)
```

指定 `--reasoning-parser` 后，推理分离默认启用。
**要禁用它，在请求中把 `separate_reasoning` 选项设为 `False`。**



```python Example
response_non_stream = client.chat.completions.create(
    model=model_name,
    messages=messages,
    temperature=0.6,
    top_p=0.95,
    stream=False,  # Non-streaming
    extra_body={"separate_reasoning": False},
)

print_highlight("==== Original Output ====")
print_highlight(response_non_stream.choices[0].message.content)
```

### SGLang 原生 API



```python Example
from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("deepseek-ai/DeepSeek-R1-Distill-Qwen-7B")
input = tokenizer.apply_chat_template(
    messages, tokenize=False, add_generation_prompt=True, return_dict=False
)

gen_url = f"http://localhost:{port}/generate"
gen_data = {
    "text": input,
    "sampling_params": {
        "skip_special_tokens": False,
        "max_new_tokens": 1024,
        "temperature": 0.6,
        "top_p": 0.95,
    },
}
gen_response = requests.post(gen_url, json=gen_data).json()["text"]

print_highlight("==== Original Output ====")
print_highlight(gen_response)

parse_url = f"http://localhost:{port}/separate_reasoning"
separate_reasoning_data = {
    "text": gen_response,
    "reasoning_parser": "deepseek-r1",
}
separate_reasoning_response_json = requests.post(
    parse_url, json=separate_reasoning_data
).json()
print_highlight("==== Reasoning ====")
print_highlight(separate_reasoning_response_json["reasoning_text"])
print_highlight("==== Text ====")
print_highlight(separate_reasoning_response_json["text"])
```

### 离线引擎 API



```python Example
import sglang as sgl
from sglang.srt.parser.reasoning_parser import ReasoningParser
from sglang.utils import print_highlight

llm = sgl.Engine(model_path="deepseek-ai/DeepSeek-R1-Distill-Qwen-7B")
tokenizer = AutoTokenizer.from_pretrained("deepseek-ai/DeepSeek-R1-Distill-Qwen-7B")
input = tokenizer.apply_chat_template(
    messages, tokenize=False, add_generation_prompt=True, return_dict=False
)
sampling_params = {
    "max_new_tokens": 1024,
    "skip_special_tokens": False,
    "temperature": 0.6,
    "top_p": 0.95,
}
result = llm.generate(prompt=input, sampling_params=sampling_params)

generated_text = result["text"]  # Assume there is only one prompt

print_highlight("==== Original Output ====")
print_highlight(generated_text)

parser = ReasoningParser("deepseek-r1")
reasoning_text, text = parser.parse_non_stream(generated_text)
print_highlight("==== Reasoning ====")
print_highlight(reasoning_text)
print_highlight("==== Text ====")
print_highlight(text)
```


```python Example
llm.shutdown()
```

<Note>
💡 AI Infra 学习笔记：推理解析器本质是个"流式状态机"——生成过程中逐个 token 地识别开始/结束标签，把 token 流切成"思维段"和"答案段"，然后在 API 层分流到 `reasoning_content` 和 `content` 两个字段。这要求解析器按模型而定（不同模型的标签不同，有的甚至没有开始标签、上来就是思维内容），所以 SGLang 把它做成可插拔的 parser。对新推理模型做接入时，只需要继承 `BaseReasoningFormatDetector` 实现一个解析器，这是推理引擎生态里常见的"适配层"设计模式。
</Note>

## 支持新的推理模型格式

对于未来的推理模型，你可以在 `python/sglang/srt/reasoning_parser.py` 中实现一个 `BaseReasoningFormatDetector` 的子类作为推理解析器，并据此为新推理模型格式指定对应的推理解析器。
