## 概览

本指南带你走完 SGLang 的完整上手流程：

1. **安装** SGLang
2. **启动**一个推理服务
3. 使用 cURL、OpenAI Python 客户端、Python `requests` 或原生 SGLang API **发送请求**

学完本指南，你就有一个能响应你的提示词的 SGLang 服务在运行了。

---

## 前置条件

- **Python**：3.10 及以上
- **GPU**：支持 CUDA 的 NVIDIA GPU（sm80 及以上，例如 A10、A100、L4、L40S、H100）
- **操作系统**：Linux（推荐）

<Note>
其他平台请参考专门指南：[AMD GPU](../hardware-platforms/amd_gpu)、[Intel Xeon CPU](../hardware-platforms/cpu_server)、[Google TPU](../hardware-platforms/tpu)、[NVIDIA Jetson](../hardware-platforms/nvidia_jetson)、[Ascend NPU](../hardware-platforms/ascend-npus/getting-started/installation) 和 [Intel XPU](../hardware-platforms/xpu)。
</Note>

## 安装

<Tabs>
  <Tab title="Pip / uv（推荐）">
    推荐使用 **uv** 安装，速度更快：

```bash
pip install --upgrade pip
pip install uv
uv pip install --prerelease=allow sglang
```
  </Tab>
  <Tab title="从源码安装">
```bash
# 克隆并从源码安装
git clone https://github.com/sgl-project/sglang.git
cd sglang
pip install --upgrade pip
pip install -e "python"
```
  </Tab>
  <Tab title="Docker">
    Docker 镜像发布在 Docker Hub 的 [lmsysorg/sglang](https://hub.docker.com/r/lmsysorg/sglang/tags)。

    把 `<secret>` 替换成你的 [Hugging Face token](https://huggingface.co/docs/hub/en/security-tokens)：

    ```bash
    docker run --gpus all \
        --shm-size 32g \
        -p 30000:30000 \
        -v ~/.cache/huggingface:/root/.cache/huggingface \
        --env "HF_TOKEN=<secret>" \
        --ipc=host \
        lmsysorg/sglang:latest \
        python3 -m sglang.launch_server --model-path meta-llama/Llama-3.1-8B-Instruct --host 0.0.0.0 --port 30000
    ```

    生产部署建议使用更小的 **runtime** 变体（体积约减小 40%）：

    ```bash
    docker run --gpus all \
        --shm-size 32g \
        -p 30000:30000 \
        -v ~/.cache/huggingface:/root/.cache/huggingface \
        --env "HF_TOKEN=<secret>" \
        --ipc=host \
        lmsysorg/sglang:latest-runtime \
        python3 -m sglang.launch_server --model-path meta-llama/Llama-3.1-8B-Instruct --host 0.0.0.0 --port 30000
    ```
  </Tab>
</Tabs>

<Tip>
如果遇到 `OSError: CUDA_HOME environment variable is not set`，用以下命令设置它：
```bash
export CUDA_HOME=/usr/local/cuda-<your-cuda-version>
```
</Tip>

## 启动服务端

用一个模型启动 SGLang 服务端。这里我们用 `qwen/qwen2.5-0.5b-instruct` 作为轻量示例：

```bash
python3 -m sglang.launch_server --model-path qwen/qwen2.5-0.5b-instruct --host 0.0.0.0 --port 30000
```

等到终端输出中出现 `The server is fired up and ready to roll!` 再继续。

<Note>
服务运行起来后，API 文档可以在以下地址查看：
- **Swagger UI**：`http://localhost:30000/docs`
- **ReDoc**：`http://localhost:30000/redoc`
- **OpenAPI 规范**：`http://localhost:30000/openapi.json`
</Note>

<Info>
服务端会自动套用 Hugging Face 分词器中的对话模板。你也可以在启动时用 `--chat-template` 覆盖它。
</Info>

## 发送请求

SGLang 完全**兼容 OpenAI API**，所以你可以直接使用已经熟悉的工具和库。

### 使用 cURL

```bash
curl http://localhost:30000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen/qwen2.5-0.5b-instruct",
    "messages": [
      {"role": "user", "content": "What is the capital of France?"}
    ]
  }'
```

### 使用 OpenAI Python 客户端

如果还没安装，先安装 OpenAI Python 库：

```bash
pip install openai
```

然后发送请求：

```python Example
import openai

client = openai.Client(base_url="http://127.0.0.1:30000/v1", api_key="None")

response = client.chat.completions.create(
    model="qwen/qwen2.5-0.5b-instruct",
    messages=[
        {"role": "user", "content": "List 3 countries and their capitals."},
    ],
    temperature=0,
    max_tokens=64,
)

print(response.choices[0].message.content)
```

#### 流式输出

```python Example
import openai

client = openai.Client(base_url="http://127.0.0.1:30000/v1", api_key="None")

response = client.chat.completions.create(
    model="qwen/qwen2.5-0.5b-instruct",
    messages=[
        {"role": "user", "content": "List 3 countries and their capitals."},
    ],
    temperature=0,
    max_tokens=64,
    stream=True,
)

for chunk in response:
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
```

### 使用 Python requests

```python Example
import requests

url = "http://localhost:30000/v1/chat/completions"

data = {
    "model": "qwen/qwen2.5-0.5b-instruct",
    "messages": [{"role": "user", "content": "What is the capital of France?"}],
}

response = requests.post(url, json=data)
print(response.json())
```

### 使用原生 `/generate` API

SGLang 还提供更灵活的原生 `/generate` 端点。

```python Example
import requests

response = requests.post(
    "http://localhost:30000/generate",
    json={
        "text": "The capital of France is",
        "sampling_params": {
            "temperature": 0,
            "max_new_tokens": 32,
        },
    },
)

print(response.json())
```

#### `/generate` 的流式输出

```python Example
import requests
import json

response = requests.post(
    "http://localhost:30000/generate",
    json={
        "text": "The capital of France is",
        "sampling_params": {
            "temperature": 0,
            "max_new_tokens": 32,
        },
        "stream": True,
    },
    stream=True,
)

prev = 0
for chunk in response.iter_lines(decode_unicode=False):
    chunk = chunk.decode("utf-8")
    if chunk and chunk.startswith("data:"):
        if chunk == "data: [DONE]":
            break
        data = json.loads(chunk[5:].strip("\n"))
        output = data["text"]
        print(output[prev:], end="", flush=True)
        prev = len(output)
```

## 离线批量推理（不启动服务端）

SGLang 也支持直接用 `Engine` 类做离线批量推理——不需要 HTTP 服务端。

```python Example
import sglang as sgl

llm = sgl.Engine(model_path="qwen/qwen2.5-0.5b-instruct")

prompts = [
    "Hello, my name is",
    "The president of the United States is",
    "The capital of France is",
    "The future of AI is",
]

sampling_params = {"temperature": 0.8, "top_p": 0.95}

outputs = llm.generate(prompts, sampling_params)

for prompt, output in zip(prompts, outputs):
    print(f"Prompt: {prompt}\nGenerated text: {output['text']}\n")

llm.shutdown()
```

## 常见问题排查

<AccordionGroup>
  <Accordion title="未设置 CUDA_HOME">
    把 `CUDA_HOME` 环境变量设置为你的 CUDA 安装根目录：
    ```bash
    export CUDA_HOME=/usr/local/cuda-<your-cuda-version>
    ```
  </Accordion>
  <Accordion title="sm75+ 设备上的 FlashInfer 问题">
    启动服务端时添加以下参数切换到其他后端：
    ```bash
    --attention-backend triton --sampling-backend pytorch
    ```
  </Accordion>
  <Accordion title="重装 FlashInfer">
    ```bash
    pip3 install --upgrade flashinfer-python --force-reinstall --no-deps
    rm -rf ~/.cache/flashinfer
    ```
  </Accordion>
  <Accordion title="B300/GB300（sm_103a）上的 ptxas 报错">
    ```bash
    export TRITON_PTXAS_PATH=/usr/local/cuda/bin/ptxas
    ```
  </Accordion>
</AccordionGroup>
