SGLang 已成为现代 LLM 训练框架事实上的推理后端，为业界顶尖模型提供算力支撑。从 GLM-4.6 到 Qwen3，领先模型都在强化学习和后训练流程中借助 SGLang 的高性能推理。

为什么后训练离不开 SGLang？

- 开箱即用的 Refit 功能：支持共置或分离部署等多种方式
- 便捷的生成暂停：支持部分 rollout 和专门的 rollout 控制
- 细粒度的引擎休眠与唤醒：为 rollout 和训练提供充足算力
- 训练推理一致性：保证训练和推理服务性能一致
- 负载均衡路由器：感知缓存的负载均衡，支撑高吞吐 rollout
- 确定性推理：确保 rollout 与训练之间零 KL 散度

<Note>
💡 AI Infra 学习笔记：强化学习（RL）训练流程是“训练-采样”交替循环——策略模型每更新一步，就要用当前权重大规模生成 rollout 数据（推理），再拿这些数据去更新模型（训练）。推理必须足够快、足够稳定，否则整个 RL 循环都会被拖慢。SGLang 在其中的关键能力包括：rollout 与训练共用权重（refit）、细粒度启停引擎（训练时让出算力）、以及确定性推理（保证 rollout 数据与训练环境数值一致，避免 KL 漂移）。理解了这一点，就能看懂为什么“训练框架”的文档里会出现“推理后端”的身影。
</Note>

这些能力，加上对主流框架的原生集成支持，让 SGLang 成为现代 LLM/VLM 后训练的基础设施骨干。我们也在幻灯片 [Optimizing Large-Scale RL with SGLang](https://gamma.app/docs/Optimizing-RL-with-SGLang-y0kqgj877k34779) 中分享了最新工作。

## 生态采用

- [**Miles**](https://github.com/radixark/miles)：面向大型 MoE 模型的企业级 RL 框架，原生对接 SGLang rollout，支持投机训练和生产级稳定性
- [**slime**](https://github.com/THUDM/slime)：结合 Megatron 和 SGLang 的后训练框架，用于训练 GLM-4.6
- [**AReaL**](https://github.com/inclusionAI/AReaL)：全异步 RL 系统，以 SGLang 为后端做持续 rollout 生成，获得 2.77 倍加速
- [**ROLL**](https://github.com/alibaba/ROLL)：一个高效易用的 LLM 强化学习库，面向大规模 GPU 资源
- [**verl**](https://github.com/volcengine/verl)：全栈 RLHF 框架，支持 PPO、GRPO 和 ReMax，模块化集成 SGLang
- [**Unsloth**](https://docs.unsloth.ai/basics/inference-and-deployment/sglang-guide)：用优化后的 kernel 把微调加速 2 倍，可与 SGLang 推理无缝对接部署
- [**LLaMA Factory**](https://github.com/hiyouga/LLaMA-Factory)：统一框架，用 LoRA、QLoRA 和全参微调等方法训练 100+ LLM
- [**Tunix**](https://github.com/google/tunix)：Google 的 JAX 原生 LLM 后训练库，支持 SFT、DPO、PPO 和 GRPO
- [**RL2**](https://github.com/ChenmienTan/RL2)：Ray Less 强化学习库，一个精简的 LLM 后训练库
