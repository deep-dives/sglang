SGLang 支持通过多种环境变量配置其运行时行为。本文档提供了一份完整的环境变量列表，并会持续更新。

*注：所有 SGLang 环境变量的标准前缀为 `SGLANG_`。旧版 `SGL_` 前缀已弃用：环境中设置的任何 `SGL_*` 变量都会在 import 时自动改写为对应的 `SGLANG_*` 变量并输出弃用警告，该别名将在未来版本中移除。少数变量保留上游/厂商前缀（如 `MOONCAKE_*`、`ASCEND_*`），因为那是它们的正式名称。*

<Note>
💡 AI Infra 学习笔记：环境变量是推理引擎在生产环境里的「旋钮」——它们控制显存分配（KV 缓存、内存池）、并行策略（TP/PP/EP/CP）、量化、调度与日志等关键行为。做性能调优时，优先关注与显存和并行相关的变量，因为它们直接决定吞吐量与延迟。这类「以配置驱动行为」的能力也是 SGLang、vLLM 等推理引擎区别于训练框架的一大特点。
</Note>
