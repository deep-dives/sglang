本文介绍 SGLang 支持的 choices 方法。

<Note>
💡 AI Infra 学习笔记：`choices` 让模型在给定候选项中选一个，常用于分类、打分类任务。难点在于模型对较长 token 有系统性偏好，直接比较 logprob 会偏向长选项，因此需要不同的归一化策略来消除 token 数量带来的偏差——理解这类细节，是评估 LLM 分类/工具调用可靠性时的高频考点。
</Note>

可选的 `choices_method` 参数决定如何从提供给 SGLang `choices` 原语的候选项中挑选结果。只有 `RuntimeEndpoint` 后端支持 `choices_method` 参数；其它后端（如 `OpenAI`）受 API 限制，各自实现了不同的选择逻辑。

## 方法

### 按 Token 长度归一化

按 Token 长度归一化是 SGLang 默认的 choices 方法。它计算每个候选项所有 token 的平均 logprob，选择最高者。

用法示例（也可以直接省略 `choices_method` 参数）：
```python Example
@sgl.function
def example(s):
    s += sgl.user("What is the capital of France?")
    s += sgl.assistant(
        sgl.gen(
            "answer",
            choices=["London", "Paris", "Berlin"],
            choices_method=sgl.token_length_normalized,
        )
    )
```


如果某个候选项包含很多 token，且后面的 token 可以基于前面的 token 被高置信度地预测出来，这种方法的效果就会变差。例如，如果把候选项设为 `["Paris", "Antidisestablishmentarianism"]`，即使是强大的模型也会在以上示例中失败。

### 贪心 Token 选择

贪心 Token 选择只比较每个候选项首个 token 的 logprob，选最高的。当候选项之间存在包含关系（一个选项是更长选项的子串）时，短选项会用它自身的平均 logprob 补齐 logprobs，再与长选项比较。

用法示例：
```python Example
@sgl.function
def example(s):
    s += sgl.user("What is the capital of France?")
    s += sgl.assistant(
        sgl.gen(
            "answer",
            choices=["London", "Paris", "Berlin"],
            choices_method=sgl.greedy_token_selection,
        )
    )
```

如果某个候选项凭借有吸引力的首个 token 把模型引向错误方向，这种方法就会表现不佳。例如，贪心选择在下面这个示例中会得到错误答案：
```python Example
@sgl.function
def us_president_example(s):
    s += sgl.user("Name a US president.")
    s += sgl.assistant(
        sgl.gen(
            "answer",
            choices=["Donald Duck", "Millard Fillmore"],
            choices_method=sgl.greedy_token_selection,
        )
    )
```

### 无条件似然归一化

无条件似然归一化会用无条件 token logprobs 对平均 token logprob 做归一化，再选择最高的候选项，具体参见 [EleutherAI 的这篇博客](https://blog.eleuther.ai/multiple-choice-normalization/)。该方法需要额外调用一次 LLM 来获取无条件似然。

用法示例：
```python Example
@sgl.function
def example(s):
    s += sgl.user("What is the capital of France?")
    s += sgl.assistant(
        sgl.gen(
            "answer",
            choices=["London", "Paris", "Berlin"],
            choices_method=sgl.unconditional_likelihood_normalized,
        )
    )
```
