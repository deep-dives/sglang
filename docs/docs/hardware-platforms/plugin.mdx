## 概述

允许硬件厂商和开发者扩展 SGLang，**无需修改主仓库代码**。

该框架提供两种插件类型，都通过 Python 标准的 `setuptools` entry_points 发现：

### 设计原则

- **非侵入**：现有的 CUDA/ROCm/NPU/XPU 代码保持不变。OOT 代码路径与已有的硬件特定逻辑并存。
- **零配置**：`pip install` 后插件会被自动发现，无需修改任何 sglang 代码。
- **环境变量控制**：`SGLANG_PLATFORM` 选择或校验要激活的平台插件；`SGLANG_PLUGINS`（逗号分隔）控制加载哪些通用插件。

### 当前范围与未来方向

插件系统目前面向**树外（OOT）硬件平台**——让新设备无需对主仓库做任何改动就能接入 SGLang。主仓库的硬件路径（CUDA、ROCm、NPU、XPU 等）继续使用现有的 `is_cuda()`/`is_npu()`/…… 工具函数。

随着插件接口逐渐成熟和稳定，树内硬件后端可以逐步迁移到同一套插件架构上。这将把代码库中散落的 `if device == "cuda" … elif device == "npu" …` 分支替换为通过平台接口的统一多态分发，让每个硬件后端自包含，核心引擎则与硬件无关。

## 架构

### 平台层级

平台层级使用 DeviceMixin 模式，在 SRT（LLM 推理）与多模态子系统之间共享设备操作：

```
DeviceMixin (shared device identity + operations)
├── SRTPlatform(DeviceMixin)           # + graph runner, KV pool, …
│   └── MySRTPlatform(SRTPlatform, MyDeviceMixin)   # OOT plugin
└── MMPlatform(DeviceMixin)            # + attention backend, VAE, … (future)
    └── MyMMPlatform(MMPlatform, MyDeviceMixin)      # OOT plugin
```

关键设计点：
- **DeviceMixin** 提供平台身份查询（`is_cuda()`、`is_npu()` 等）和设备操作（`set_device()`、`get_device_name()` 等）
- **SRTPlatform** 增加 SRT 特定的工厂方法、能力标志和生命周期钩子
- OOT 插件实现一个**设备 mixin**（厂商特定操作），并通过多重继承与 **SRTPlatform** 组合
- 所有方法都是**实例方法**（不是 classmethod），通过 `current_platform` 单例调用
- 设备操作和工厂方法默认抛 `NotImplementedError`（快速失败）
- 能力标志使用安全的保守默认值（`False`/`pass`）
- 方法标注为 **[Active]**（由 SGLang 核心调用）或 **[Planned]**（为未来迁移预留）

### 平台发现（`current_platform`）

`current_platform` 是 `sglang.srt.platforms` 中的**懒加载单例**。首次访问时按以下优先级链解析当前激活的平台：

```
entry_points("sglang.srt.platforms")  → Enumerate ALL plugins by name (metadata only)
  │
  ├─ SGLANG_PLATFORM set (front-loading filter):
  │   ├─ Name not found in discovered → RuntimeError
  │   ├─ activate() returns non-None  → load that platform
  │   └─ activate() returns None      → RuntimeError (hardware unavailable)
  │
  └─ SGLANG_PLATFORM unset (auto-discover, activate all):
      ├─ 0 activated + SGLANG_USE_CPU_ENGINE=1 → fallback CpuSRTPlatform
      ├─ 0 activated + CUDA available          → fallback CudaSRTPlatform
      ├─ 0 activated + ROCm available          → fallback RocmSRTPlatform
      ├─ 0 activated + XPU available           → fallback XpuSRTPlatform
      ├─ 0 activated + none of the above       → fallback base SRTPlatform
      ├─ 1 activated → use it
      └─ N activated → RuntimeError (must set SGLANG_PLATFORM)
```

> **注意**：`load_plugins()` 是幂等的（由 `_plugins_loaded` 标志保护）。在 spawn 出的子进程中该标志会重置，因此插件会被正确地重新加载。

```
load_plugins()
  ├── _get_excluded_dists()                       → compute dists to skip (via SGLANG_PLATFORM)
  ├── load_plugins_by_group("sglang.srt.plugins",     → discover entry_points, filter by SGLANG_PLUGINS
  │     excluded_dists=...)                          skip plugins from unselected platform packages
  ├── for each plugin:                            → set _current_plugin_source context var
  │     func()                                      side effects (register hooks with source tracking)
  └── HookRegistry.apply_hooks()                  → monkey-patch targets
```

## 插件类型 1：硬件平台插件

### 描述

硬件平台插件注册一个 `SRTPlatform` 子类，告诉 SGLang 如何与特定的硬件后端交互。

### 快速开始

**1. 创建一个最小的包：**

```
my_platform_plugin/
├── pyproject.toml
└── my_platform_plugin/
    ├── __init__.py    # activate() function
    ├── device.py      # MyDeviceMixin
    └── platform.py    # MySRTPlatform
```

**2. `pyproject.toml`：**

```toml
[build-system]
requires = ["setuptools"]
build-backend = "setuptools.build_meta"

[project]
name = "my-platform-plugin"
version = "0.1.0"

[project.entry-points."sglang.srt.platforms"]
my_device = "my_platform_plugin:activate"
```

**3. `__init__.py`** —— 激活函数：

```python
def activate():
    """Return fully-qualified class name to activate, or None to skip."""
    if _my_device_is_available():
        return "my_platform_plugin.platform.MySRTPlatform"
    return None
```

**4. `device.py`** —— 设备 mixin：

```python
from sglang.srt.platforms.device_mixin import DeviceMixin, PlatformEnum

class MyDeviceMixin(DeviceMixin):
    _enum = PlatformEnum.OOT
    device_name = "my_device"
    device_type = "my_device"   # torch device type

    def set_device(self, device) -> None: ...
    def get_device_name(self, device_id=0) -> str: ...
    def get_device_total_memory(self, device_id=0) -> int: ...
    def get_current_memory_usage(self, device=None) -> float: ...
    def get_device_capability(self, device_id=0): ...
    def get_torch_distributed_backend_str(self) -> str: ...
```

**5. `platform.py`** —— SRT 平台：

```python
from sglang.srt.platforms.interface import SRTPlatform
from my_platform_plugin.device import MyDeviceMixin

class MySRTPlatform(SRTPlatform, MyDeviceMixin):
    def get_default_attention_backend(self) -> str: ...
    def support_cuda_graph(self) -> bool: ...
    # ... override other methods as needed
```

**6. 安装并验证：**

```bash
pip install -e my_platform_plugin/
python -c "from sglang.srt.platforms import current_platform; print(current_platform)"
```

## 插件类型 2：通用插件

### 描述

通用功能插件向 sglang 注入行为，**无需自定义平台**。用例包括：

- **可观测性**：向任意函数添加日志、指标和追踪
- **行为修改**：修改函数参数或返回值
- **性能剖析**：给关键函数加上计时
- **A/B 测试**：在运行时替换实现

### 快速开始

**1. 创建一个最小的包：**

```
my_general_plugin/
├── pyproject.toml
└── my_general_plugin/
    └── __init__.py    # register() function
```

**2. `pyproject.toml`：**

```toml
[build-system]
requires = ["setuptools"]
build-backend = "setuptools.build_meta"

[project]
name = "my-general-plugin"
version = "0.1.0"

[project.entry-points."sglang.srt.plugins"]
my_plugin = "my_general_plugin:register"
```

**3. `__init__.py`** —— 注册钩子：

```python
from sglang.srt.plugins.hook_registry import HookRegistry, HookType

def register():
    """Entry point called by load_plugins()."""
    HookRegistry.register(
        "sglang.srt.managers.scheduler.Scheduler.__init__",
        my_hook,
        HookType.AROUND,
    )

def my_hook(original_fn, self, *args, **kwargs):
    result = original_fn(self, *args, **kwargs)
    print(f"Scheduler initialized! gpu_id={self.gpu_id}")
    return result
```

**4. 安装并运行：**

```bash
pip install -e my_general_plugin/
sglang serve --model-path <model> [options]
# Look for "Scheduler initialized!" in logs
```

### 钩子类型

`HookRegistry` 支持四种钩子类型：

<table style={{width: "100%", borderCollapse: "collapse", tableLayout: "fixed"}}>
  <colgroup>
    <col style={{width: "33.33%"}} />
    <col style={{width: "33.33%"}} />
    <col style={{width: "33.33%"}} />
  </colgroup>
  <thead>
    <tr>
      <th>钩子类型</th>
      <th>签名</th>
      <th>描述</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td><strong>BEFORE</strong></td>
      <td><code>fn(*args, **kwargs) -&gt; (args, kwargs) \| None</code></td>
      <td>在原始函数之前运行。返回 <code>None</code> 保持参数不变，或返回 <code>(args, kwargs)</code> 修改参数。</td>
    </tr>
    <tr>
      <td><strong>AFTER</strong></td>
      <td><code>fn(result, *args, **kwargs) -&gt; new_result \| None</code></td>
      <td>在原始函数之后运行。返回 <code>None</code> 保留结果，或返回新值替换。</td>
    </tr>
    <tr>
      <td><strong>AROUND</strong></td>
      <td><code>fn(original_fn, *args, **kwargs) -&gt; result</code></td>
      <td>包裹原始函数。你需要自己调用 <code>original_fn</code>。对执行有完全的控制。</td>
    </tr>
    <tr>
      <td><strong>REPLACE</strong></td>
      <td><code>fn(*args, **kwargs) -&gt; result</code> 或 <code>class</code></td>
      <td>整体替换原始函数或类。对于类目标，直接传入替换类——通过 <code>setattr</code> 替换，同时保持 <code>isinstance()</code>/<code>issubclass()</code> 语义。</td>
    </tr>
  </tbody>
</table>

> **注意**：只有 `REPLACE` 接受类作为钩子。把类传给 `BEFORE`/`AFTER`/`AROUND` 会在注册时报 `TypeError`。

### 注册 API

钩子可以用**命令式 API** 或**装饰器 API** 注册：

```python
# --- Imperative API ---
from sglang.srt.plugins.hook_registry import HookRegistry, HookType

def my_timer(original_fn, *args, **kwargs):
    start = time.perf_counter()
    result = original_fn(*args, **kwargs)
    print(f"Elapsed: {time.perf_counter() - start:.3f}s")
    return result

HookRegistry.register(
    "sglang.srt.managers.scheduler.Scheduler.get_next_batch_to_run",
    my_timer,
    HookType.AROUND,
)

# --- Decorator API ---
from sglang.srt.plugins.hook_registry import plugin_hook, HookType

@plugin_hook(
    "sglang.srt.managers.scheduler.Scheduler.get_next_batch_to_run",
    type=HookType.AROUND,
)
def my_timer(original_fn, *args, **kwargs):
    start = time.perf_counter()
    result = original_fn(*args, **kwargs)
    print(f"Elapsed: {time.perf_counter() - start:.3f}s")
    return result

# --- Class replacement (REPLACE) ---
from sglang.srt.plugins.hook_registry import plugin_hook, HookType
from sglang.srt.managers.scheduler import Scheduler

@plugin_hook(
    "sglang.srt.managers.scheduler.Scheduler",
    type=HookType.REPLACE,
)
class MyScheduler(Scheduler):
    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        print("Enhanced scheduler initialized!")
```

### 钩子目标解析

目标路径使用全限定点分表示法。两种格式都支持：

- **点分格式**：`sglang.srt.managers.scheduler.Scheduler.__init__`
- **entry-point 风格**：`sglang.srt.managers.scheduler:Scheduler.__init__`（冒号按点处理）
