---
title: 奖励模型
---

这些模型输出标量奖励分数或分类结果，常用于强化学习或内容审核任务。

它们使用 `--is-embedding` 执行，部分模型可能需要 `--trust-remote-code`。

<Note>
💡 AI Infra 学习笔记：奖励模型（reward model）是 RLHF/RL 训练链路里的"裁判"——它不对用户说话，而是接收一段文本（或 prompt + response），输出一个标量分数，表示这段文本有多符合人类偏好。因此它的推理形态与嵌入/分类模型类似：一次前向输出分数，没有自回归生成，所以 SGLang 里用 `--is-embedding` 运行。推理侧关心的是打分吞吐与低延迟（训练中会被海量调用），这也解释了为什么奖励模型服务要复用嵌入 runner 的批处理能力。
</Note>

## 示例启动命令

<CodeGroup>
```shell Command
python3 -m sglang.launch_server \
  --model-path Qwen/Qwen2.5-Math-RM-72B \  # example HF/local path
  --is-embedding \
  --host 0.0.0.0 \
  --tp-size=4 \                          # set for tensor parallelism
  --port 30000 \
```
</CodeGroup>

## 支持的模型

| 模型系列（奖励）                                                          | 示例 HuggingFace 标识符                                       | 描述                                                                      |
|---------------------------------------------------------------------------|-----------------------------------------------------|---------------------------------------------------------------------------------|
| **Llama（3.1 Reward / `LlamaForSequenceClassification`）**                 | `Skywork/Skywork-Reward-Llama-3.1-8B-v0.2`            | 基于 Llama 3.1（8B）的奖励模型（偏好分类器），用于 RLHF 中为响应打分和排序。 |
| **Gemma 2（27B Reward / `Gemma2ForSequenceClassification`）**              | `Skywork/Skywork-Reward-Gemma-2-27B-v0.2`             | 基于 Gemma‑2（27B）派生，为 RLHF 与多语言任务提供人类偏好打分。 |
| **InternLM 2（Reward / `InternLM2ForRewardMode`）**                        | `internlm/internlm2-7b-reward`                        | 基于 InternLM 2（7B）的奖励模型，用于对齐流水线中引导输出朝偏好行为靠拢。 |
| **Qwen2.5（Reward - Math / `Qwen2ForRewardModel`）**                       | `Qwen/Qwen2.5-Math-RM-72B`                            | 来自 Qwen2.5 系列的 72B 数学专用 RLHF 奖励模型，用于评估和改进响应。 |
| **Qwen2.5（Reward - Sequence / `Qwen2ForSequenceClassification`）**        | `jason9693/Qwen2.5-1.5B-apeach`                       | 用于序列分类的较小 Qwen2.5 变体，提供另一种 RLHF 评分机制。 |
