---
title: 大语言模型
---
这些模型接收文本输入并产生文本输出（例如对话补全）。它们主要是大语言模型（LLM），其中一些采用混合专家（MoE）架构以支持更大规模的扩展。

## 示例启动命令

```shell Command
python3 -m sglang.launch_server \
  --model-path meta-llama/Llama-3.2-1B-Instruct \  # example HF/local path
  --host 0.0.0.0 \
  --port 30000 \
```

## 支持的模型

下表汇总了支持的模型。

如果你不确定某个特定架构是否已实现，可以通过 GitHub 搜索。例如，要搜索 `Qwen3ForCausalLM`，请在 GitHub 搜索栏中使用以下表达式：

```text Output
repo:sgl-project/sglang path:/^python\/sglang\/srt\/models\// Qwen3ForCausalLM
```

<Note>
💡 AI Infra 学习笔记：读这张表时留意 MoE 模型的命名规律，例如 `Qwen3-30B-A3B` 表示"总参数 30B、激活参数 3B"。MoE 的稀疏激活意味着推理时只计算被路由到的那几个专家的前向，理论上算力开销远小于总参数量对应的稠密模型——这正是大模型能把参数量堆到百亿、千亿级别的关键。对推理引擎来说，MoE 会引入额外的显存布局（把每个专家当独立权重）与路由调度问题，往往需要配合专家并行（EP）才能榨干多 GPU 的利用率。
</Note>
