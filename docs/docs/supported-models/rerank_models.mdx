---
title: 重排序模型
---
SGLang 通过优化的服务化框架与灵活的程序接口，为重排序模型提供了全面支持。这套设计能高效处理交叉编码器（cross-encoder）重排序任务，提升搜索结果排序的准确性与相关性。SGLang 的设计确保重排序模型部署时具备高吞吐与低延迟，非常适合大规模检索系统中的基于语义的结果精排。

<Warning>
SGLang 中的重排序模型分为两类：

- **交叉编码器重排序模型**：使用 `--is-embedding`（嵌入 runner）运行。
- **仅解码器（decoder-only）重排序模型**：**不加** `--is-embedding` 运行，使用下一 token 的 logprob 评分（yes/no）。
  - 纯文本（例如 Qwen3-Reranker）
  - 多模态（例如 Qwen3-VL-Reranker）：还支持图像/视频内容

某些模型可能需要 `--trust-remote-code`。
</Warning>

<Note>
💡 AI Infra 学习笔记：检索系统里常区分两类模型：双编码器（bi-encoder）与交叉编码器（cross-encoder）。双编码器把 query 和 document 分别编码成向量，靠向量相似度做召回，速度快但精度有限——嵌入模型就属于这一类；交叉编码器把 query 和 document 拼在一起过一遍模型打分，精度高但慢，通常作为召回后的精排阶段。SGLang 对两类都支持：交叉编码器走嵌入 runner（`--is-embedding`），解码器式重排序器则用下一 token 的 logprob 做 yes/no 打分。理解这个"粗召回 + 精排"的分层架构，是理解 RAG/向量检索系统性能设计的钥匙。
</Note>

## 交叉编码器重排序（嵌入 runner）

### 启动命令

```shell
python3 -m sglang.launch_server \
  --model-path BAAI/bge-reranker-v2-m3 \
  --host 0.0.0.0 \
  --disable-radix-cache \
  --chunked-prefill-size -1 \
  --attention-backend triton \
  --is-embedding \
  --port 30000
```

### 示例客户端请求

```python
import requests

url = "http://127.0.0.1:30000/v1/rerank"

payload = {
    "model": "BAAI/bge-reranker-v2-m3",
    "query": "what is panda?",
    "documents": [
        "hi",
        "The giant panda (Ailuropoda melanoleuca), sometimes called a panda bear or simply panda, is a bear species endemic to China."
    ],
    "top_n": 1,
    "return_documents": True
}

response = requests.post(url, json=payload)
response_json = response.json()

for item in response_json:
    if item.get("document"):
        print(f"Score: {item['score']:.2f} - Document: '{item['document']}'")
    else:
        print(f"Score: {item['score']:.2f} - Index: {item['index']}")
```

**请求参数：**

- `query`（必填）：用于对文档排序的查询文本
- `documents`（必填）：待排序的文档列表
- `model`（必填）：用于重排序的模型
- `top_n`（可选）：返回的最大文档数。默认为返回全部文档。如果指定值大于文档总数，则返回全部文档。
- `return_documents`（可选）：是否在响应中返回文档。默认为 `True`。

## Qwen3-Reranker（仅解码器 yes/no 重排序）

### 启动命令

```shell
python3 -m sglang.launch_server \
  --model-path Qwen/Qwen3-Reranker-0.6B \
  --trust-remote-code \
  --disable-radix-cache \
  --host 0.0.0.0 \
  --port 8001 \
  --chat-template examples/chat_template/qwen3_reranker.jinja
```

<Note>
Qwen3-Reranker 使用仅解码器的 logprob 打分（yes/no）。请勿用 `--is-embedding` 启动它。
</Note>

<Note>
💡 AI Infra 学习笔记：Qwen3-Reranker 这类"仅解码器 yes/no 重排序器"把重排问题包装成了一次生成任务——把 query 与文档拼进提示词，让模型只产出 yes/no，再取 yes/no 对应 token 的 logprob 作为相关性分数。这样它就能复用 LLM 的上下文建模能力，而 SGLang 的 KV 缓存/前缀缓存也能直接生效。要注意：它既然走生成路径，就**不能**用嵌入 runner 的 `--is-embedding` 启动，否则 `/v1/rerank` 无从计算 logprob。
</Note>

### 示例客户端请求（支持可选的 instruct、top_n 与 return_documents）

```shell
curl -X POST http://127.0.0.1:8001/v1/rerank \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Qwen3-Reranker-0.6B",
    "query": "法国首都是哪里？",
    "documents": [
      "法国的首都是巴黎。",
      "德国的首都是柏林。",
      "香蕉是黄色的水果。"
    ],
    "instruct": "Given a web search query, retrieve relevant passages that answer the query.",
    "top_n": 2,
    "return_documents": true
  }'
```

**请求参数：**

- `query`（必填）：用于对文档排序的查询文本
- `documents`（必填）：待排序的文档列表
- `model`（必填）：用于重排序的模型
- `instruct`（可选）：给重排序器的指令文本
- `top_n`（可选）：返回的最大文档数。默认为返回全部文档。如果指定值大于文档总数，则返回全部文档。
- `return_documents`（可选）：是否在响应中返回文档。默认为 `True`。

### 响应格式

`/v1/rerank` 返回一个对象列表（按分数降序排列）：

- `score`：浮点数，越大表示相关性越高
- `document`：原始文档字符串（仅当 `return_documents` 为 `true` 时包含）
- `index`：在输入 `documents` 中的原始索引
- `meta_info`：可选的调试/用量信息（某些模型可能提供）

返回结果的数量由 `top_n` 参数控制。如果未指定 `top_n` 或其值大于文档总数，则返回全部文档。

示例（`return_documents: true`）：

```json
[
  {"score": 0.99, "document": "法国的首都是巴黎。", "index": 0},
  {"score": 0.01, "document": "德国的首都是柏林。", "index": 1},
  {"score": 0.00, "document": "香蕉是黄色的水果。", "index": 2}
]
```

示例（`return_documents: false`）：

```json
[
  {"score": 0.99, "index": 0},
  {"score": 0.01, "index": 1},
  {"score": 0.00, "index": 2}
]
```

示例（`top_n: 2`）：

```json
[
  {"score": 0.99, "document": "法国的首都是巴黎。", "index": 0},
  {"score": 0.01, "document": "德国的首都是柏林。", "index": 1}
]
```

### 常见坑

- **必须加 `--chat-template`。** 不加 `--chat-template examples/chat_template/qwen3_reranker.jinja` 时，服务端无法识别该模型是仅解码器重排序器，会返回 400 错误：`"This model does not appear to be an embedding model by default. Please add `--is-embedding`..."`。解决办法是加上 chat template 参数，而**不是** `--is-embedding`。
- 如果你用 `--is-embedding` 启动 Qwen3-Reranker，`/v1/rerank` 将无法计算 yes/no logprob 分数。请**去掉** `--is-embedding` 重新启动。
- 如果遇到类似 "score should be a valid number" 的校验错误，且后端返回的是列表，请升级到能把 `embedding[0]` 强转为 `score` 以用于重排序响应的版本。

## Qwen3-VL-Reranker（多模态仅解码器重排序）

Qwen3-VL-Reranker 扩展了 Qwen3-Reranker，以支持多模态内容，可对包含文本、图像和视频的文档进行重排序。

### 启动命令

```shell
python3 -m sglang.launch_server \
  --model-path Qwen/Qwen3-VL-Reranker-2B \
  --trust-remote-code \
  --disable-radix-cache \
  --host 0.0.0.0 \
  --port 30000 \
  --chat-template examples/chat_template/qwen3_vl_reranker.jinja
```

<Note>
Qwen3-VL-Reranker 与 Qwen3-Reranker 一样使用仅解码器的 logprob 打分（yes/no）。请勿用 `--is-embedding` 启动它。
</Note>

### 纯文本重排序（向后兼容）

```python
import requests

url = "http://127.0.0.1:30000/v1/rerank"

payload = {
    "model": "Qwen3-VL-Reranker-2B",
    "query": "What is machine learning?",
    "documents": [
        "Machine learning is a branch of artificial intelligence that enables computers to learn from data.",
        "The weather in Paris is usually mild with occasional rain.",
        "Deep learning is a subset of machine learning using neural networks with many layers.",
    ],
    "instruct": "Retrieve passages that answer the question.",
    "return_documents": True
}

response = requests.post(url, json=payload)
results = response.json()

for item in results:
    print(f"Score: {item['score']:.4f} - {item['document'][:60]}...")
```

### 图像重排序（文本查询，图像/混合文档）

```python
import requests

url = "http://127.0.0.1:30000/v1/rerank"

payload = {
    "query": "A woman playing with her dog on a beach at sunset.",
    "documents": [
        # Document 1: Text description
        "A woman shares a joyful moment with her golden retriever on a sun-drenched beach at sunset.",
        # Document 2: Image URL
        [
            {
                "type": "image_url",
                "image_url": {
                    "url": "https://example.com/beach_dog.jpeg"
                }
            }
        ],
        # Document 3: Text + Image (mixed)
        [
            {"type": "text", "text": "A joyful scene at the beach:"},
            {
                "type": "image_url",
                "image_url": {
                    "url": "https://example.com/beach_dog.jpeg"
                }
            }
        ]
    ],
    "instruct": "Retrieve images or text relevant to the user's query.",
    "return_documents": False
}

response = requests.post(url, json=payload)
results = response.json()

for item in results:
    print(f"Index: {item['index']}, Score: {item['score']:.4f}")
```

### 多模态查询重排序（带图像的查询）

```python
import requests

url = "http://127.0.0.1:30000/v1/rerank"

payload = {
    # Query with text and image
    "query": [
        {"type": "text", "text": "Find similar images to this:"},
        {
            "type": "image_url",
            "image_url": {
                "url": "https://example.com/reference_image.jpeg"
            }
        }
    ],
    "documents": [
        "A cat sleeping on a couch.",
        "A woman and her dog enjoying the sunset at the beach.",
        "A busy city street with cars and pedestrians.",
        [
            {
                "type": "image_url",
                "image_url": {
                    "url": "https://example.com/similar_image.jpeg"
                }
            }
        ]
    ],
    "instruct": "Find images or descriptions similar to the query image."
}

response = requests.post(url, json=payload)
results = response.json()

for item in results:
    print(f"Index: {item['index']}, Score: {item['score']:.4f}")
```

### 请求参数（多模态）

- `query`（必填）：可以是字符串（纯文本）或内容片段列表：
  - `&#123;"type": "text", "text": "..."&#125;` 用于文本
  - `&#123;"type": "image_url", "image_url": &#123;"url": "..."&#125;&#125;` 用于图像
  - `&#123;"type": "video_url", "video_url": &#123;"url": "..."&#125;&#125;` 用于视频
- `documents`（必填）：文档列表，每个文档可以是字符串或内容片段列表（格式与 query 相同）
- `instruct`（可选）：给重排序器的指令文本
- `top_n`（可选）：返回的最大文档数
- `return_documents`（可选）：是否在响应中返回文档（默认：`false`）

### 常见坑

- 对 Qwen3-VL-Reranker 始终使用 `--chat-template examples/chat_template/qwen3_vl_reranker.jinja`。
- 请勿用 `--is-embedding` 启动。
- 为获得最佳效果，使用 `--disable-radix-cache` 以避免多模态内容的缓存问题。
- **注意**：目前只测试并支持 `Qwen3-VL-Reranker-2B`。8B 模型可能有不同行为，不保证能与此模板配合工作。
