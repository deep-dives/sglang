本教程提供安装后使用 SGLang 进行聊天补全的快速入门指南。服务端运行起来后，API 文档可在 `http://localhost:30000/docs`（Swagger UI）、`http://localhost:30000/redoc`（ReDoc）或 `http://localhost:30000/openapi.json`（OpenAPI 规范，对 AI 智能体很有用）查看。如果使用其他端口，请把 `30000` 换成你的端口。

- 视觉语言模型请参见 [OpenAI API - 视觉](./openai_api_vision)。
- 嵌入模型请参见 [OpenAI API - 嵌入](./openai_api_embeddings) 和 [Encode（嵌入模型）](./native_api#encode-embedding-model)。
- 奖励模型请参见 [Classify（奖励模型）](./native_api#classify-reward-model)。

## 启动服务端

```python Example
from sglang.test.doc_patch import launch_server_cmd
from sglang.utils import wait_for_server, terminate_process

# This is equivalent to running the following command in your terminal
# python3 -m sglang.launch_server --model-path qwen/qwen2.5-0.5b-instruct --host 0.0.0.0

server_process, port = launch_server_cmd(
    """
python3 -m sglang.launch_server --model-path qwen/qwen2.5-0.5b-instruct \
 --host 0.0.0.0 --log-level warning
"""
)

wait_for_server(f"http://localhost:{port}")
```

## 使用 cURL

```python Example
import subprocess, json

curl_command = f"""
curl -s http://localhost:{port}/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{{"model": "qwen/qwen2.5-0.5b-instruct", "messages": [{{"role": "user", "content": "What is the capital of France?"}}]}}'
"""

response = json.loads(subprocess.check_output(curl_command, shell=True))
print(response)
```

## 使用 Python requests

```python Example
import requests

url = f"http://localhost:{port}/v1/chat/completions"

data = {
    "model": "qwen/qwen2.5-0.5b-instruct",
    "messages": [{"role": "user", "content": "What is the capital of France?"}],
}

response = requests.post(url, json=data)
print(response.json())
```

## 使用 OpenAI Python 客户端

<Note>
💡 AI Infra 学习笔记：`/v1/chat/completions` 请求在服务端会先经过「对话模板」，把 messages 列表组装成模型期望的完整输入文本（包括 system/role 等特殊标记），再分词、prefill。所以同样的消息，换模型后输出可能不同——对话模板是推理服务里容易被忽略的「隐藏参数」，也可用 `--chat-template` 覆盖。
</Note>

```python Example
import openai

client = openai.Client(base_url=f"http://127.0.0.1:{port}/v1", api_key="None")

response = client.chat.completions.create(
    model="qwen/qwen2.5-0.5b-instruct",
    messages=[
        {"role": "user", "content": "List 3 countries and their capitals."},
    ],
    temperature=0,
    max_tokens=64,
)
print(response)
```

### 流式

<Note>
💡 AI Infra 学习笔记：流式响应使用 Server-Sent Events（SSE）协议，数据以 `data:` 前缀的 JSON 分块到达，最后以 `data: [DONE]` 结束。逐 chunk 打印能显著降低首 token 延迟（TTFT）的感知，是聊天类产品的基本交互模式。
</Note>

```python Example
import openai

client = openai.Client(base_url=f"http://127.0.0.1:{port}/v1", api_key="None")

# Use stream=True for streaming responses
response = client.chat.completions.create(
    model="qwen/qwen2.5-0.5b-instruct",
    messages=[
        {"role": "user", "content": "List 3 countries and their capitals."},
    ],
    temperature=0,
    max_tokens=64,
    stream=True,
)

# Handle the streaming output
for chunk in response:
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
```

## 使用原生生成 API

你也可以用 requests 调用更灵活的原生 `/generate` 端点。API 参考见[采样参数](./sampling_params)。

```python Example
import requests

response = requests.post(
    f"http://localhost:{port}/generate",
    json={
        "text": "The capital of France is",
        "sampling_params": {
            "temperature": 0,
            "max_new_tokens": 32,
        },
    },
)

print(response.json())
```
### 流式

```python Example
import requests, json

response = requests.post(
    f"http://localhost:{port}/generate",
    json={
        "text": "The capital of France is",
        "sampling_params": {
            "temperature": 0,
            "max_new_tokens": 32,
        },
        "stream": True,
    },
    stream=True,
)

prev = 0
for chunk in response.iter_lines(decode_unicode=False):
    chunk = chunk.decode("utf-8")
    if chunk and chunk.startswith("data:"):
        if chunk == "data: [DONE]":
            break
        data = json.loads(chunk[5:].strip("\n"))
        output = data["text"]
        print(output[prev:], end="", flush=True)
        prev = len(output)
```
