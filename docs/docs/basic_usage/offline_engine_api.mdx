SGLang 提供了一个无需 HTTP 服务端的直接推理引擎，特别适合那些额外引入 HTTP 服务端只会徒增复杂度或开销的使用场景。以下是两类常见用法：

- 离线批量推理
- 在引擎之上构建自定义服务端

本文重点介绍离线批量推理，演示四种不同的推理模式：

- 非流式同步生成
- 流式同步生成
- 非流式异步生成
- 流式异步生成

<Note>
💡 AI Infra 学习笔记：同步/异步描述的是调用方如何等待结果（阻塞等待还是挂起协程），流式/非流式描述的是结果一次性返回还是按 token 增量返回。流式模式对 TTFT（首 token 延迟）敏感的交互场景至关重要——用户在第一个 token 到达时就能看到输出，而不必等整段生成完。
</Note>

此外，你也可以轻松地在 SGLang 离线引擎之上构建自定义服务端。一个可在 Python 脚本中直接运行的详细示例见 [custom_server](https://github.com/sgl-project/sglang/blob/main/examples/runtime/engine/custom_server.py)。

## Nest Asyncio
注意，如果你想在 ipython 或其他嵌套事件循环的环境中使用**离线引擎**，需要添加以下代码：
```python Example
import nest_asyncio

nest_asyncio.apply()

```

<Note>
💡 AI Infra 学习笔记：Python 的 asyncio 是「单事件循环」模型——ipython/Jupyter 里已经有一个事件循环在运行，再调用 `asyncio.run()` 会因「循环已在运行」而报错。`nest_asyncio` 通过打补丁允许嵌套事件循环来绕过这个限制，这是异步推理客户端在交互式环境里的常见坑。
</Note>

## 离线批量推理

SGLang 离线引擎通过高效的调度支持批量推理。

```python Example
# launch the offline engine
import asyncio

import sglang as sgl
import sglang.test.doc_patch
from sglang.utils import async_stream_and_merge, stream_and_merge

llm = sgl.Engine(model_path="qwen/qwen2.5-0.5b-instruct")
```

<Note>
💡 AI Infra 学习笔记：离线引擎与在线服务化的核心区别在于是否走 HTTP 层。在线场景下引擎前面有 HTTP 入口、连续批处理调度器和流式输出；离线批量推理则直接以 Python 对象形式提交 prompt 列表，省去序列化与网络往返，适合评测、数据标注等对吞吐敏感的任务。两者底层共用同一套调度器与 CUDA 执行内核。
</Note>

### 非流式同步生成

```python Example
prompts = [
    "Hello, my name is",
    "The president of the United States is",
    "The capital of France is",
    "The future of AI is",
]

sampling_params = {"temperature": 0.8, "top_p": 0.95}

outputs = llm.generate(prompts, sampling_params)
for prompt, output in zip(prompts, outputs):
    print("===============================")
    print(f"Prompt: {prompt}\nGenerated text: {output['text']}")
```

### 流式同步生成

```python Example
prompts = [
    "Write a short, neutral self-introduction for a fictional character. Hello, my name is",
    "Provide a concise factual statement about France’s capital city. The capital of France is",
    "Explain possible future trends in artificial intelligence. The future of AI is",
]

sampling_params = {
    "temperature": 0.2,
    "top_p": 0.9,
}

print("\n=== Testing synchronous streaming generation with overlap removal ===\n")

for prompt in prompts:
    print(f"Prompt: {prompt}")
    merged_output = stream_and_merge(llm, prompt, sampling_params)
    print("Generated text:", merged_output)
    print()
```

### 非流式异步生成

```python Example
prompts = [
    "Write a short, neutral self-introduction for a fictional character. Hello, my name is",
    "Provide a concise factual statement about France’s capital city. The capital of France is",
    "Explain possible future trends in artificial intelligence. The future of AI is",
]

sampling_params = {"temperature": 0.8, "top_p": 0.95}

print("\n=== Testing asynchronous batch generation ===")

async def main():
    outputs = await llm.async_generate(prompts, sampling_params)

    for prompt, output in zip(prompts, outputs):
        print(f"\nPrompt: {prompt}")
        print(f"Generated text: {output['text']}")

asyncio.run(main())
```

### 流式异步生成

```python Example
prompts = [
    "Write a short, neutral self-introduction for a fictional character. Hello, my name is",
    "Provide a concise factual statement about France’s capital city. The capital of France is",
    "Explain possible future trends in artificial intelligence. The future of AI is",
]

sampling_params = {"temperature": 0.8, "top_p": 0.95}

print("\n=== Testing asynchronous streaming generation (no repeats) ===")

async def main():
    for prompt in prompts:
        print(f"\nPrompt: {prompt}")
        print("Generated text: ", end="", flush=True)

        # Replace direct calls to async_generate with our custom overlap-aware version
        async for cleaned_chunk in async_stream_and_merge(llm, prompt, sampling_params):
            print(cleaned_chunk, end="", flush=True)

        print()  # New line after each prompt

asyncio.run(main())
```
