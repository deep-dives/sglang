SGLang 提供兼容 OpenAI 的 API，帮助你从 OpenAI 服务平滑过渡到本地自托管模型。
完整的 API 参考见 [OpenAI API Reference](https://platform.openai.com/docs/guides/vision)。
本教程介绍视觉语言模型的视觉 API。

SGLang 支持多种视觉语言模型，如 Llama 3.2、LLaVA-OneVision、Qwen2.5-VL、Gemma3 以及[更多](../supported-models/multimodal_language_models)。

<Note>
💡 AI Infra 学习笔记：视觉语言模型（VLM）通常在文本 token 序列中插入「图像 token」——图片先经过独立的视觉编码器变成视觉特征，再映射成若干 token 与文本交错输入主干模型。图像 token 数量取决于分辨率与切块策略，会显著拉长 prefill 长度，这也是视觉输入下 TTFT 和显存占用比纯文本更高的原因之一。
</Note>

除了 OpenAI API，你也可以使用 [SGLang 离线引擎](https://github.com/sgl-project/sglang/blob/main/examples/runtime/engine/offline_batch_inference_vlm.py)。

## 启动服务端

在终端启动服务端并等待其初始化完成。

```python Example
from sglang.test.doc_patch import launch_server_cmd
from sglang.utils import wait_for_server, print_highlight, terminate_process

example_image_url = "https://raw.githubusercontent.com/sgl-project/sglang/main/examples/assets/example_image.png"
logo_image_url = (
    "https://raw.githubusercontent.com/sgl-project/sglang/main/assets/logo.png"
)

vision_process, port = launch_server_cmd("""
python3 -m sglang.launch_server --model-path Qwen/Qwen2.5-VL-7B-Instruct --log-level warning
""")

wait_for_server(f"http://localhost:{port}", process=vision_process)
```

## 使用 cURL

服务端就绪后，你可以用 curl 或 requests 发送测试请求。

```python Example
import subprocess

curl_command = f"""
curl -s http://localhost:{port}/v1/chat/completions \\
  -H "Content-Type: application/json" \\
  -d '{{
    "model": "Qwen/Qwen2.5-VL-7B-Instruct",
    "messages": [
      {{
        "role": "user",
        "content": [
          {{
            "type": "text",
            "text": "What’s in this image?"
          }},
          {{
            "type": "image_url",
            "image_url": {{
              "url": "{example_image_url}"
            }}
          }}
        ]
      }}
    ],
    "max_tokens": 300
  }}'
"""

response = subprocess.check_output(curl_command, shell=True).decode()
print_highlight(response)


response = subprocess.check_output(curl_command, shell=True).decode()
print_highlight(response)
```

## 使用 Python requests

```python Example
import requests

url = f"http://localhost:{port}/v1/chat/completions"

data = {
    "model": "Qwen/Qwen2.5-VL-7B-Instruct",
    "messages": [
        {
            "role": "user",
            "content": [
                {"type": "text", "text": "What’s in this image?"},
                {
                    "type": "image_url",
                    "image_url": {"url": example_image_url},
                },
            ],
        }
    ],
    "max_tokens": 300,
}

response = requests.post(url, json=data)
print_highlight(response.text)
```

## 使用 OpenAI Python 客户端

```python Example
from openai import OpenAI

client = OpenAI(base_url=f"http://localhost:{port}/v1", api_key="None")

response = client.chat.completions.create(
    model="Qwen/Qwen2.5-VL-7B-Instruct",
    messages=[
        {
            "role": "user",
            "content": [
                {
                    "type": "text",
                    "text": "What is in this image?",
                },
                {
                    "type": "image_url",
                    "image_url": {"url": example_image_url},
                },
            ],
        }
    ],
    max_tokens=300,
)

print_highlight(response.choices[0].message.content)
```

## 多图输入

如果模型支持，服务端也支持多张图片以及文本与图片交错输入。

<Note>
💡 AI Infra 学习笔记：多图/图文交错的关键在于模型是否支持「交错序列」，以及多张图在长度限制内如何摆放——这取决于模型训练时的数据形式，不是推理引擎单方面能决定的；引擎层面主要影响多图时的 KV 缓存与 prefill 调度开销。
</Note>

```python Example
from openai import OpenAI

client = OpenAI(base_url=f"http://localhost:{port}/v1", api_key="None")

response = client.chat.completions.create(
    model="Qwen/Qwen2.5-VL-7B-Instruct",
    messages=[
        {
            "role": "user",
            "content": [
                {
                    "type": "image_url",
                    "image_url": {
                        "url": example_image_url,
                    },
                },
                {
                    "type": "image_url",
                    "image_url": {
                        "url": logo_image_url,
                    },
                },
                {
                    "type": "text",
                    "text": "I have two very different images. They are not related at all. "
                    "Please describe the first image in one sentence, and then describe the second image in another sentence.",
                },
            ],
        }
    ],
    temperature=0,
)

print_highlight(response.choices[0].message.content)
```
