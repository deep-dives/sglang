SGLang 提供 Ollama API 兼容性，让你可以把 Ollama CLI 和 Python 库与 SGLang 一起使用，以 SGLang 作为推理后端。

<Note>
💡 AI Infra 学习笔记：Ollama 兼容的本质同样是「协议翻译」——SGLang 在服务端实现 Ollama 的 `/api/chat`、`/api/generate` 等路由，把 Ollama 客户端的请求映射到自己的引擎。这样用户可以沿用熟悉的 Ollama 工具链（CLI、库、生态脚本）享受 SGLang 的高性能，而无需改代码。
</Note>

## 前置条件

<CodeGroup>
```bash Command
# Install the Ollama Python library (for Python client usage)
pip install ollama
```
</CodeGroup>

<Note>你不需要安装 Ollama 服务端——SGLang 充当后端。你只需要 `ollama` CLI 或 Python 库作为客户端。</Note>

## 快速开始

### 1. 启动 SGLang 服务端

<CodeGroup>
```bash Command
python -m sglang.launch_server \
    --model Qwen/Qwen2.5-1.5B-Instruct \
    --port 30001 \
    --host 0.0.0.0
```
</CodeGroup>

<Note>`ollama run` 使用的模型名必须与你传给 `--model` 的完全一致。</Note>

### 2. 使用 Ollama CLI

<CodeGroup>
```bash Command
# List available models
OLLAMA_HOST=http://localhost:30001 ollama list

# Interactive chat
OLLAMA_HOST=http://localhost:30001 ollama run "Qwen/Qwen2.5-1.5B-Instruct"
```
</CodeGroup>

如果连接的是防火墙后面的远程服务端：

<CodeGroup>
```bash Command
# SSH tunnel
ssh -L 30001:localhost:30001 user@gpu-server -N &

# Then use Ollama CLI as above
OLLAMA_HOST=http://localhost:30001 ollama list
```
</CodeGroup>

### 3. 使用 Ollama Python 库

```python Example
import ollama

client = ollama.Client(host='http://localhost:30001')

# Non-streaming
response = client.chat(
    model='Qwen/Qwen2.5-1.5B-Instruct',
    messages=[{'role': 'user', 'content': 'Hello!'}]
)
print(response['message']['content'])

# Streaming
stream = client.chat(
    model='Qwen/Qwen2.5-1.5B-Instruct',
    messages=[{'role': 'user', 'content': 'Tell me a story'}],
    stream=True
)
for chunk in stream:
    print(chunk['message']['content'], end='', flush=True)
```

## 智能路由（Smart Router）

想用 LLM 判断器在本地 Ollama（快）与远程 SGLang（强）之间做智能路由，请参见 [Smart Router 文档](https://github.com/sgl-project/sglang/blob/main/python/sglang/srt/entrypoints/ollama/README.md)。

<Note>
💡 AI Infra 学习笔记：智能路由（LLM-as-judge）是典型的「延迟/质量权衡」方案——简单查询交给本地小模型（低延迟、低成本），复杂查询才路由到远程强模型。对 AI Infra 学习者来说，这是理解「模型分级 / 多后端调度」与成本优化的入门场景。
</Note>
