## 1. 模型介绍

[Kimi-K2.6](https://huggingface.co/moonshotai/Kimi-K2.6) 是 Moonshot AI 开源的、原生多模态智能体模型，在代码编写、长时执行（long-horizon execution）和智能体集群（agent swarm）方面处于行业领先水平。在关键基准上，它与 GPT-5.4、Claude Opus 4.6、Gemini 3.1 Pro 相当甚至更优。

<Note>
💡 AI Infra 学习笔记：Kimi-K2.6 这类「超长上下文 + 长时智能体」负载，是推理引擎内存优化的压力测试。思考型模型会在给出答案前产生数千甚至数万 token 的推理内容，KV 缓存随之线性膨胀；多轮智能体任务则会让同一段历史被反复处理。应对手段通常包括：前缀缓存（prefix caching）/Radix 缓存复用相同前缀的 KV、KV 缓存量化（FP8）、分块预填充（chunked prefill）降低峰值显存，以及必要时的前缀重计算。这些正是超长上下文服务优化的核心。
</Note>

**核心特性：**

- **长时编码**：擅长复杂的端到端编码任务，可连续执行 13 小时以上、修改 4000+ 行代码，并横跨多种语言（Rust、Go、Python）与任务类型（前端、DevOps、性能优化）。
- **编码驱动的设计**：能把提示词和视觉输入转化为可直接上线的界面，包含 WebGL 着色器、GSAP + Framer Motion、Three.js 3D 等丰富的动效元素。
- **进阶智能体集群**：单次运行可扩展到 300 个并行子智能体、执行 4000 步协调动作。一条提示词，产出 100+ 文件。
- **主动式智能体**：为 OpenClaw、Hermes Agent 等自主框架提供动力，可连续运行 5 天。
- **原生多模态**：在视觉-语言 token 上预训练，配合 MoonViT（4 亿参数）实现视觉理解、跨模态推理以及基于视觉输入的智能体工具调用。

### 3.2 配置要点

- **显存**：需要单卡显存 ≥140GB 的 GPU。原生 INT4 检查点支持 H200（8 卡，TP=8）、B300（8 卡，TP=8）、GB300（4 卡，TP=4）、MI300X/MI325X（4 卡，TP=4）、MI350X/MI355X（4 卡，TP=4）。用 `--context-length 128000` 节省显存。
- **NVFP4**：在 NVIDIA Blackwell 上，用 `nvidia/Kimi-K2.6-NVFP4` 并加 `--quantization modelopt_fp4`。B300 用 `tp=8`，GB300 用 `tp=4`。
- **AMD GPU 的 TP 限制**：在 AMD GPU 上，TP 必须 ≤ 4（不能是 8）。Kimi-K2.6 有 64 个注意力头；AITER MLA kernel 要求 `heads_per_gpu % 16 == 0`。TP=4 时每卡分到 16 个头（合法），TP=8 时每卡 8 个头（不合法）。
- **AMD Docker 镜像**：MI350X/MI355X 用 `lmsysorg/sglang:v0.5.9-rocm700-mi35x`，MI300X/MI325X 用 `lmsysorg/sglang:v0.5.9-rocm700-mi30x`。
- **DP Attention**：生产环境用 `--dp <N> --enable-dp-attention` 提升吞吐。常见做法是把 `--dp` 设成与 `--tp` 相同，但并非必须。
- **推理解析器**：加上 `--reasoning-parser kimi_k2`，把模型输出中的思考过程与回答内容分开。
- **工具调用解析器**：加上 `--tool-call-parser kimi_k2` 以支持结构化工具调用。
- **AMD FP8 KV 缓存**：在 AMD 平台上，生成器默认会加上 `--kv-cache-dtype fp8_e4m3`，并把 `--mem-fraction-static` 设为 0.8，以便把 INT4 权重和 KV 缓存都装进显存。FP8 KV 缓存用少量精度换取显存；如果发现你的负载精度下降，就去掉该参数。

<Note>
💡 AI Infra 学习笔记：部署时的显存本质是「权重 + KV 缓存」的分配博弈。权重是固定的（INT4 等量化可显著缩小），KV 缓存则随并发和上下文长度动态增长，由 `--mem-fraction-static` 控制静态内存预留比例；`--context-length` 直接设定单请求上下文的硬上限。调这几个参数，就是在吞吐（能塞进多少并发请求）与长上下文支持之间权衡——这也是部署显存分析题的常见考点。
</Note>

#### 4.2.2 推理输出

Kimi-K2.6 同时支持思考模式（默认）和即时模式。

**思考模式（默认）**——推理内容会自动分离：

```python Example
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:30000/v1",
    api_key="EMPTY"
)

response = client.chat.completions.create(
    model="moonshotai/Kimi-K2.6",
    messages=[
        {"role": "user", "content": "Which one is bigger, 9.11 or 9.9? Think carefully."}
    ]
)

print("====== Reasoning Content (Thinking Mode) ======")
print(response.choices[0].message.reasoning_content)
print("====== Response (Thinking Mode) ======")
print(response.choices[0].message.content)
```

**即时模式（关闭思考）**——关闭思考以获得更快的响应：

```python Example
response = client.chat.completions.create(
    model="moonshotai/Kimi-K2.6",
    messages=[
        {"role": "user", "content": "Which one is bigger, 9.11 or 9.9? Think carefully."}
    ],
    extra_body={"chat_template_kwargs": {"thinking": False}}
)

print("====== Response (Instant Mode) ======")
print(response.choices[0].message.content)
```

#### 4.2.3 工具调用

Kimi-K2.6 支持工具调用，可用于智能体任务：

```python Example
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:30000/v1",
    api_key="EMPTY"
)

# Define available tools
tools = [
    {
        "type": "function",
        "function": {
            "name": "get_weather",
            "description": "Get the current weather for a location",
            "parameters": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city name"
                    },
                    "unit": {
                        "type": "string",
                        "enum": ["celsius", "fahrenheit"],
                        "description": "Temperature unit"
                    }
                },
                "required": ["location"]
            }
        }
    }
]

response = client.chat.completions.create(
    model="moonshotai/Kimi-K2.6",
    messages=[
        {"role": "user", "content": "What's the weather in Beijing?"}
    ],
    tools=tools,
    stream=True
)

# Process streaming response
tool_calls_accumulator = {}

for chunk in response:
    if chunk.choices and len(chunk.choices) > 0:
        delta = chunk.choices[0].delta

        if hasattr(delta, 'tool_calls') and delta.tool_calls:
            for tool_call in delta.tool_calls:
                index = tool_call.index
                if index not in tool_calls_accumulator:
                    tool_calls_accumulator[index] = {'name': None, 'arguments': ''}
                if tool_call.function:
                    if tool_call.function.name:
                        tool_calls_accumulator[index]['name'] = tool_call.function.name
                    if tool_call.function.arguments:
                        tool_calls_accumulator[index]['arguments'] += tool_call.function.arguments

        if delta.content:
            print(delta.content, end="", flush=True)

for index, tool_call in sorted(tool_calls_accumulator.items()):
    print(f"Tool Call: {tool_call['name']}")
    print(f"  Arguments: {tool_call['arguments']}")
```

**输出示例：**

```text Output
Tool Call: get_weather
  Arguments: {"location": "Beijing"}
```

**处理工具调用结果：**

```python Example
# Send tool result back to the model
messages = [
    {"role": "user", "content": "What's the weather in Beijing?"},
    {
        "role": "assistant",

```

```text Output
It's a nice, warm day there—great for being outdoors!
```

#### 4.2.4 多模态 + 工具调用（智能体视觉）

把视觉理解与工具调用结合起来，完成进阶的智能体任务：

```python Example
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:30000/v1",
    api_key="EMPTY"
)

tools = [
    {
        "type": "function",
        "function": {
            "name": "search_product",
            "description": "Search for a product by name or description",
            "parameters": {
                "type": "object",
                "properties": {
                    "query": {
                        "type": "string",
                        "description": "The product name or description to search for"
                    }
                },
                "required": ["query"]
            }
        }
    }
]

response = client.chat.completions.create(
    model="moonshotai/Kimi-K2.6",
    messages=[
        {
            "role": "user",
            "content": [
                {
                    "type": "image_url",
                    "image_url": {
                        "url": "https://ofasys-multimodal-wlcb-3-toshanghai.oss-accelerate.aliyuncs.com/wpf272043/keepme/image/receipt.png"
                    }
                },
                {
                    "type": "text",
                    "text": "Can you identify this product and search for similar items?"
                }
            ]
        }
    ],
    tools=tools
)

msg = response.choices[0].message

# Print reasoning process
if msg.reasoning_content:
    print("=== Reasoning ===")
    print(msg.reasoning_content)

# Print response content
if msg.content:
    print("=== Content ===")
    print(msg.content)

# Print tool calls
if msg.tool_calls:
    print("=== Tool Calls ===")
    for tc in msg.tool_calls:
        print(f"  Function: {tc.function.name}")
        print(f"  Arguments: {tc.function.arguments}")
```
