## 1. 模型介绍

[Kimi-K2.5](https://huggingface.co/moonshotai/Kimi-K2.5) 是 Moonshot AI 开源的、原生多模态智能体模型，在 Kimi-K2-Base 基础上，用约 15 万亿混合视觉与文本 token 持续预训练而成。它把视觉与语言理解无缝融合，并具备进阶的智能体能力，支持即时（instant）与思考（thinking）两种模式。

<Note>
💡 AI Infra 学习笔记：Kimi-K2.5 是「大规模 MoE + 超长上下文 + 多模态」的代表。多模态意味着输入里除了文本还有图像，视觉 token 数量往往远超文本，会显著放大预填充（prefill）阶段的计算和 KV 缓存开销；同时它又支持投机解码（speculative decoding）来压低单 token 延迟。推理引擎的优化点通常集中在这几处：分块预填充、KV 缓存量化、以及 EAGLE 这类草稿模型方案。
</Note>

**核心特性：**

- **原生多模态**：K2.5 在视觉-语言 token 上预训练，在视觉知识、跨模态推理以及基于视觉输入的智能体工具调用方面表现出色。
- **看得见的编程**：K2.5 能根据视觉规格（UI 设计稿、视频工作流）生成代码，并自主编排工具处理视觉数据。
- **智能体集群（Agent Swarm）**：K2.5 从单个智能体的扩展，转向自主、协调的集群式执行方案——把复杂任务拆解成并行的子任务，由动态实例化的领域专用智能体分别执行。
- **投机解码**：支持基于 EAGLE 的投机解码，降低延迟。

**可用模型**：
- INT4（初始发布版）：[moonshotai/Kimi-K2.5](https://huggingface.co/moonshotai/Kimi-K2.5)
- NVFP4（4 位量化版）：[nvidia/Kimi-K2.5-NVFP4](https://huggingface.co/nvidia/Kimi-K2.5-NVFP4)

更多细节见[官方文档](https://huggingface.co/moonshotai/Kimi-K2.5)和[部署指南](https://huggingface.co/moonshotai/Kimi-K2.5/blob/main/docs/deploy_guidance.md)。

### 3.2 配置要点

- **显存**：需要单卡显存 ≥140GB 的 GPU。支持平台：H200（8 卡，TP=8）、B300（8 卡，TP=8）、GB300（4 卡，TP=4）、MI300X/MI325X（4 卡，TP=4）、MI350X/MI355X（4 卡，TP=4）。用 `--context-length 128000` 节省显存。
- **AMD GPU 的 TP 限制**：在 AMD GPU 上，TP 必须 ≤4（不能是 8）。Kimi-K2.5 有 64 个注意力头；AITER MLA kernel 要求 `heads_per_gpu % 16 == 0`。TP=4 时每卡分到 16 个头（合法），TP=8 时每卡 8 个头（不合法）。
- **AMD Docker 镜像**：MI350X/MI355X 用 `lmsysorg/sglang:v0.5.9-rocm700-mi35x`，MI300X/MI325X 用 `lmsysorg/sglang:v0.5.9-rocm700-mi30x`。ROCm 7.2 镜像（`rocm720`）存在 AITER 兼容性问题。
- **DP Attention**：生产环境用 `--dp <N> --enable-dp-attention` 提升吞吐。常见做法是把 `--dp` 设成与 `--tp` 相同，但并非必须。
- **推理解析器**：加上 `--reasoning-parser kimi_k2`，把模型输出中的思考过程与回答内容分开。
- **工具调用解析器**：加上 `--tool-call-parser kimi_k2` 以支持结构化工具调用。

#### 4.2.2 推理输出

Kimi-K2.5 同时支持思考模式（默认）和即时模式。

**思考模式（默认）**——推理内容会自动分离：

```python Example
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:30000/v1",
    api_key="EMPTY"
)

response = client.chat.completions.create(
    model="moonshotai/Kimi-K2.5",
    messages=[
        {"role": "user", "content": "Which one is bigger, 9.11 or 9.9? Think carefully."}
    ]
)

print("====== Reasoning Content (Thinking Mode) ======")
print(response.choices[0].message.reasoning_content)
print("====== Response (Thinking Mode) ======")
print(response.choices[0].message.content)
```

**即时模式（关闭思考）**——关闭思考以获得更快的响应：

```python Example
response = client.chat.completions.create(
    model="moonshotai/Kimi-K2.5",
    messages=[
        {"role": "user", "content": "Which one is bigger, 9.11 or 9.9? Think carefully."}
    ],
    extra_body={"chat_template_kwargs": {"thinking": False}}
)

print("====== Response (Instant Mode) ======")
print(response.choices[0].message.content)
```

#### 4.2.3 工具调用

Kimi-K2.5 支持工具调用，可用于智能体任务：

```python Example
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:30000/v1",
    api_key="EMPTY"
)

# Define available tools
tools = [
    {
        "type": "function",
        "function": {
            "name": "get_weather",
            "description": "Get the current weather for a location",
            "parameters": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city name"
                    },
                    "unit": {
                        "type": "string",
                        "enum": ["celsius", "fahrenheit"],
                        "description": "Temperature unit"
                    }
                },
                "required": ["location"]
            }
        }
    }
]

response = client.chat.completions.create(
    model="moonshotai/Kimi-K2.5",
    messages=[
        {"role": "user", "content": "What's the weather in Beijing?"}
    ],
    tools=tools,
    stream=True
)

# Process streaming response
tool_calls_accumulator = {}

for chunk in response:
    if chunk.choices and len(chunk.choices) > 0:
        delta = chunk.choices[0].delta

        if hasattr(delta, 'tool_calls') and delta.tool_calls:
            for tool_call in delta.tool_calls:
                index = tool_call.index
                if index not in tool_calls_accumulator:
                    tool_calls_accumulator[index] = {'name': None, 'arguments': ''}
                if tool_call.function:
                    if tool_call.function.name:
                        tool_calls_accumulator[index]['name'] = tool_call.function.name
                    if tool_call.function.arguments:
                        tool_calls_accumulator[index]['arguments'] += tool_call.function.arguments

        if delta.content:
            print(delta.content, end="", flush=True)

for index, tool_call in sorted(tool_calls_accumulator.items()):
    print(f"Tool Call: {tool_call['name']}")
    print(f"  Arguments: {tool_call['arguments']}")
```

**输出示例：**

```text Output
Tool Call: get_weather
  Arguments: {"location": "Beijing"}
```

**处理工具调用结果：**

```python Example
# Send tool result back to the model
messages = [
    {"role": "user", "content": "What's the weather in Beijing?"},
    {
        "role": "assistant",
        "content": None,
        "tool_calls": [{
            "id": "call_123",
            "type": "function",
            "function": {
                "name": "get_weather",
                "arguments": '{"location": "Beijing", "unit": "celsius"}'
            }
        }]
    },
    {
        "role": "tool",
        "tool_call_id": "call_123",
        "content": "The weather in Beijing is 22°C and sunny."
    }
]

final_response = client.chat.completions.create(
    model="moonshotai/Kimi-K2.5",
    messages=messages
)

print(final_response.choices[0].message.content)
```

**输出示例：**

```text Output
The weather in Beijing is **22°C and sunny**. ☀️

It's a nice day there with comfortable temperatures and clear skies!
```

#### 4.2.4 多模态 + 工具调用（智能体视觉）

把视觉理解与工具调用结合起来，完成进阶的智能体任务：

```python Example
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:30000/v1",
    api_key="EMPTY"
)

tools = [
    {
        "type": "function",
        "function": {
            "name": "search_product",
            "description": "Search for a product by name or description",
            "parameters": {
                "type": "object",
                "properties": {
                    "query": {
                        "type": "string",
                        "description": "The product name or description to search for"
                    }
                },
                "required": ["query"]
            }
        }
    }
]

response = client.chat.completions.create(
    model="moonshotai/Kimi-K2.5",
    messages=[
        {
            "role": "user",
            "content": [
                {
                    "type": "image_url",
                    "image_url": {
                        "url": "https://ofasys-multimodal-wlcb-3-toshanghai.oss-accelerate.aliyuncs.com/wpf272043/keepme/image/receipt.png"
                    }
                },
                {
                    "type": "text",
                    "text": "Can you identify this product and search for similar items?"
                }
            ]
        }
    ],
    tools=tools
)

msg = response.choices[0].message

# Print reasoning process
if msg.reasoning_content:
    print("=== Reasoning ===")
    print(msg.reasoning_content)

# Print response content
if msg.content:
    print("=== Content ===")
    print(msg.content)

# Print tool calls
if msg.tool_calls:
    print("=== Tool Calls ===")
    for tc in msg.tool_calls:
        print(f"  Function: {tc.function.name}")
        print(f"  Arguments: {tc.function.arguments}")
```

**输出示例：**

```text Output

The user is asking me to identify a product from a receipt and search for similar items.
Looking at the receipt, I can see:

 2. The product purchased is "CINNAMON SUGAR"
 3. Price is 17,000 (likely Indonesian Rupiah based on "CASH IDR")
 4. Quantity is 1

So the product is a Cinnamon Sugar pretzel from Auntie Anne's.
Now I need to search for this product or similar items using the search_product function.
=== Content ===
I can see from the receipt that the product is a **Cinnamon Sugar** item from **Auntie Anne's** (the famous pretzel chain). This appears to be a Cinnamon Sugar Pretzel purchased for 17,000 IDR (Indonesian Rupiah).

Let me search for this product and similar items:
=== Tool Calls ===
  Function: search_product
  Arguments: {"query": "Auntie Anne's Cinnamon Sugar Pretzel"}
```

#### 4.2.5 投机解码

**NVIDIA**

用以下命令部署 Kimi-K2.5（H200/B300，开启全部特性）：

```shell Command
sglang serve \
  --model-path moonshotai/Kimi-K2.5 \
  --tp 8 \
  --reasoning-parser kimi_k2 \
  --tool-call-parser kimi_k2 \
  --speculative-algorithm=EAGLE3 \
  --speculative-num-steps 3 \
  --speculative-eagle-topk 1 \
  --speculative-num-draft-tokens 4 \
  --speculative-draft-model-path lightseekorg/kimi-k2.5-eagle3-mla \
  --trust-remote-code \
  --host 0.0.0.0 \
  --port 30000
```

  --tool-call-parser kimi_k2 \
  --kv-cache-dtype fp8_e4m3 \

### 5.3 速度基准测试（AMD MI350X）

**测试环境：**

- 硬件：AMD Instinct MI350X GPU ×4
- 模型：Kimi-K2.5（BF16）
- 张量并行：4
- SGLang 版本：0.5.9
- Docker 镜像：`lmsysorg/sglang:v0.5.9-rocm700-mi35x`
- ROCm：7.0

我们用 SGLang 内置的基准测试工具配合 `random` 数据集做标准化性能评估。

:::info AMD GPU 的 TP 限制
在 AMD GPU 上，Kimi-K2.5 要求 TP ≤ 4。模型有 64 个注意力头，AITER MLA kernel 要求 `heads_per_gpu % 16 == 0`。TP=4 时每卡分到 16 个头（合法），TP=8 时每卡 8 个头（不合法）。
:::
