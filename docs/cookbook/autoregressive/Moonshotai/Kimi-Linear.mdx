## 1. 模型介绍
Kimi Linear 是一种混合线性注意力架构，在短上下文、长上下文以及强化学习（RL）扩展等多种场景下都优于传统的全注意力方法。其核心是 Kimi Delta Attention（KDA）——Gated DeltaNet 的精炼版本，引入更高效的门控机制，以优化有限状态 RNN 记忆的利用。

<Note>
💡 AI Infra 学习笔记：标准 Transformer 的注意力复杂度随序列长度二次增长，KV 缓存也随之线性膨胀；Mamba 类线性注意力则把历史压缩进一个固定大小的循环状态（不再缓存完整 KV），推理时每一步的成本恒定，因此长上下文下解码显著更快（这里号称最高 6×）。代价是「记忆」有损——于是就有了 KDA 与全局 MLA 按 3:1 混合的架构，用少量全注意力层兜住长程精度。推理引擎需要为这类模型单独管理循环状态内存，并配套专门的 kernel。
</Note>

这一代模型在各方面都带来了全面升级：

Kimi Delta Attention（KDA）：一种线性注意力机制，用细粒度门控改良了带门控的 delta 规则。
混合架构：KDA 与全局 MLA 按 3:1 混合，在保持甚至超过全注意力质量的同时降低显存占用。
性能更优：在多种任务上胜过全注意力，包括在 1.4T token 训练上的长上下文与 RL 类基准（做了公平对比）。
高吞吐：解码速度最高提升 6 倍，显著降低每输出 token 的时间（TPOT）。

更多细节请参考 [Kimi Linear 官方 GitHub 仓库]: https://github.com/MoonshotAI/Kimi-Linear

### 4.2 进阶用法

#### 4.2.1 启动 docker
```shell Command
docker pull lmsysorg/sglang:v0.5.7-rocm700-mi30x
```

```shell Command
docker run -d -it --ipc=host --network=host --privileged \
  --cap-add=CAP_SYS_ADMIN \
  --device=/dev/kfd --device=/dev/dri --device=/dev/mem \
  --group-add video --cap-add=SYS_PTRACE \
  --security-opt seccomp=unconfined \
  -v /:/work \
  -e SHELL=/bin/bash \
  --name Kimi-linear \
  lmsysorg/sglang:v0.5.7-rocm700-mi30x \
  /bin/bash
```

#### 4.2.2 进入 docker 后的安装步骤

```shell Command
pip install sentencepiece tiktoken
```

#### 4.2.3 启动服务
```shell Command
export SGLANG_ROCM_FUSED_DECODE_MLA=0

SGLANG_ROCM_FUSED_DECODE_MLA=0 python3 -m sglang.launch_server \
  --model-path moonshotai/Kimi-Linear-48B-A3B-Instruct \
  --tokenizer-path  moonshotai/Kimi-Linear-48B-A3B-Instruct \
  --tp 4 \
  --trust-remote-code
```
