## 1. 模型介绍

[Kimi-K2](https://moonshotai.github.io/Kimi-K2/) 是 Moonshot AI 推出的 SOTA 级 MoE 大语言模型，总参数 1T，激活参数仅 32B。

<Note>
💡 AI Infra 学习笔记：MoE（混合专家）架构的核心是「总参数很大、但每次推理只激活一部分专家」。Kimi-K2 总参数 1T、激活 32B，意味着权重占用的显存大，但单 token 的计算量只相当于 32B 稠密模型。推理引擎为此引入专家并行（EP）把不同专家分布到多卡上，配合路由器（router）动态选择专家——这也是 MoE 模型部署时的核心调优点。
</Note>

**模型版本：**

- **[Kimi-K2-Instruct](https://huggingface.co/moonshotai/Kimi-K2-Instruct)**：面向通用对话和智能体任务优化的后训练模型，兼容 vLLM、SGLang、KTransformers 和 TensorRT-LLM。
- **[Kimi-K2-Thinking](https://huggingface.co/moonshotai/Kimi-K2-Thinking)**：进阶思考模型，具备逐步推理和工具调用能力。原生 INT4 量化，支持 256k 上下文窗口，非常适合复杂推理和多步工具调用场景。
- **ROCm 支持**：可通过 SGLang 在 AMD MI300X GPU 上运行（已验证）。

更多细节见[官方文档](https://github.com/MoonshotAI/Kimi-K2)和[技术报告](https://www.arxiv.org/abs/2507.20534)。

### 3.2 配置要点

- **显存**：需要 8 张单卡显存 ≥140GB 的 GPU（H200/B200）。用 `--context-length 128000` 节省显存。
- **专家并行（EP）**：用 `--ep` 提升 MoE 吞吐，见 [EP 文档](../../../docs/advanced_features/expert_parallelism)。
- **数据并行（DP）**：生产环境可用 `--dp 4 --enable-dp-attention` 提升吞吐。
- **KV 缓存**：用 `--kv-cache-dtype fp8_e4m3` 可减少 50% 显存占用（CUDA 11.8+）。

<Note>
💡 AI Infra 学习笔记：KV 缓存是自回归解码阶段为每个请求缓存的键值张量，随上下文变长而线性增长，通常是部署时最大的显存开销之一。把它量化为 FP8（如 `--kv-cache-dtype fp8_e4m3`）能在几乎不影响精度的前提下把缓存显存减半；如果显存仍不够，还可以配合前缀缓存（prefix caching）和上下文长度上限来管理。KV 缓存也是推理引擎面试中的高频考点。
</Note>

- **推理解析器**：为 Kimi-K2-Thinking 加上 `--reasoning-parser kimi_k2`，把思考过程与回答内容分开。
- **工具调用解析器**：加上 `--tool-call-parser kimi_k2` 以支持结构化工具调用。
- **AMD GPU**：在 AMD GPU 上启动前，先设置环境变量 `SGLANG_ROCM_FUSED_DECODE_MLA=0`。

### 4.2 进阶用法

#### 4.2.1 推理解析器

为 Kimi-K2-Thinking 启用推理解析器：

```shell Command
python -m sglang.launch_server \
  --model moonshotai/Kimi-K2-Thinking \
  --reasoning-parser kimi_k2 \
  --tp 8 \
  --host 0.0.0.0 \
  --port 8000
```

**示例：**

```python Example
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8000/v1",
    api_key="EMPTY"
)

# Enable streaming to see the thinking process in real-time
response = client.chat.completions.create(
    model="moonshotai/Kimi-K2-Thinking",
    messages=[
        {"role": "user", "content": "Solve this problem step by step: What is 15% of 240?"}
    ],
    temperature=0.6,
    max_tokens=2048,
    stream=True
)

# Process the stream
has_thinking = False
has_answer = False
thinking_started = False

for chunk in response:
    if chunk.choices and len(chunk.choices) > 0:
        delta = chunk.choices[0].delta

        # Print thinking process
        if hasattr(delta, 'reasoning_content') and delta.reasoning_content:
            if not thinking_started:
                print("=============== Thinking =================", flush=True)
                thinking_started = True
            has_thinking = True
            print(delta.reasoning_content, end="", flush=True)

        # Print answer content
        if delta.content:
            # Close thinking section and add content header
            if has_thinking and not has_answer:
                print("\n=============== Content =================", flush=True)
                has_answer = True
            print(delta.content, end="", flush=True)

print()
```

#### 4.2.2 工具调用

Kimi-K2-Instruct 和 Kimi-K2-Thinking 都支持工具调用。部署时启用工具调用解析器：

**部署命令：**

```shell Command
python -m sglang.launch_server \
  --model moonshotai/Kimi-K2-Instruct \
  --tool-call-parser kimi_k2 \
  --tp 8 \
  --trust-remote-code \
  --host 0.0.0.0 \
  --port 8000
```

**Python 示例（含思考过程）：**

```python Example
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8000/v1",
    api_key="EMPTY"
)

# Define available tools
tools = [
    {
        "type": "function",
        "function": {
            "name": "get_weather",
            "description": "Get the current weather for a location",
            "parameters": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city name"
                    },
                    "unit": {
                        "type": "string",
                        "enum": ["celsius", "fahrenheit"],
                        "description": "Temperature unit"
                    }
                },
                "required": ["location"]
            }
        }
    }
]

# Make request with streaming to see thinking process
response = client.chat.completions.create(
    model="moonshotai/Kimi-K2-Thinking",
    messages=[
        {"role": "user", "content": "What's the weather in Beijing?"}
    ],
    tools=tools,
    temperature=0.7,
    stream=True
)

# Process streaming response
thinking_started = False
has_thinking = False
tool_calls_accumulator = {}

for chunk in response:
    if chunk.choices and len(chunk.choices) > 0:
        delta = chunk.choices[0].delta

        # Print thinking process
        if hasattr(delta, 'reasoning_content') and delta.reasoning_content:
            if not thinking_started:
                print("=============== Thinking =================", flush=True)
                thinking_started = True
            has_thinking = True
            print(delta.reasoning_content, end="", flush=True)

        # Accumulate tool calls
        if hasattr(delta, 'tool_calls') and delta.tool_calls:
            # Close thinking section if needed
            if has_thinking and thinking_started:
                print("\n=============== Content =================\n", flush=True)
                thinking_started = False

            for tool_call in delta.tool_calls:
                index = tool_call.index
                if index not in tool_calls_accumulator:
                    tool_calls_accumulator[index] = {
                        'name': None,
                        'arguments': ''
                    }

                if tool_call.function:
                    if tool_call.function.name:
                        tool_calls_accumulator[index]['name'] = tool_call.function.name
                    if tool_call.function.arguments:
                        tool_calls_accumulator[index]['arguments'] += tool_call.function.arguments

        # Print content
        if delta.content:
            print(delta.content, end="", flush=True)

# Print accumulated tool calls
for index, tool_call in sorted(tool_calls_accumulator.items()):
    print(f"🔧 Tool Call: {tool_call['name']}")
    print(f"   Arguments: {tool_call['arguments']}")

print()
```

**输出示例：**

```text Output
=============== Thinking =================
  The user is asking about the weather in Beijing. I need to use the get_weather function to retrieve this information. Beijing is a major city in China, so I should be able to get weather data for it. The location parameter is required, but the unit parameter is optional. Since the user didn't specify a temperature unit, I can just provide the location and let the function use its default. I'll check the weather in Beijing for you.
=============== Content =================

  🔧 Tool Call: get_weather
   Arguments: {"location":"Beijing"}
```

**注意：**

- 推理解析器会展示模型如何决定使用某个工具
- 工具调用会用函数名和参数明确标注
- 然后你可以执行该函数，把结果回传给模型继续对话

**处理工具调用结果：**

```python Example
# After getting the tool call, execute the function
def get_weather(location, unit="celsius"):
    # Your actual weather API call here
    return f"The weather in {location} is 22°{unit[0].upper()} and sunny."

# Send tool result back to the model
messages = [
    {"role": "user", "content": "What's the weather in Beijing?"},
    {
        "role": "assistant",
        "content": None,
        "tool_calls": [{
            "id": "call_123",
            "type": "function",
            "function": {
                "name": "get_weather",
                "arguments": '{"location": "Beijing", "unit": "celsius"}'
            }
        }]
    },
    {
        "role": "tool",
        "tool_call_id": "call_123",
        "content": get_weather("Beijing", "celsius")
    }
]

final_response = client.chat.completions.create(
    model="moonshotai/Kimi-K2-Thinking",
    messages=messages,
    temperature=0.7
)

print(final_response.choices[0].message.content)
# Output: "The weather in Beijing is currently 22°C and sunny."
```
