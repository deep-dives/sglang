## 1. 模型介绍

[Llama 4](https://github.com/meta-llama/llama-models/blob/main/models/llama4/MODEL_CARD.md) 是 Meta 最新一代开源大语言模型，性能处于行业领先水平。

SGLang 从 [v0.4.5](https://github.com/sgl-project/sglang/releases/tag/v0.4.5) 起就支持 Llama 4 Scout（109B）和 Llama 4 Maverick（400B）。

持续的优化进展记录在 [Roadmap](https://github.com/sgl-project/sglang/issues/5118) 中。

这一代模型在各方面都带来了全面升级：

能力出众的 Llama 4 Maverick 总参数约 400B、激活参数 17B，拥有 128 个专家。
高效的 Llama 4 Scout 总参数约 109B、激活参数同样为 17B，只用了 16 个专家。
两个模型都采用早期融合（early fusion）实现原生多模态，可同时处理文本和图像输入。Maverick 与 Scout 都在多达 40 万亿 token、覆盖 200 种语言的数据上训练（并针对 12 种语言做了专门的微调支持，包括阿拉伯语、西班牙语、德语和印地语）。

<Note>
💡 AI Infra 学习笔记：Llama 4 是典型的「MoE + 混合注意力」架构——Maverick 总参数约 400B、激活仅 17B，128 个专家；同时把局部注意力（SWA）与全局注意力层交错，让长上下文只对部分层做全量计算。对推理引擎而言，这带来两个优化点：一是 MoE 需要专家并行（EP）来分摊专家计算，二是 SWA 与全局注意力需要不同的 KV 缓存策略——只对全局层保留完整 KV、局部层按窗口截断，就能在超长上下文下大幅省显存。
</Note>

更多细节请参考官方 llama4 仓库：https://www.llama.com/models/llama-4/

### 3.2 配置要点

- **避免 OOM**：调低 `--context-length` 可避免 GPU 显存不足。推荐值：Scout 在 8×H100 上最高 1M、8×H200 上最高 2.5M；Maverick 在 8×H200 上无需设置 context-length。启用混合 KV 缓存后，Scout 在 8×H100 上可达 5M、8×H200 上可达 10M。
- **Attention 后端自动选择**：SGLang 会自动挑选最优后端。如需手动指定，用 `--attention-backend`：
  - Blackwell (B200/GB200)：`trtllm_mha`
  - Hopper (H100/H200)：`fa3`
  - AMD GPU：`aiter`
  - Intel XPU：`intel_xpu`
  - 其它：`triton`
- **对话模板**：对话补全任务加上 `--chat-template llama-4`。
- **多模态**：加上 `--enable-multimodal` 以支持图像输入。
- **混合 KV 缓存**：用 `--swa-full-tokens-ratio` 控制 SWA（局部注意力）层 KV token 与全注意力层 KV token 的比例（默认 0.8，范围 0–1）。

<Note>
💡 AI Infra 学习笔记：混合 KV 缓存正是为「局部注意力 + 全局注意力」混合的模型设计的。`--swa-full-tokens-ratio` 控制的是 SWA（局部注意力）层 KV 与全注意力层 KV 的比例：只给全局层存完整 KV、局部层用滑动窗口截断，缓存占用就能大幅下降——这也是 Scout 能在 8×H200 上把上下文推到 10M 的关键。理解这个比例的含义，就能理解这类参数为什么直接决定长上下文的显存上限。
</Note>

- **EAGLE 投机解码**：Llama 4 Scout 与 Maverick 均支持 EAGLE3 投机解码。用上方的交互式命令生成器启用。
- **Xeon CPU 服务配置**：请参考 [SGLang CPU 服务端文档](../../../docs/hardware-platforms/cpu_server#launch-of-the-serving-engine) 中「启动推理引擎」一节的 `Notes` 部分，了解参数如何配置，尤其是 TP（张量并行）和 NUMA 绑定的设置。

```bash Command
sglang serve \
  --model-path meta-llama/Llama-4-Scout-17B-16E-Instruct \
  --tp 8 \
  --context-length 1000000 \
  --trust-remote-code
```

### Llama-4-Maverick
8 卡部署命令：

```bash Command
sglang serve \
  --model-path meta-llama/Llama-4-Maverick-17B-128E-Instruct \
  --tp 8 \
  --trust-remote-code
```

#### 4.2.3 EAGLE 投机解码

SGLang 支持用 [EAGLE 投机解码](../../../docs/advanced_features/speculative_decoding) 服务 Llama 4 Maverick（400B）。用 EAGLE3 算法和 SGLang 的 EAGLE3 草稿模型启用：

```shell Command
python3 -m sglang.launch_server \
  --model-path meta-llama/Llama-4-Maverick-17B-128E-Instruct \
  --speculative-algorithm EAGLE3 \
  --speculative-draft-model-path lmsys/sglang-EAGLE3-Llama-4-Maverick-17B-128E-Instruct-v1 \
  --speculative-num-steps 3 \
  --speculative-eagle-topk 1 \
  --speculative-num-draft-tokens 4 \
  --trust-remote-code \
  --tp 8
```
