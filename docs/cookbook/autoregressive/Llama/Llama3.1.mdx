## 1. 模型介绍

Llama 3.1 是 Meta 于 2024 年 7 月发布的一系列预训练与指令微调生成模型，提供 8B、70B 和 405B 三种规模，其中 405B 是当时能力最强的完全开源模型。

<Note>
💡 AI Infra 学习笔记：Llama 系列是开源模型的行业基准，其几个关键架构决策影响了整个推理栈。分组查询注意力（GQA）让多个查询头共享同一组 KV，显著降低 KV 缓存占用；旋转位置编码（RoPE）把位置信息融入注意力打分，支持向更长上下文外推。理解这些结构，才能理解为什么不同模型在 KV 缓存、前缀缓存上的表现差异巨大——这也是推理引擎做内存优化时首先关注的模型侧因素。
</Note>

这些模型为所有人带来了开放智能，并有多项新特性与改进：

- **更强的通用智能**：在编码、SOTA 级工具使用以及整体推理能力上都有显著提升。
- **更长的上下文**：Llama 3.1 把上下文扩展到 128K token，提升摘要、代码推理等长上下文任务的表现。
- **工具使用**：Llama 3.1 经过训练可与搜索引擎、Python 解释器和数学引擎交互，零样本工具使用能力也有提升，能调用可能从未见过的工具。
- **多语言**：除英语外，Llama 3.1 还支持 7 种语言：法语、德语、印地语、意大利语、葡萄牙语、西班牙语和泰语。

更多细节请参考 [Llama 3.1 博客](https://ai.meta.com/blog/meta-llama-3-1/) 和 [Llama 3.1 模型卡](https://github.com/meta-llama/llama-models/blob/main/models/llama3_1/MODEL_CARD.md)。note

### 3.2 配置要点

**投机解码（NVIDIA GPU）：**

- 延迟敏感场景使用投机解码：
  - `--speculative-algorithm EAGLE3`：投机解码算法
  - `--speculative-num-steps 3`：投机校验轮数
  - `--speculative-eagle-topk 1`：草稿 token 的 Top-k 采样
  - `--speculative-num-draft-tokens 4`：每步的草稿 token 数
  - `--speculative-draft-model-path`：草稿模型权重的路径，可以是本地文件夹或 Hugging Face 仓库 ID，例如 [`yuhuili/EAGLE3-LLaMA3.1-Instruct-8B`](https://huggingface.co/yuhuili/EAGLE3-LLaMA3.1-Instruct-8B)。

<Note>
💡 AI Infra 学习笔记：投机解码（speculative decoding）的思路是先用一个轻量草稿模型快速生成多个候选 token，再用大模型一次性并行校验：接受则原来「一个前向只出一步」变成「一次前向出多步」。`--speculative-num-draft-tokens` 控制每步草稿数，`--speculative-num-steps` 控制校验轮数。它在延迟敏感场景能显著压低逐 token 延迟，代价是多占一份草稿模型的显存。
</Note>

**AMD GPU 部署：**

- **按硬件选择 TP**：MI355X（256GB 显存）支持比 MI300X/MI325X（192GB）更小的 TP 值
- **已验证的 TP 配置**：
  - MI300X/MI325X：405B BF16（TP=8）、405B FP8（TP=4）、70B/8B（TP=1）
  - MI355X：405B BF16（TP=4）、405B FP8（TP=2）、70B/8B（TP=1）
- **FP8 模型版本**：
  - 405B：用 Meta 官方的 `meta-llama/Llama-3.1-405B-Instruct-FP8`
  - 70B/8B：用 AMD 优化过的 `amd/Llama-3.1-{size}-Instruct-FP8-KV`
- **工具调用**：Instruct 模型用 `--tool-call-parser llama3` 启用

**Xeon CPU 部署：**

- 请参考 [SGLang CPU 服务端文档](../../../docs/hardware-platforms/cpu_server#launch-of-the-serving-engine) 中「启动推理引擎」一节的 `Notes` 部分，了解参数如何配置，尤其是 TP（张量并行）和 NUMA 绑定的设置。

def exponential_backoff_retry(url, method, retries=3, backoff_factor=1, max_delay=60):
    """
    Retry a request with exponential backoff.

    Args:

        retries (int): The number of retries to attempt. Defaults to 3.

        max_delay (int): The maximum delay to wait between retries in seconds. Defaults to 60.

    Returns:

    """

### 4.2 进阶用法

#### 4.2.1 工具调用

Llama 3 支持工具调用。先启用工具调用解析器启动服务端：

```shell Command
sglang serve \
  --model-path  Meta-Llama/Llama-3.1-405B-Instruct \
  --tool-call-parser llama3 \
  --tp 8
```

**Python 示例**

```python Example
from openai import OpenAI

client = OpenAI(api_key="None", base_url=f"http://0.0.0.0:8000/v1")

tools = [
    {
        "type": "function",
        "function": {
            "name": "get_weather",
            "description": "Get the weather in a given location",
            "parameters": {
                "type": "object",
                "properties": {
                    "city": {
                        "type": "string",
                        "description": "The city to find the weather for, e.g. 'San Francisco'",
                    },
                    "unit": {
                        "type": "string",
                        "description": "The unit to fetch the temperature in",
                        "enum": ["celsius", "fahrenheit"],
                    },
                },
                "required": ["city", "unit"],
            },
        },
    }
]

response = client.chat.completions.create(
    model="meta-llama/Llama-3.1-405B-Instruct",
    messages=[
        {
            "role": "user",
            "content": "What's the weather like in Boston today?",
        }
    ],
    temperature=0.7,
    stream=True,
    tools=tools,
)


arguments = []

tool_calls_accumulator = {}

for chunk in response:
    if chunk.choices and len(chunk.choices) > 0:
        delta = chunk.choices[0].delta

        if hasattr(delta, 'tool_calls') and delta.tool_calls:
            for tool_call in delta.tool_calls:
                index = tool_call.index
                if index not in tool_calls_accumulator:
                    tool_calls_accumulator[index] = {
                        'name': None,
                        'arguments': ''
                    }

                if tool_call.function:
                    if tool_call.function.name:
                        tool_calls_accumulator[index]['name'] = tool_call.function.name
                    if tool_call.function.arguments:
                        tool_calls_accumulator[index]['arguments'] += tool_call.function.arguments

        # Print content
        if delta.content:
            print(delta.content, end="", flush=True)

# Print accumulated tool calls
for index, tool_call in sorted(tool_calls_accumulator.items()):
    print(f"🔧 Tool Call: {tool_call['name']}")
    print(f"   Arguments: {tool_call['arguments']}")

print()
```

def get_weather(location, unit="celsius"):

# Send tool result back to the model
messages = [
    {"role": "user", "content": "What's the weather like in Boston today?"},
