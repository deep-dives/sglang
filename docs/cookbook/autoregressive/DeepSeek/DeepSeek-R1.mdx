## 1. 模型介绍

[DeepSeek-R1](https://github.com/deepseek-ai/DeepSeek-R1) 是 DeepSeek 的高级推理模型，将强大的语言理解与逐步推理能力相结合。该模型提供针对不同硬件平台优化的多种量化格式。

**核心特性：**

- **高级推理**：内建的推理能力，适用于复杂问题求解
- **多种量化格式**：FP8 与 FP4 变体，应对不同的性能/显存取舍
- **硬件优化**：专门针对 NVIDIA B200（Blackwell）与 H200（Hopper）GPU、AMD MI300X、MI325X、MI355X GPU 以及 Intel Xeon CPU 调优
- **高性能**：同时针对吞吐量与延迟场景优化

**可用模型：**

- **FP8（8 位量化）**：[deepseek-ai/DeepSeek-R1-0528](https://huggingface.co/deepseek-ai/DeepSeek-R1-0528) - 推荐用于 H200 与 MI300X
- **FP4（4 位量化）**：[nvidia/DeepSeek-R1-0528-FP4-v2](https://huggingface.co/nvidia/DeepSeek-R1-0528-FP4-v2) - 推荐用于 B200 与 MI355X
- **BF16（由 FP8 提升）**：[unsloth/DeepSeek-R1-0528-BF16](https://huggingface.co/unsloth/DeepSeek-R1-0528-BF16)
- **INT8（通道级）**：[meituan/DeepSeek-R1-Channel-INT8](https://huggingface.co/meituan/DeepSeek-R1-Channel-INT8)
- **W4A8**：[novita/Deepseek-R1-0528-W4AFP8](https://huggingface.co/novita/Deepseek-R1-0528-W4AFP8)
- **AWQ（4 位）**：[QuixiAI/DeepSeek-R1-0528-AWQ](https://huggingface.co/QuixiAI/DeepSeek-R1-0528-AWQ)
- **MXFP4**：[amd/DeepSeek-R1-MXFP4](https://huggingface.co/amd/DeepSeek-R1-MXFP4)

**许可协议：**
使用 DeepSeek-R1 需要同意 DeepSeek 社区许可协议。详见 [LICENSE](https://huggingface.co/deepseek-ai/DeepSeek-R1-0528/blob/main/LICENSE)。

更多细节请参考[官方 DeepSeek-R1 仓库](https://github.com/deepseek-ai/DeepSeek-R1)。

**数据并行注意力（`--enable-dp-attention`）：** 推荐用于高吞吐场景。在单节点 8 卡上用 `--enable-dp-attention --tp 8 --dp 8`。

### 4.2 高级用法

#### 4.2.1 推理解析器

DeepSeek-R1 支持内建思考过程的高级推理能力。部署时启用推理解析器，可把思考与内容部分分开：

```shell Command
python -m sglang.launch_server \
  --model-path deepseek-ai/DeepSeek-R1-0528 \
  --reasoning-parser deepseek-r1 \
  --tp 8
```

**带思考过程的流式输出：**

```python Example
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:30000/v1",
    api_key="EMPTY"
)

# Enable streaming to see the thinking process in real-time
response = client.chat.completions.create(
    model="deepseek-ai/DeepSeek-R1-0528",
    messages=[
        {"role": "user", "content": "Solve this problem step by step: What is 15% of 240?"}
    ],
    temperature=0.7,
    max_tokens=2048,
    stream=True
)

# Process the stream
has_thinking = False
has_answer = False
thinking_started = False

for chunk in response:
    if chunk.choices and len(chunk.choices) > 0:
        delta = chunk.choices[0].delta

        # Print thinking process
        if hasattr(delta, 'reasoning_content') and delta.reasoning_content:
            if not thinking_started:
                print("=============== Thinking =================", flush=True)
                thinking_started = True
            has_thinking = True
            print(delta.reasoning_content, end="", flush=True)

        # Print answer content
        if delta.content:
            # Close thinking section and add content header
            if has_thinking and not has_answer:
                print("\n=============== Content =================", flush=True)
                has_answer = True
            print(delta.content, end="", flush=True)

print()
```

**输出示例：**

```text Output
=============== Thinking =================
To solve this problem, I need to calculate 15% of 240.
Step 1: Convert 15% to decimal: 15% = 0.15
Step 2: Multiply 240 by 0.15
Step 3: 240 × 0.15 = 36
=============== Content =================

The answer is 36. To find 15% of 240, we multiply 240 by 0.15, which equals 36.
```

**注意：** 推理解析器会捕获模型的逐步思考过程，让你看到模型是如何得出结论的。

#### 4.2.2 工具调用

DeepSeek-R1 支持工具调用能力。启用工具调用解析器：

```shell Command
python -m sglang.launch_server \
  --model-path deepseek-ai/DeepSeek-R1-0528 \
  --reasoning-parser deepseek-r1 \
  --tool-call-parser deepseekv3 \
  --chat-template examples/chat_template/tool_chat_template_deepseekr1.jinja \
  --tp 8
```

**Python 示例（带思考过程）：**

```python Example
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:30000/v1",
    api_key="EMPTY"
)

# Define available tools
tools = [
    {
        "type": "function",
        "function": {
            "name": "get_weather",
            "description": "Get the current weather for a location",
            "parameters": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city name"
                    },
                    "unit": {
                        "type": "string",
                        "enum": ["celsius", "fahrenheit"],
                        "description": "Temperature unit"
                    }
                },
                "required": ["location"]
            }
        }
    }
]

# Make request with streaming to see thinking process
response = client.chat.completions.create(
    model="deepseek-ai/DeepSeek-R1-0528",
    messages=[
        {"role": "user", "content": "What's the weather in Beijing?"}
    ],
    tools=tools,
    temperature=0.7,
    stream=True
)

# Process streaming response
thinking_started = False
has_thinking = False

for chunk in response:
    if chunk.choices and len(chunk.choices) > 0:
        delta = chunk.choices[0].delta

        # Print thinking process
        if hasattr(delta, 'reasoning_content') and delta.reasoning_content:
            if not thinking_started:
                print("=============== Thinking =================", flush=True)
                thinking_started = True
            has_thinking = True
            print(delta.reasoning_content, end="", flush=True)

        # Print tool calls
        if hasattr(delta, 'tool_calls') and delta.tool_calls:
            # Close thinking section if needed
            if has_thinking and thinking_started:
                print("\n=============== Content =================", flush=True)
                thinking_started = False

            for tool_call in delta.tool_calls:
                if tool_call.function:
                    print(f"🔧 Tool Call: {tool_call.function.name}")
                    print(f"   Arguments: {tool_call.function.arguments}")

        # Print content
        if delta.content:
            print(delta.content, end="", flush=True)

print()
```

**输出示例：**

```text Output
=============== Thinking =================
The user is asking about the weather in Beijing. I need to use the get_weather function to retrieve this information.
I should call the function with location="Beijing".
=============== Content =================

🔧 Tool Call: get_weather
   Arguments:
🔧 Tool Call: None
   Arguments: {"location": "Beijing"}
```

**注意：**

- 推理解析器会展示模型如何决定使用工具
- 工具调用会用函数名与参数清晰地标出
- 之后你可以执行该函数并把结果返回给模型以继续对话

**处理工具调用结果：**

```python Example
# After getting the tool call, execute the function
def get_weather(location, unit="celsius"):
    # Your actual weather API call here
    return f"The weather in {location} is 22°{unit[0].upper()} and sunny."

# Send tool result back to the model
messages = [
    {"role": "user", "content": "What's the weather in Beijing?"},
    {
        "role": "assistant",
        "content": None,
        "tool_calls": [{
            "id": "call_123",
            "type": "function",
            "function": {
                "name": "get_weather",
                "arguments": '{"location": "Beijing", "unit": "celsius"}'
            }
        }]
    },
    {
        "role": "tool",
        "tool_call_id": "call_123",
        "content": get_weather("Beijing", "celsius")
    }
]

final_response = client.chat.completions.create(
    model="deepseek-ai/DeepSeek-R1-0528",
    messages=messages,
    temperature=0.7
)

print(final_response.choices[0].message.content)
# Output: "The weather in Beijing is currently 22°C and sunny."
```

#### 4.2.3 多 token 预测（EAGLE 投机解码）

DeepSeek-R1 支持基于 EAGLE 的多 token 预测（MTP），与 DeepSeek-V3 机制相同。完整的启动命令、参数参考与调优指南（`--speculative-num-steps`、`--speculative-eagle-topk`、`--max-running-requests`）以及 `bench_speculative.py` 链接请参考 [DeepSeek-V3 §4.2.3](/cookbook/autoregressive/DeepSeek/DeepSeek-V3#4-2-3-multi-token-prediction-eagle-speculative-decoding)。R1 的带 `--speculative-*` 参数的速度基准命令使用的就是这一机制。

#### 4.2.4 思维预算（Thinking Budget）

用 `CustomLogitProcessor` 限制模型的思维 token 预算。启动时加 `--enable-custom-logit-processor`：

```shell Command
python3 -m sglang.launch_server \
  --model deepseek-ai/DeepSeek-R1 \
  --tp 8 \
  --port 30000 \
  --reasoning-parser deepseek-r1 \
  --enable-custom-logit-processor
```

```python Example
import openai
from sglang.srt.sampling.custom_logit_processor import DeepSeekR1ThinkingBudgetLogitProcessor

client = openai.Client(base_url="http://127.0.0.1:30000/v1", api_key="*")
response = client.chat.completions.create(
    model="deepseek-ai/DeepSeek-R1",
    messages=[{"role": "user", "content": "Is Paris the Capital of France?"}],
    max_tokens=1024,
    extra_body={
        "custom_logit_processor": DeepSeekR1ThinkingBudgetLogitProcessor().to_str(),
        "custom_params": {"thinking_budget": 512},
    },
)
print(response)
```

<Note>
💡 AI Infra 学习笔记：推理（reasoning）模型会在输出正式答案前生成大段"思维链"，生成 token 数远多于普通模型——KV 缓存随之快速增长，解码阶段的显存与耗时都很可观。用思维预算（thinking budget）限制思考长度，是在"思考质量"与"成本/延迟"之间做取舍，生产环境常配合 PD 分离与投机解码一起使用。
</Note>

#### 5.1.2 并发级别

在不同并发级别下测试每个场景，以捕捉吞吐量 vs 延迟的权衡：

- **低并发**：`--max-concurrency 1`（面向延迟优化）
- **中并发**：`--max-concurrency 16`（均衡）
- **高并发**：`--max-concurrency 100`（面向吞吐量优化）

<Note>
💡 AI Infra 学习笔记：并发数（concurrency）是理解推理性能的关键旋钮——低并发测的是单请求延迟（TTFT/TPOT），高并发才能把 GPU 打满、压出最大吞吐。不同负载在"延迟 vs 吞吐"之间构成帕累托前沿：随着并发上升，总吞吐先涨后趋于饱和，单请求延迟则持续恶化。基准时先确认并发真的把服务压满了，否则结果没有参考意义。
</Note>

#### 5.1.3 提示词数量

对每个并发级别，配置 `num_prompts` 以模拟真实的用户负载：

- **快速测试**：`num_prompts = concurrency × 1`（最小测试）
- **推荐**：`num_prompts = concurrency × 5`（标准基准）
- **稳定测量**：`num_prompts = concurrency × 10`（生产级）

#### 5.1.5 理解结果

**关键指标：**

- **请求吞吐量（req/s）**：每秒处理的请求数
- **输出 token 吞吐量（tok/s）**：每秒生成的 token 总数
- **平均 TTFT（ms）**：首 token 时间——衡量响应速度
- **平均 TPOT（ms）**：单输出 token 时间——衡量生成速度
- **平均 ITL（ms）**：token 间延迟——衡量流式输出的稳定性

**这些配置为什么重要：**

- **1K/1K（聊天）**：代表最常见的对话式 AI 负载。对大多数部署来说这是最高优先级的场景。
- **1K/8K（推理）**：测试长文生成能力，对复杂推理、代码生成与详细解释至关重要。
- **8K/1K（摘要）**：评估大上下文输入下的性能，对 RAG 系统、文档问答与摘要任务必不可少。
- **可变并发**：捕捉帕累托前沿——不同负载水平下吞吐量与延迟之间的最优权衡。低并发展示最佳情况延迟，高并发展示最大吞吐量。

**解读结果：**

- 把你的结果与硬件基线数据对比
- 相同延迟下吞吐更高 = 性能更好
- 更低的 TTFT = 更快的用户响应体验
- 更低的 TPOT = 更快的生成速度
