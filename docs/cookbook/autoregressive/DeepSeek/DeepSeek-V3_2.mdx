## 1. 模型介绍

DeepSeek-V3.2 系列包含三个模型变体，各自针对不同使用场景优化：

**[DeepSeek-V3.2-Exp](https://huggingface.co/deepseek-ai/DeepSeek-V3.2-Exp)** 是 DeepSeek-V3.1-Terminus 的升级版，通过持续训练引入 DeepSeek 稀疏注意力（DSA）机制。DSA 是一种由闪电级 indexer 驱动的细粒度稀疏注意力机制，让 DeepSeek-V3.2-Exp 在长上下文场景下获得显著的效率提升。推荐用于通用对话、长上下文处理与高效推理。

**[DeepSeek-V3.2](https://huggingface.co/deepseek-ai/DeepSeek-V3.2)** 是标准版本，适用于通用任务与对话场景。本地部署时，我们建议把采样参数设置为 temperature = 1.0、top_p = 0.95。推荐用于标准对话与通用任务。

**[DeepSeek-V3.2-Speciale](https://huggingface.co/deepseek-ai/DeepSeek-V3.2-Speciale)** 是专为深度推理任务设计的特殊变体。该模型专门针对需要复杂逻辑推理与深度思考的场景优化。但该模型不支持工具调用（见下文）。本地部署时，我们建议把采样参数设置为 temperature = 1.0、top_p = 0.95。推荐用于深度推理任务、复杂逻辑问题与数学推理。

**[DeepSeek-V3.2-NVFP4](https://huggingface.co/nvidia/DeepSeek-V3.2-NVFP4)** 是面向 Blackwell 设备、由 NVIDIA 优化的 DeepSeek-V3.2 NVFP4 量化变体。它使用 ModelOpt FP4 量化，可选多种 MoE runner 后端（`flashinfer_trtllm`（推荐）、`flashinfer_cutlass` 或 `flashinfer_cutedsl`），能以更低的张量并行度（TP=4）高效部署。它支持与 DeepSeek-V3.2 相同的功能，包括工具调用、推理与投机解码（MTP）。

**[DeepSeek-V3.2-MXFP4](https://huggingface.co/amd/DeepSeek-V3.2-mxfp4)** 是面向 AMD MI300X/MI355X 设备的 OCP-MXFP4 优化变体。它使用 OCP MXFP4 量化与 triton mxfp4 后端（与 gptoss-120B 相同的后端），能在单节点内以更低的张量并行度（TP=8）高效部署。它包含与 DeepSeek-V3.2 相同的功能，包括工具调用、推理、fp8-kv、CP、TP 与投机解码 MTP。

<Note>
💡 AI Infra 学习笔记：DeepSeek 稀疏注意力（DSA）是 V3.2 的核心创新——先用一个轻量 indexer 快速选出每个查询最相关的 top-k 关键 token，再做稀疏注意力，把长序列注意力从 O(n²) 降到接近线性，同时 KV 缓存命中与预填充成本都大幅下降。这是处理 128K+ 长上下文、降低 TTFT 的关键技术，与 MLA 一起构成 DeepSeek 系模型的"显存省一半、算力省一大截"组合拳。
</Note>

### 3.2 配置技巧

- **短序列 MHA 预填充（自适应）：** 对于短于 2048 token（默认阈值）的预填充序列，DSA 后端会自动切换到标准 MHA（SM90 上用 FlashAttention 变长，SM100 上用 TRT-LLM ragged MHA）。要扩展到更长序列，把环境变量 `SGLANG_DSA_PREFILL_DENSE_ATTN_KV_LEN_THRESHOLD` 设为更大的值（可能有轻微精度取舍）。
- **DSA 预填充/解码注意力 kernel（`--dsa-prefill-backend`、`--dsa-decode-backend`）：** `dsa` 后端会自动为 DeepSeek-V3.2 选择。可用 kernel：`flashmla_sparse`、`flashmla_sparse_q8`（原生 FP8 e4m3 稀疏预填充——没有 fp8→bf16 反量化往返；仅 Hopper SM90 + `--kv-cache-dtype fp8_e4m3`，仅预填充）、`flashmla_kv`、`flashmla_auto`、`fa3`（仅 Hopper）、`tilelang`（GPU/HPU/NPU）、`aiter`（AMD，仅解码）、`trtllm`（仅 Blackwell）。默认：Hopper BF16 KV → `flashmla_sparse` 预填充 / `fa3` 解码；Hopper FP8 KV → `flashmla_kv` 两者；Blackwell BF16 → `flashmla_sparse` / `trtllm`；Blackwell FP8 → `trtllm` 两者。
- **索引缓存（Index Cache）：** 在层间复用 indexer 结果以提升效率，精度损失可忽略。**GLM-5** 特别地，追加 `--json-model-override-args '{"index_topk_pattern": "FFSFSSSFSSFFFSSSFFFSFSSSSSSFFSFFSFFSSFFFFFFSFFFFFSFFSSSSSSFSFFFSFSSSFSFFSFFSSS"}'` 以获得更好的速度/精度权衡。
- **HiSparse（实验性）：** 通过把 KV 数据卸载到 CPU 固定内存，减少长上下文解码时每个请求的 GPU 内存。需要 PD 分离模式（仅解码实例）。参见 [HiSparse 指南](../../../docs/advanced_features/hisparse_guide)。
- **Blackwell 上的 NVFP4：** 指定 `--quantization modelopt_fp4` 和 `--moe-runner-backend flashinfer_trtllm`（推荐）/ `flashinfer_cutlass` / `flashinfer_cutedsl`。完整示例：
  ```bash
  python -m sglang.launch_server --model nvidia/DeepSeek-V3.2-NVFP4 --tp 4 \
    --quantization modelopt_fp4 --moe-runner-backend flashinfer_trtllm \
    --tool-call-parser deepseekv32 --reasoning-parser deepseek-v3
  ```
- **NCCL 超时：** 模型加载缓慢 → 加 `--dist-timeout 3600`。

#### 4.2.1 推理解析器

DeepSeek-V3.2 支持推理模式。部署时启用推理解析器，可把思考与内容部分分开：

```shell Command
sglang serve \
  --model-path deepseek-ai/DeepSeek-V3.2-Exp \
  --reasoning-parser deepseek-v3 \
  --tp 8 \
  --host 0.0.0.0 \
  --port 30000
```

**带思考过程的流式输出：**

```python Example
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:30000/v1",
    api_key="EMPTY"
)

# Enable streaming to see the thinking process in real-time
response = client.chat.completions.create(
    model="deepseek-ai/DeepSeek-V3.2-Exp",
    messages=[
        {"role": "user", "content": "Solve this problem step by step: What is 15% of 240?"}
    ],
    temperature=0.7,
    max_tokens=2048,
    extra_body = {"chat_template_kwargs": {"thinking": True}},
    stream=True
)

# Process the stream
has_thinking = False
has_answer = False
thinking_started = False

for chunk in response:
    if chunk.choices and len(chunk.choices) > 0:
        delta = chunk.choices[0].delta

        # Print thinking process
        if hasattr(delta, 'reasoning_content') and delta.reasoning_content:
            if not thinking_started:
                print("=============== Thinking =================", flush=True)
                thinking_started = True
            has_thinking = True
            print(delta.reasoning_content, end="", flush=True)

        # Print answer content
        if delta.content:
            # Close thinking section and add content header
            if has_thinking and not has_answer:
                print("\n=============== Content =================", flush=True)
                has_answer = True
            print(delta.content, end="", flush=True)

print()
```

**输出示例：**

```text Output
=============== Thinking =================
To solve this problem, I need to calculate 15% of 240.
Step 1: Convert 15% to decimal: 15% = 0.15
Step 2: Multiply 240 by 0.15
Step 3: 240 × 0.15 = 36
=============== Content =================

The answer is 36. To find 15% of 240, we multiply 240 by 0.15, which equals 36.
```

**注意：** 推理解析器会捕获模型的逐步思考过程，让你看到模型是如何得出结论的。

DeepSeek-V3.2 与 DeepSeek-V3.2-Exp 都支持工具调用能力，但使用不同的参数。启用工具调用解析器：

```shell Command

  --trust-remote-code \

  --reasoning-parser deepseek-v3
```

**部署命令：**

对于 DeepSeek-V3.2-Exp：

```shell Command
sglang serve \
  --model-path deepseek-ai/DeepSeek-V3.2-Exp \
  --tool-call-parser deepseekv31 \
  --reasoning-parser deepseek-v3 \
  --chat-template ./examples/chat_template/tool_chat_template_deepseekv32.jinja \
  --tp 8 \
  --host 0.0.0.0 \
  --port 30000
```

对于 DeepSeek-V3.2，使用 `--tool-call-parser deepseekv32` 并去掉 `--chat-template`。

**Python 示例（带思考过程）：**

```python Example
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:30000/v1",
    api_key="EMPTY"
)

# Define available tools
tools = [
    {
        "type": "function",
        "function": {
            "name": "get_weather",
            "description": "Get the current weather for a location",
            "parameters": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city name"
                    },
                    "unit": {
                        "type": "string",
                        "enum": ["celsius", "fahrenheit"],
                        "description": "Temperature unit"
                    }
                },
                "required": ["location"]
            }
        }
    }
]

# Make request with streaming to see thinking process
response = client.chat.completions.create(
    model="deepseek-ai/DeepSeek-V3.2-Exp",
    messages=[
        {"role": "user", "content": "What's the weather in Beijing?"}
    ],
    tools=tools,
    extra_body = {"chat_template_kwargs": {"thinking": True}},
    temperature=0.7,
    stream=True
)

# Process streaming response
thinking_started = False
has_thinking = False
tool_calls_accumulator = {}

for chunk in response:
    if chunk.choices and len(chunk.choices) > 0:
        delta = chunk.choices[0].delta

        # Print thinking process
        if hasattr(delta, 'reasoning_content') and delta.reasoning_content:
            if not thinking_started:
                print("=============== Thinking =================", flush=True)
                thinking_started = True
            has_thinking = True
            print(delta.reasoning_content, end="", flush=True)

        # Accumulate tool calls
        if hasattr(delta, 'tool_calls') and delta.tool_calls:
            # Close thinking section if needed
            if has_thinking and thinking_started:
                print("\n=============== Content =================\n", flush=True)
                thinking_started = False

            for tool_call in delta.tool_calls:
                index = tool_call.index
                if index not in tool_calls_accumulator:
                    tool_calls_accumulator[index] = {
                        'name': None,
                        'arguments': ''
                    }

                if tool_call.function:
                    if tool_call.function.name:
                        tool_calls_accumulator[index]['name'] = tool_call.function.name
                    if tool_call.function.arguments:
                        tool_calls_accumulator[index]['arguments'] += tool_call.function.arguments

        # Print content
        if delta.content:
            print(delta.content, end="", flush=True)

# Print accumulated tool calls
for index, tool_call in sorted(tool_calls_accumulator.items()):
    print(f"Tool Call: {tool_call['name']}")
    print(f"   Arguments: {tool_call['arguments']}")

print()
```

**输出示例：**

```text Output
=============== Thinking =================
The user is asking about the weather in Beijing. I need to use the get_weather function to retrieve this information.
I should call the function with location="Beijing".
=============== Content =================

Tool Call: get_weather
   Arguments: {"location": "Beijing", "unit": "celsius"}
```

**注意：**

- 推理解析器会展示模型如何决定使用工具
- 工具调用会用函数名与参数清晰地标出
- 之后你可以执行该函数并把结果返回给模型以继续对话

**处理工具调用结果：**

```python Example
# After getting the tool call, execute the function
def get_weather(location, unit="celsius"):
    # Your actual weather API call here
    return f"The weather in {location} is 22°{unit[0].upper()} and sunny."

# Send tool result back to the model
messages = [
    {"role": "user", "content": "What's the weather in Beijing?"},
    {
        "role": "assistant",
        "content": None,
        "tool_calls": [{
            "id": "call_123",
            "type": "function",
            "function": {
                "name": "get_weather",
                "arguments": '{"location": "Beijing", "unit": "celsius"}'
            }
        }]
    },
    {
        "role": "tool",
        "tool_call_id": "call_123",
        "content": get_weather("Beijing", "celsius")
    }
]

final_response = client.chat.completions.create(
    model="deepseek-ai/DeepSeek-V3.2-Exp",
    messages=messages,
    temperature=0.7
)

print(final_response.choices[0].message.content)
# Output: "The weather in Beijing is currently 22°C and sunny."
```

#### 4.2.3 多 token 预测（EAGLE 投机解码） {#4-2-3-multi-token-prediction-eagle-speculative-decoding}

SGLang 基于 [EAGLE 投机解码](../../../docs/advanced_features/speculative_decoding#eagle-decoding) 为 DeepSeek V3.2 实现了多 token 预测（MTP）。这一优化能显著提升小批量场景的解码速度。

**配合 DP 注意力：**

```bash Command
python -m sglang.launch_server --model deepseek-ai/DeepSeek-V3.2-Exp --tp 8 --dp 8 \
  --enable-dp-attention \
  --speculative-algorithm EAGLE \
  --speculative-num-steps 3 --speculative-eagle-topk 1 --speculative-num-draft-tokens 4
```

**纯 TP：**

```bash Command
python -m sglang.launch_server --model deepseek-ai/DeepSeek-V3.2-Exp --tp 8 \
  --speculative-algorithm EAGLE \
  --speculative-num-steps 3 --speculative-eagle-topk 1 --speculative-num-draft-tokens 4
```

用 [bench_speculative.py](https://github.com/sgl-project/sglang/blob/main/scripts/playground/bench_speculative.py) 为你的负载找到最优值。最小可用配置是 `--speculative-num-steps 1 --speculative-eagle-topk 1 --speculative-num-draft-tokens 2`。

<Note>
`--max-running-requests` 在 MTP 下默认为 48。大批量场景下增大它。
</Note>

<Tip>
spec-v2 重叠调度器默认启用。传 `--disable-overlap-schedule` 可禁用。
</Tip>

#### 4.2.4 PD 分离部署（PD Disaggregation）

预填充-解码（PD）分离部署把预填充与解码阶段拆到不同实例上，提升混合负载下的 GPU 利用率。

<Note>
💡 AI Infra 学习笔记：PD 分离（prefill-decode disaggregation）解决的是两个阶段负载特性冲突的问题——预填充计算密集、并行度高，解码访存密集、逐 token 串行。混在一起时，长请求的预填充会占满 GPU，拖慢所有正在解码的短请求、拉高 TTFT。拆开后各自调优、独立扩缩容，是长上下文与高并发生产部署的标配思路。
</Note>

**预填充命令：**

```bash Command
python -m sglang.launch_server \
  --model-path deepseek-ai/DeepSeek-V3.2-Exp \
  --disaggregation-mode prefill \
  --host $LOCAL_IP \
  --port $PORT \
  --tp 8 \
  --dp 8 \
  --enable-dp-attention \
  --dist-init-addr ${HOST}:${DIST_PORT} \
  --trust-remote-code \
  --disaggregation-bootstrap-port 8998 \
  --mem-fraction-static 0.9
```

**解码命令：**

```bash Command
python -m sglang.launch_server \
  --model-path deepseek-ai/DeepSeek-V3.2-Exp \
  --disaggregation-mode decode \
  --host $LOCAL_IP \
  --port $PORT \
  --tp 8 \
  --dp 8 \
  --enable-dp-attention \
  --dist-init-addr ${HOST}:${DIST_PORT} \
  --trust-remote-code \
  --mem-fraction-static 0.9
```

**路由器命令：**

```bash Command
python -m sglang_router.launch_router --pd-disaggregation \
  --prefill $PREFILL_ADDR 8998 \
  --decode $DECODE_ADDR \
  --host 127.0.0.1 \
  --port 30000
```

生产部署（RBG / LWS 为基础、DeepEP EP 并行）请参考 [multi_node_deployment 文档](../../../docs/references/multi_node_deployment/rbg_pd/deepseekv32_pd)。

#### 4.2.5 DSA 长序列上下文并行与 PP/CP

SGLang 为长序列负载提供两种上下文并行（CP）模式，用 `--dsa-prefill-cp-mode` 控制。

**序列内切分**（`--dsa-prefill-cp-mode in-seq-split`）：每个 CP rank 处理序列的一个均匀分片；KV 缓存通过 all-gather 聚合。预填充期间批大小限制为 1。参见 [PR #12065](https://github.com/sgl-project/sglang/pull/12065)。

```bash Command
# In-seq splitting mode — EP + DP, batch size 1
python -m sglang.launch_server --model deepseek-ai/DeepSeek-V3.2-Exp \
  --tp 8 --ep 8 --dp 2 --enable-dp-attention \
  --enable-dsa-prefill-context-parallel --attn-cp-size 4 \
  --dsa-prefill-cp-mode in-seq-split --max-running-requests 32
```

**轮转切分**（`--dsa-prefill-cp-mode round-robin-split`，默认）：按 `token_idx % cp_size` 分配 token。支持 fused MoE、FP8 KV 缓存与多批预填充。不能与 DP 注意力组合。参见 [PR #13959](https://github.com/sgl-project/sglang/pull/13959)。

```bash Command
# Round-robin splitting — FusedMoE + CP8
python -m sglang.launch_server --model deepseek-ai/DeepSeek-V3.2-Exp \
  --tp 8 --enable-dsa-prefill-context-parallel --attn-cp-size 8 \
  --dsa-prefill-cp-mode round-robin-split --max-running-requests 32
```

**PP + CP（多节点）：** 组合流水线并行与上下文并行实现跨节点扩展。下面经过生产优化的配置已在 Hopper 上验证：

我们建议在 Hopper 平台上用 `DP2` + `MTP` 本地部署 DeepSeek V3.2 的 agent 工作流：

```shell Command
export SGLANG_DEEPEP_LL_COMBINE_SEND_NUM_SMS=32
export SGLANG_SET_CPU_AFFINITY=1

# Test workload ISL/OSL=1k/1k, raw tap : 4948.16 toks/sec, MAX ITL 5970
#   dp 2 : 5019.54  toks/sec, MAX ITL 7233
#   dp 4 : 4942.82  toks/sec, MAX ITL 35654
#   dp 2 + mtp : 6842.51 toks/sec, MAX ITL 3081
sglang_args=$(echo serve \
  --model-path $MAPPED_MODEL_PATH \
  --nccl-init $MASTER_ADDR:$MASTER_PORT --nnodes 2 --node-rank $RANK --tp 16 \
  --dp 2 --enable-dp-attention --page-size 64 \
  --trust-remote-code --host "0.0.0.0" --port 30000 \
  --log-requests \
  --context-length 65536 --max-running-requests 128 \
  --speculative-algorithm EAGLE \
  --speculative-num-steps 2 --speculative-eagle-topk 1 --speculative-num-draft-tokens 3 \
  --allow-auto-truncate --enable-metrics \
  --tool-call-parser deepseekv32 --reasoning-parser deepseek-v3 \
  --served-model-name DeepSeek-V3.2-Opt-dp2-mtp
)

sglang_args=($sglang_args)

sglang "${sglang_args[@]}" 2>&1 | tee $LOG_DIR/$RANK.log
```

**CP + PP + EP + DP**

`CP` 目前在 Hopper 平台上与 `PP=2` 一起启用，相比独立部署可以把 TP=16 降到 TP=8：

```shell Command
# verified on Hopper platform
sglang_args=$(echo serve \
  --model-path $MAPPED_MODEL_PATH \
  --nccl-init $MASTER_ADDR:$MASTER_PORT --nnodes 2 --node-rank $RANK --tp 8 --pp-size 2 --dp 1 --enable-dp-attention \
  --moe-a2a-backend deepep --ep-size 16  \
  --page-size 128 \
  --chunked-prefill-size 16384 \
  --attention-backend dsa \
```
