## 1. 模型介绍

[DeepSeek-OCR](https://github.com/deepseek-ai/DeepSeek-OCR) 是 DeepSeek 推出的高级 OCR（光学字符识别）模型，专为从图像中高精度提取文字而设计。该模型针对各种文档处理与图像转文字任务做了优化。

**核心特性：**

- **高级 OCR**：从图像和文档中高精度识别文字
- **多模态**：支持多种图像格式与文档类型

<Note>
💡 AI Infra 学习笔记：OCR 模型属于多模态（VLM）推理——图像会先被视觉编码器切分成若干图像 token（vision tokens），再与文本 token 一起进入语言模型，因此图像的分辨率会直接决定 token 数量和显存占用。这也是为什么 bench 结果里单独统计 `Total input vision tokens`：长图、高分辨率图在推理成本上的差异可能比文本还大。
</Note>

**可用模型：**

- **基础模型**：[deepseek-ai/DeepSeek-OCR](https://huggingface.co/deepseek-ai/DeepSeek-OCR) - 推荐用于 OCR 任务

**许可协议：**
使用 DeepSeek-OCR 需要同意 DeepSeek 社区许可协议。详见 [LICENSE](https://huggingface.co/deepseek-ai/DeepSeek-OCR/blob/main/LICENSE)。

更多细节请参考[官方 DeepSeek-OCR 仓库](https://github.com/deepseek-ai/DeepSeek-OCR)。

### 4.2 OCR 专用提示词

DeepSeek-OCR 接受模型卡推荐的提示词：

```text
<image>
<|grounding|>Convert the document to markdown.
```

```text
<image>
Free OCR.
```

**兼容 OpenAI 的图像请求示例：**

```python Example
import requests

url = "http://localhost:30000/v1/chat/completions"

data = {
    "model": "deepseek-ai/DeepSeek-OCR",
    "messages": [
        {
            "role": "user",
            "content": [
                {
                    "type": "text",
                    "text": "<image>\n<|grounding|>Convert the document to markdown."
                },
                {
                    "type": "image_url",
                    "image_url": {"url": "https://example.com/your_image.jpg"}
                },
            ],
        }
    ],
    "max_tokens": 512,
}

response = requests.post(url, json=data)
print(response.text)
```

## 5. 基准测试

### 5.1 速度基准测试

**测试环境：**

- 硬件：AMD MI300X GPU（1 卡）
- 模型：DeepSeek-OCR
- 张量并行度：1
- SGLang 版本：0.5.7

我们用 SGLang 内置的基准测试工具，在 [ShareGPT_Vicuna_unfiltered](https://huggingface.co/datasets/anon8231489123/ShareGPT_Vicuna_unfiltered) 数据集上做性能评估。该数据集包含真实对话数据，能更好地反映实际使用场景的性能。为模拟真实使用模式，我们把每个请求配置为 1024 个输入 token 与 1024 个输出 token，代表带详细回答的典型中等长度对话。

#### 5.1.1 延迟敏感基准测试

- 模型部署命令：

```shell Command
python3 -m sglang.launch_server \
  --model-path deepseek-ai/DeepSeek-OCR \
  --tp 1 \
  --dtype float16 \
  --trust-remote-code \
  --host 0.0.0.0 \
  --port 8000
```

- 基准测试命令：

```shell Command
python3 -m sglang.bench_serving \
  --backend sglang \
  --host 127.0.0.1 \
  --port 8000 \
  --model deepseek-ai/DeepSeek-OCR \
  --random-input-len 1024 \
  --random-output-len 1024 \
  --num-prompts 10 \
  --max-concurrency 1
```
