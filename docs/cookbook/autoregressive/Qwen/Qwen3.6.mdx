## 1. 模型介绍

Qwen3.6 系列由阿里巴巴开发。基于社区的直接反馈，Qwen3.6 优先考虑稳定性与实际可用性，在智能体编码和思考保留方面带来了大幅升级。该系列发布两种尺寸/稀疏度变体：

- [Qwen3.6-35B-A3B](https://huggingface.co/Qwen/Qwen3.6-35B-A3B)——基于 Gated Delta Network 骨干的**稀疏 MoE**（总参数 35B，激活 3B）。
- [Qwen3.6-27B](https://huggingface.co/Qwen/Qwen3.6-27B)——**稠密**混合 GDN 架构；权重体积更小，适合单 GPU。

两个变体共享相同的混合推理、工具调用和多模态接口，原生支持最长 262,144 token 的上下文，并可通过扩展支持超过 1M token。

<Note>
💡 AI Infra 学习笔记：同一个系列同时推出「稀疏 MoE（35B 总参 / 3B 激活）」与「稠密 27B」两个变体，是很有代表性的部署权衡：MoE 用更多总参数换取更强的模型容量，但单 token 的计算量只相当于 3B 稠密模型，推理成本更低、吞吐更高；稠密模型则权重更小、内存访问更规整，实现和维护都更简单。对推理引擎来说，MoE 需要额外的专家路由与显存驻留（全部专家权重都在显存里），这正是"总参数 35B、激活仅 3B 却能单 GPU 部署"的原因。
</Note>


**主要特性：**

- **智能体编码**：以前端工作流和仓库级推理为主的场景下更加流畅、精确
- **思考保留**：新增可保留历史消息中推理上下文的选项，让迭代开发更顺畅
- **高效混合架构**：Gated Delta Network 骨干；稀疏 MoE（35B / 激活 3B）或稠密 27B 变体
- **混合推理**：默认开启思考模式，逐步推理，也可关闭以直接作答
- **工具调用**：内置工具调用支持，使用 `qwen3_coder` 解析器
- **多 token 预测（MTP）**：支持投机解码，降低延迟；MoE 和稠密两个变体都附带 `mtp.safetensors`
- **多模态**：统一的视觉语言模型，支持文本、图像和视频输入

## 2. 安装 SGLang

Qwen3.6 需要 SGLang `>=0.5.10`。你可以通过 PyPI、源码或 Docker 镜像安装：

```bash Command
# Install from PyPI
uv pip install sglang

# Or install from source
uv pip install 'git+https://github.com/sgl-project/sglang.git#subdirectory=python'

# Or use Docker (NVIDIA GPUs; also serves the NVFP4 variants)
docker pull lmsysorg/sglang:latest
```

完整的 Docker 配置和其它安装方式请参考 [SGLang 官方安装指南](../../../docs/get-started/install)。

### 3.2 配置建议

- 投机解码（MTP）可以显著降低交互式场景的延迟。
- **Mamba Radix 缓存**：Qwen3.6 的混合 Gated Delta Network 架构通过 `--mamba-radix-cache-strategy` 支持两种 mamba 调度策略：
  - **V1（`no_buffer`）**：默认。无重叠调度器，显存占用更低。
  - **V2（`extra_buffer`）**：使用 `--mamba-radix-cache-strategy extra_buffer --page-size 64` 启用重叠调度与分支点缓存。需要 FLA kernel 后端（仅 NVIDIA GPU）。以更高的 mamba 状态显存换取更高吞吐。
- 建议用 `--mem-fraction-static` 参数获得最优的显存利用率，请根据你的硬件和工作负载调整。
- 上下文长度默认为 262,144 token。如果遇到 OOM 错误，可以考虑调小，但建议至少保留 128K 以保持思考能力。
- **CUDA IPC 传输**：添加环境变量 `SGLANG_USE_CUDA_IPC_TRANSPORT=1`，用 CUDA IPC 传输多模态特征，可显著改善 TTFT（首 token 延迟）。注意：这会按图像大小消耗额外显存，你可能需要调低 `--mem-fraction-static` 或 `--max-running-requests`。
- **多模态注意力后端**：在 H100/H200 上用 `--mm-attention-backend fa3` 获得更好的视觉性能，在 B200/B300 上用 `--mm-attention-backend fa4`。
- 处理大图或视频时，你可能需要调低 `--mem-fraction-static`，为图像特征张量留出空间。
- 硬件要求：
    - **35B-A3B BF16**：权重约 70GB。所有受支持硬件上 TP=1 即可。
    - **35B-A3B FP8**：权重约 35GB。所有受支持硬件上 TP=1 即可。
    - **35B-A3B NVFP4**：权重约 23GB。B200/B300 上 TP=1 即可。
    - **27B BF16**：权重约 54GB。所有受支持硬件上 TP=1 即可。
    - **27B FP8**：权重约 27GB。所有受支持硬件上 TP=1 即可。
    - **27B NVFP4**：权重约 22GB。B200/B300 上 TP=1 即可。

Qwen3.6 的所有变体（MoE 35B-A3B 和稠密 27B）都能装进单块受支持的 GPU。NVFP4 在 B200/B300 上可用：

## 4. 模型调用

用以下命令部署 Qwen3.6（H200，全部特性开启）。部署稠密 27B 变体时把 `--model-path` 换成 `Qwen/Qwen3.6-27B-FP8`——其余参数全部沿用：

```shell Command
sglang serve \
  --model-path Qwen/Qwen3.6-35B-A3B-FP8 \
  --reasoning-parser qwen3 \
  --tool-call-parser qwen3_coder \
  --speculative-algorithm EAGLE \
  --speculative-num-steps 3 \
  --speculative-eagle-topk 1 \
  --speculative-num-draft-tokens 4 \
  --mem-fraction-static 0.8 \
  --host 0.0.0.0 \
  --port 30000
```

### 4.2 视觉输入

Qwen3.6 是统一的视觉语言模型，支持图像和视频输入。

**图像输入示例：**

```python Example
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:30000/v1",
    api_key="EMPTY"
)

response = client.chat.completions.create(
    model="Qwen/Qwen3.6-35B-A3B-FP8",
    messages=[
        {
            "role": "user",
            "content": [
                {
                    "type": "image_url",
                    "image_url": {
                        "url": "https://qianwen-res.oss-accelerate.aliyuncs.com/Qwen3.5/demo/CI_Demo/mathv-1327.jpg"
                    }
                },
                {
                    "type": "text",
                    "text": "Describe this image in detail."
                }
            ]
        }
    ],
    max_tokens=2048,
    stream=True
)

thinking_started = False
has_thinking = False
has_answer = False

for chunk in response:
    if chunk.choices and len(chunk.choices) > 0:
        delta = chunk.choices[0].delta

        if hasattr(delta, 'reasoning_content') and delta.reasoning_content:
            if not thinking_started:
                print("=============== Thinking =================", flush=True)
                thinking_started = True
            has_thinking = True
            print(delta.reasoning_content, end="", flush=True)

        if delta.content:
            if has_thinking and not has_answer:
                print("\n=============== Content =================", flush=True)
                has_answer = True
            print(delta.content, end="", flush=True)

print()
```

### 4.3 高级用法

#### 4.3.1 推理解析器

Qwen3.6 **默认**支持思考模式。部署时启用推理解析器，可以把思考过程和回答内容分开。思考过程会通过流式响应中的 `reasoning_content` 返回。

要关闭思考、使用指令模式，请在请求时传入 `chat_template_kwargs`：

- **思考模式**（默认）：模型在回答前先逐步推理。无需额外参数。
- **指令模式**（`{"enable_thinking": false}`）：模型直接作答，不进行思考。

**示例 1：思考模式（默认）**

```python Example
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:30000/v1",
    api_key="EMPTY"
)

response = client.chat.completions.create(
    model="Qwen/Qwen3.6-35B-A3B-FP8",
    messages=[
        {"role": "user", "content": "Solve this problem step by step: What is 15% of 240?"}
    ],
    max_tokens=2048,
    stream=True
)

has_thinking = False
has_answer = False
thinking_started = False

for chunk in response:
    if chunk.choices and len(chunk.choices) > 0:
        delta = chunk.choices[0].delta

        if hasattr(delta, 'reasoning_content') and delta.reasoning_content:
            if not thinking_started:
                print("=============== Thinking =================", flush=True)
                thinking_started = True
            has_thinking = True
            print(delta.reasoning_content, end="", flush=True)

        if delta.content:
            if has_thinking and not has_answer:
                print("\n=============== Content =================", flush=True)
                has_answer = True
            print(delta.content, end="", flush=True)

print()
```

**示例 2：指令模式（关闭思考）**

要关闭思考、直接作答，请通过 `chat_template_kwargs` 传入 `{"enable_thinking": false}`：

```python Example
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:30000/v1",
    api_key="EMPTY"
)

response = client.chat.completions.create(
    model="Qwen/Qwen3.6-35B-A3B-FP8",
    messages=[
        {"role": "user", "content": "What is 15% of 240?"}
    ],
    extra_body={"chat_template_kwargs": {"enable_thinking": False}},
    max_tokens=2048,
    stream=True
)

for chunk in response:
    if chunk.choices and len(chunk.choices) > 0:
        delta = chunk.choices[0].delta
        if delta.content:
            print(delta.content, end="", flush=True)

print()
```

#### 4.3.2 思考保留

Qwen3.6 经过训练，可以保留并利用历史消息中的思考痕迹。在智能体场景下启用该功能，保持完整的推理上下文有助于提高决策一致性：

<Note>
💡 AI Infra 学习笔记：「思考保留」是智能体场景下的一项新特性：把历史轮次中的推理痕迹（reasoning trace）也传给模型，让它在长对话中保持一致的决策逻辑。代价是每轮都要把更长的上下文写进 KV 缓存，显存与预填充开销随之上升——是否开启，本质是在"决策一致性"与"吞吐/显存"之间做权衡。
</Note>


```python Example
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:30000/v1",
    api_key="EMPTY"
)

response = client.chat.completions.create(
    model="Qwen/Qwen3.6-35B-A3B-FP8",
    messages=[
        {"role": "user", "content": "Help me plan a web app architecture."}
    ],
    extra_body={"chat_template_kwargs": {"preserve_thinking": True}},
    max_tokens=2048,
    stream=True
)

thinking_started = False
has_thinking = False
has_answer = False

for chunk in response:
    if chunk.choices and len(chunk.choices) > 0:
        delta = chunk.choices[0].delta

        if hasattr(delta, 'reasoning_content') and delta.reasoning_content:
            if not thinking_started:
                print("=============== Thinking =================", flush=True)
                thinking_started = True
            has_thinking = True
            print(delta.reasoning_content, end="", flush=True)

        if delta.content:
            if has_thinking and not has_answer:
                print("\n=============== Content =================", flush=True)
                has_answer = True
            print(delta.content, end="", flush=True)

print()
```

#### 4.3.3 工具调用

Qwen3.6 支持工具调用。部署时启用工具调用解析器。

```python Example
from openai import OpenAI

tools = [

            "parameters": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city name"
                    },
                    "unit": {
                        "type": "string",
                        "enum": ["celsius", "fahrenheit"],
                        "description": "Temperature unit"
                    }
                },
                "required": ["location"]
            }
        }
    }
]

response = client.chat.completions.create(
    model="Qwen/Qwen3.6-35B-A3B-FP8",
    messages=[
        {"role": "user", "content": "What's the weather in Beijing?"}
    ],
    tools=tools,
    stream=True
)

thinking_started = False
has_thinking = False

for chunk in response:
    if chunk.choices and len(chunk.choices) > 0:
        delta = chunk.choices[0].delta

        if hasattr(delta, 'reasoning_content') and delta.reasoning_content:
            if not thinking_started:
                print("=============== Thinking =================", flush=True)
                thinking_started = True
            has_thinking = True
            print(delta.reasoning_content, end="", flush=True)

        if hasattr(delta, 'tool_calls') and delta.tool_calls:
            if has_thinking and thinking_started:
                print("\n=============== Content =================", flush=True)
                thinking_started = False

            for tool_call in delta.tool_calls:
                if tool_call.function:
                    print(f"Tool Call: {tool_call.function.name}")
                    print(f"   Arguments: {tool_call.function.arguments}")

        if delta.content:
            print(delta.content, end="", flush=True)

print()
```
