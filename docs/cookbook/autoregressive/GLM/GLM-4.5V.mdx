## 1. 模型介绍

[GLM-4.5V](https://huggingface.co/zai-org/GLM-4.5V) 是智谱 AI 推出的先进多模态视觉语言模型，基于下一代旗舰文本基座模型 GLM-4.5-Air（106B 参数，12B 激活）构建。它在 42 个公开视觉语言基准测试上达到了同规模模型中的 SOTA 性能。通过高效的混合训练，GLM-4.5V 聚焦于真实世界的可用性，能对多种视觉内容类型进行全谱系视觉推理。

**硬件支持：** NVIDIA B200/H100/H200、AMD MI300X/MI325X/MI355X

GLM-4.5V 引入了以下关键特性：

- **图像推理与定位**：场景理解、复杂的多图像分析、空间识别与精准的视觉元素定位。支持归一化坐标（0-1000）的边界框预测，可用于准确的目标检测。
- **视频理解**：长视频分段与事件识别，支持对长视频序列进行全面的时序分析。
- **GUI Agent 任务**：屏幕阅读、图标识别和桌面操作辅助，面向 Agent 应用，能让人与图形界面自然交互。
- **复杂图表与长文档解析**：研究报表分析，以及从含文本、图表、表格和图片的文档中抽取信息。最多可处理 64K token 的多模态上下文。
- **思考模式开关**：让用户在快速响应与深度推理之间取得平衡。可根据任务需要启用或禁用思维链推理，以兼顾准确性与可解释性。

### 3.2 配置技巧
- **TTFT 优化**：设置 `SGLANG_USE_CUDA_IPC_TRANSPORT=1`，用 CUDA IPC 传输多模态特征，可显著改善 TTFT。这会额外消耗显存，可能需要调整 `--mem-fraction-static` 和/或 `--max-running-requests`。（额外显存与「图像大小 × 当前运行请求中的图像数量」成正比。）
- **TP=8 配置**：使用张量并行（TP）度为 8 时，视觉注意力的 12 个头无法被整除。可以通过添加 `--mm-enable-dp-encoder` 解决。
- **快速加载模型**：对大型模型（如 106B 版本），可以用 `--model-loader-extra-config='{"enable_multithread_load": "true","num_threads": 64}'` 加快模型加载。
- **硬件注意事项：**
  - **H100（FP8）**：使用 FP8 检查点可获得最佳显存效率。
  - **A100 / H100（BF16）**：使用标准多模态参数，在吞吐量与显存占用之间取得平衡。
  - **H200 / B200**：开箱即用，支持完整上下文长度以及图像 + 视频并发处理。
- **其它多模态参数：**
  - `--mm-attention-backend fa3`：指定多模态注意力后端（Flash Attention 3）。
  - `--keep-mm-feature-on-device`：处理完成后把多模态特征张量保留在 GPU 上，避免 D2H 内存拷贝。
  - `SGLANG_USE_CUDA_IPC_TRANSPORT=1`：用 CUDA IPC 共享内存传输多模态数据，可显著改善端到端延迟。

<Note>
💡 AI Infra 学习笔记：多模态推理里，图像/视频要先经过视觉编码器变成特征（image features），再映射为视觉 token 交给语言模型。这些特征在「编码器—语言模型」之间的搬运（GPU 间或 GPU→CPU→GPU）会直接拉高 TTFT；CUDA IPC 共享内存传输能省掉跨进程拷贝，而 `--mm-enable-dp-encoder` 则解决视觉注意力头数无法被 TP 整除的问题。多模态场景中视觉 token 往往很长，也是 KV 缓存和 prefill 计算量的主要来源之一。
</Note>

**完整多模态优化示例：**
```bash Command
SGLANG_USE_CUDA_IPC_TRANSPORT=1 \
SGLANG_VLM_CACHE_SIZE_MB=0 \
python -m sglang.launch_server \
  --model-path zai-org/GLM-4.5V \
  --host 0.0.0.0 \
  --port 30000 \
  --trust-remote-code \
  --tp-size 8 \
  --enable-cache-report \
  --log-level info \
  --max-running-requests 64 \
  --mem-fraction-static 0.65 \
  --chunked-prefill-size 8192 \
  --attention-backend fa3 \
  --mm-attention-backend fa3 \
  --mm-enable-dp-encoder \
  --enable-metrics
```

#### 4.2.1 多模态输入

GLM-4.5V 支持图像和视频输入。下面是一个使用图像输入的基础示例：

```python Example
import time
from openai import OpenAI

client = OpenAI(
    api_key="EMPTY",
    base_url="http://localhost:30000/v1",
    timeout=3600
)

messages = [
    {
        "role": "user",
        "content": [
            {
                "type": "image_url",
                "image_url": {
                    "url": "https://ofasys-multimodal-wlcb-3-toshanghai.oss-accelerate.aliyuncs.com/wpf272043/keepme/image/receipt.png"
                }
            },
            {
                "type": "text",
                "text": "Describe this image in detail."
            }
        ]
    }
]

start = time.time()
response = client.chat.completions.create(
    model="zai-org/GLM-4.5V",
    messages=messages,
    max_tokens=2048
)
print(f"Response costs: {time.time() - start:.2f}s")
print(f"Generated text: {response.choices[0].message.content}")
```

#### 4.2.2 思考模式

GLM-4.5V 支持思考模式以增强推理。部署时启用思考模式：

```shell Command
python -m sglang.launch_server \
  --model-path zai-org/GLM-4.5V \
  --reasoning-parser glm45 \
  --tp 4 \
  --host 0.0.0.0 \
  --port 30000
```

**带思考过程的流式输出：**

```python Example
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:30000/v1",
    api_key="EMPTY"
)

# Enable streaming to see the thinking process in real-time
response = client.chat.completions.create(
    model="zai-org/GLM-4.5V",
    messages=[
        {"role": "user", "content": "Solve this problem step by step: What is 15% of 240?"}
    ],
    temperature=0.7,
    max_tokens=2048,
    stream=True
)

# Process the stream
has_thinking = False
has_answer = False
thinking_started = False

for chunk in response:
    if chunk.choices and len(chunk.choices) > 0:
        delta = chunk.choices[0].delta

        # Print thinking process
        if hasattr(delta, 'reasoning_content') and delta.reasoning_content:
            if not thinking_started:
                print("=============== Thinking =================", flush=True)
                thinking_started = True
            has_thinking = True
            print(delta.reasoning_content, end="", flush=True)

        # Print answer content
        if delta.content:
            # Close thinking section and add content header
            if has_thinking and not has_answer:
                print("\n=============== Content =================", flush=True)
                has_answer = True
            print(delta.content, end="", flush=True)

print()
```

**注意：** 推理解析器会捕获模型逐步的思考过程，让你看到模型是如何得出结论的。

**关闭思考模式：**

要对某个具体请求关闭思考模式：


#### 4.2.3 工具调用

GLM-4.5V 支持工具调用。启用工具调用解析器：

```shell Command
python -m sglang.launch_server \
  --model-path zai-org/GLM-4.5V \

  --host 0.0.0.0 \
  --port 30000
```

**Python 示例（带思考过程）：**

```python Example
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:30000/v1",
    api_key="EMPTY"
)

# Define available tools
tools = [
    {
        "type": "function",
        "function": {
            "name": "get_weather",
            "description": "Get the current weather for a location",
            "parameters": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city name"
                    },
                    "unit": {
                        "type": "string",
                        "enum": ["celsius", "fahrenheit"],
                        "description": "Temperature unit"
                    }
                },
                "required": ["location"]
            }
        }
    }
]

# Make request with streaming to see thinking process
response = client.chat.completions.create(
    model="zai-org/GLM-4.5V",
    messages=[
        {"role": "user", "content": "What's the weather in Beijing?"}
    ],
    tools=tools,
    temperature=0.7,
    stream=True
)

# Process streaming response
thinking_started = False
has_thinking = False
tool_calls_accumulator = {}

for chunk in response:
    if chunk.choices and len(chunk.choices) > 0:
        delta = chunk.choices[0].delta

        # Print thinking process
        if hasattr(delta, 'reasoning_content') and delta.reasoning_content:
            if not thinking_started:
                print("=============== Thinking =================", flush=True)
                thinking_started = True
            has_thinking = True
            print(delta.reasoning_content, end="", flush=True)

        # Accumulate tool calls
        if hasattr(delta, 'tool_calls') and delta.tool_calls:
            # Close thinking section if needed
            if has_thinking and thinking_started:
                print("\n=============== Content =================\n", flush=True)
                thinking_started = False

            for tool_call in delta.tool_calls:
                index = tool_call.index
                if index not in tool_calls_accumulator:
                    tool_calls_accumulator[index] = {
                        'name': None,
                        'arguments': ''
                    }

                if tool_call.function:
                    if tool_call.function.name:
                        tool_calls_accumulator[index]['name'] = tool_call.function.name
                    if tool_call.function.arguments:
                        tool_calls_accumulator[index]['arguments'] += tool_call.function.arguments

        # Print content
        if delta.content:
            print(delta.content, end="", flush=True)

# Print accumulated tool calls
for index, tool_call in sorted(tool_calls_accumulator.items()):
    print(f"🔧 Tool Call: {tool_call['name']}")
    print(f"   Arguments: {tool_call['arguments']}")

print()
```

**输出示例：**

```text Output
=============== Thinking =================
The user is asking about the weather in Beijing. I need to use the get_weather function to retrieve this information.
I should call the function with location="Beijing".
=============== Content =================

🔧 Tool Call: get_weather
   Arguments: {"location": "Beijing", "unit": "celsius"}
```

**注意：**

- 推理解析器会展示模型是如何决定使用某个工具的
- 工具调用会用函数名和参数清晰地标注出来
- 之后你可以执行该函数，把结果发回给模型以继续对话

**处理工具调用结果：**

```python Example
# After getting the tool call, execute the function
def get_weather(location, unit="celsius"):
    # Your actual weather API call here
    return f"The weather in {location} is 22°{unit[0].upper()} and sunny."

# Send tool result back to the model
messages = [
    {"role": "user", "content": "What's the weather in Beijing?"},
    {
        "role": "assistant",
        "content": None,
        "tool_calls": [{
            "id": "call_123",
            "type": "function",
            "function": {
                "name": "get_weather",
                "arguments": '{"location": "Beijing", "unit": "celsius"}'
            }
        }]
    },
    {
        "role": "tool",
        "tool_call_id": "call_123",
        "content": get_weather("Beijing", "celsius")
    }
]

final_response = client.chat.completions.create(
    model="zai-org/GLM-4.5V",
    messages=messages,
    temperature=0.7
)

print(final_response.choices[0].message.content)
# Output: "The weather in Beijing is currently 22°C and sunny."
```

#### 4.2.4 思考预算

除了启用/禁用完整推理模式（见 4.2.2 节），你还可以用 `CustomLogitProcessor` 限制思考 token 的数量。启动时加上 `--enable-custom-logit-processor`，并在请求中传入 `Glm4MoeThinkingBudgetLogitProcessor`：

```python Example
import openai
from sglang.srt.sampling.custom_logit_processor import Glm4MoeThinkingBudgetLogitProcessor

client = openai.Client(base_url="http://127.0.0.1:30000/v1", api_key="*")
response = client.chat.completions.create(
    model="zai-org/GLM-4.5V",
    messages=[{"role": "user", "content": "Describe this image briefly."}],
    max_tokens=1024,
    extra_body={
        "custom_logit_processor": Glm4MoeThinkingBudgetLogitProcessor().to_str(),
        "custom_params": {"thinking_budget": 512},
    },
)
print(response)
```
