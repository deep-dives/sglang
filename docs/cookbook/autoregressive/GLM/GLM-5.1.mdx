<Note>
💡 AI Infra 学习笔记：量化格式与硬件平台强绑定——NVFP4 只有 NVIDIA Blackwell（B300/GB300）能跑，MXFP4 主要面向 AMD gfx950（MI355X），FP8/BF16 则是两家的通用选项。部署时「选量化」几乎是第一决策：它同时决定了可用的张量并行度、KV 缓存策略（如配合 `--kv-cache-dtype fp8_e4m3`）和最终能塞进几块卡，比后续任何 kernel 微调都更影响总体成本。
</Note>

- **H100 和 H200**：推荐用 FP8 部署。
- **B300 和 GB300**：推荐用 NVFP4 部署。使用 `nvidia/GLM-5.1-NVFP4` 配合 `--quantization modelopt_fp4`。B300 上用 `tp=8`，GB300 上用 `tp=4`。B300 和 GB300 必须使用 CUDA 13 镜像变体。
- **AMD GPU**：BF16 和 FP8 检查点以 tp=8 运行在 MI300X/MI325X/MI355X 上。在 MI355X（gfx950）上，MXFP4 检查点 `amd/GLM-5.1-MXFP4` 也支持以 tp=4 配合 `--kv-cache-dtype fp8_e4m3` 运行。所有 AMD 路径都要传 `--dsa-prefill-backend tilelang --dsa-decode-backend tilelang`、`--chunked-prefill-size 131072` 和 `--watchdog-timeout 1200`（为权重加载预留 20 分钟）。FP8 大约只用 BF16 一半的显存（约 89 GB/卡 vs 约 175 GB/卡）。AMD GPU 上支持 EAGLE 投机解码：MI300X/MI325X（gfx942）和 MI355X（gfx950），但它**必须加 `--disable-custom-all-reduce`**——aiter 自定义 all-reduce kernel 在高并发 EAGLE 验证阶段会死锁，不加这个参数服务端会挂住。
- 其它配置技巧（MTP、DSA kernel、上下文并行、HiSparse、NVFP4、Index Cache）请参考 [DeepSeek-V3.2 cookbook 页面](../DeepSeek/DeepSeek-V3_2)。GLM-5.1 与 DeepSeek-V3.2 共享相同的模型结构，优化技巧通用。
- 用 `--json-model-override-args '{"index_topk_pattern": "FFSFSSSFSSFFFSSSFFFSFSSSSSSFFSFFSFFSSFFFFFFSFFFFFSFFSSSSSSFSFFFSFSSSFSFFSFFSSS"}'` 为 GLM-5.1 启用 [IndexCache](https://github.com/THUDM/IndexCache) 方法。这能在只损失很小精度的情况下提升服务效率。如果你在做严格的精度评估，不要启用该特性。

## 4. 模型调用

用下面的命令部署 GLM-5.1（H200 上的 FP8，启用全部特性）：

```shell Command
sglang serve \
  --model-path zai-org/GLM-5.1-FP8 \
  --tp 8 \
  --tool-call-parser glm47 \
  --reasoning-parser glm45 \
  --speculative-algorithm EAGLE \
  --speculative-num-steps 3 \
  --speculative-eagle-topk 1 \
  --speculative-num-draft-tokens 4 \
  --mem-fraction-static 0.85 \
  --host 0.0.0.0 \
  --port 30000
```

### 4.4 高级用法

#### 4.4.1 推理解析器

GLM-5.1 **默认**支持思考模式。部署时启用推理解析器，即可把思考过程与正文内容分开。思考过程会通过流式响应中的 `reasoning_content` 返回。

如需关闭思考、使用 Instruct 模式，请在请求时传入 `chat_template_kwargs`：

- **思考模式**（默认）：模型在回答前会逐步推理。无需额外参数。
- **Instruct 模式**（`{"enable_thinking": false}`）：模型直接响应，不做思考。

**示例 1：思考模式（默认）**

思考模式默认开启。模型回答前会逐步推理，思考过程通过 `reasoning_content` 返回：

```python Example
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:30000/v1",
    api_key="EMPTY"
)

# Thinking mode is enabled by default, no extra parameters needed
response = client.chat.completions.create(
    model="zai-org/GLM-5.1-FP8",
    messages=[
        {"role": "user", "content": "Solve this problem step by step: What is 15% of 240?"}
    ],
    max_tokens=2048,
    stream=True
)

# Process the stream
has_thinking = False
has_answer = False
thinking_started = False

for chunk in response:
    if chunk.choices and len(chunk.choices) > 0:
        delta = chunk.choices[0].delta

        # Print thinking process
        if hasattr(delta, 'reasoning_content') and delta.reasoning_content:
            if not thinking_started:
                print("=============== Thinking =================", flush=True)
                thinking_started = True
            has_thinking = True
            print(delta.reasoning_content, end="", flush=True)

        # Print answer content
        if delta.content:
            # Close thinking section and add content header
            if has_thinking and not has_answer:
                print("\n=============== Content =================", flush=True)
                has_answer = True
            print(delta.content, end="", flush=True)

print()
```

```python Example
from openai import OpenAI

client = OpenAI(

for chunk in response:
    if chunk.choices and len(chunk.choices) > 0:

        if delta.content:
            print(delta.content, end="", flush=True)

print()
```

#### 4.4.2 工具调用

GLM-5.1 支持工具调用。部署时启用工具调用解析器。思考模式默认开启；要针对工具调用请求关闭它，请传入 `extra_body={"chat_template_kwargs": {"enable_thinking": False}}`。

**Python 示例（带思考过程）：**

```python Example
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:30000/v1",
    api_key="EMPTY"
)

# Define available tools
tools = [
    {
        "type": "function",
        "function": {
            "name": "get_weather",
            "description": "Get the current weather for a location",
            "parameters": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city name"
                    },
                    "unit": {
                        "type": "string",
                        "enum": ["celsius", "fahrenheit"],
                        "description": "Temperature unit"
                    }
                },
                "required": ["location"]
            }
        }
    }
]

# Make request with streaming to see thinking process
response = client.chat.completions.create(
    model="zai-org/GLM-5.1-FP8",
    messages=[
        {"role": "user", "content": "What's the weather in Beijing?"}
    ],
    tools=tools,
    stream=True
)

# Process streaming response
thinking_started = False
has_thinking = False

for chunk in response:
    if chunk.choices and len(chunk.choices) > 0:
        delta = chunk.choices[0].delta

        # Print thinking process
        if hasattr(delta, 'reasoning_content') and delta.reasoning_content:
            if not thinking_started:
                print("=============== Thinking =================", flush=True)
                thinking_started = True
            has_thinking = True
            print(delta.reasoning_content, end="", flush=True)

        # Print tool calls
        if hasattr(delta, 'tool_calls') and delta.tool_calls:
            # Close thinking section if needed
            if has_thinking and thinking_started:
                print("\n=============== Content =================", flush=True)
                thinking_started = False

            for tool_call in delta.tool_calls:
                if tool_call.function:
                    print(f"Tool Call: {tool_call.function.name}")
                    print(f"   Arguments: {tool_call.function.arguments}")

        # Print content
        if delta.content:
            print(delta.content, end="", flush=True)

print()
```

```text Output
   Arguments:
Tool Call: None
   Arguments: {
Tool Call: None
   Arguments: "location": "Be
Tool Call: None
```
