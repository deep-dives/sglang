## 1. 模型介绍

GLM-4.6V 系列包含两个版本：GLM-4.6V（106B）是面向云端和高性能集群场景的基座模型；GLM-4.6V-Flash（9B）则是为本地部署和低延迟应用优化的轻量模型。GLM-4.6V 在训练阶段把上下文窗口扩展到 128K token，在相似参数规模的模型中取得了视觉理解的 SOTA 性能。更重要的是，GLM 团队首次集成了原生函数调用（Function Calling）能力，有效弥合了「视觉感知」与「可执行动作」之间的鸿沟，为真实业务场景中的多模态 Agent 提供了统一的技术基础。

除了在可比规模的模型上于各大多模态基准测试中取得 SOTA 性能外，GLM-4.6V 还引入了以下关键特性：

- **原生多模态函数调用**：支持原生的视觉驱动工具使用。图像、截图和文档页面可以直接作为工具输入，无需先转成文本；图表、搜索图片、渲染页面等视觉输出也能被解读并融入推理链。这打通了从感知、理解到执行的完整闭环。请参考此[示例](#4-2-3-tool-calling)。
- **图文交错内容生成**：能从复杂的多模态输入生成高质量混合内容。GLM-4.6V 会基于横跨文档、用户输入和工具检索图片的多模态上下文，综合生成与任务相符的连贯图文交错内容。生成过程中它还能主动调用搜索和检索工具来收集整理更多文本与图像，产出内容丰富、有视觉依据的内容。
- **多模态文档理解**：GLM-4.6V 最多可处理 128K token 的多文档或长文档输入，能把排版丰富的页面直接当图像解读。它联合理解文本、布局、图表、表格和插图，即使是不事先转换为纯文本的复杂、多图文档也能准确理解。
- **前端复刻与视觉编辑**：能从 UI 截图重建像素级精确的 HTML/CSS，并支持自然语言驱动的修改。它通过视觉方式识别布局、组件和样式，生成整洁的代码，还能根据简单的用户指令进行迭代式的视觉修改。

<Note>
💡 AI Infra 学习笔记：原生多模态函数调用意味着「看懂图 → 决定调用哪个工具 → 执行动作」整条链路都能在一个模型内完成，这是多模态 Agent 的关键能力。对推理引擎而言，这类负载往往同时包含图像输入（视觉 token 的 prefill）和工具调用（多轮短请求），对多模态特征的处理管线与调度器都提出了额外要求。
</Note>

## 2. SGLang 安装

SGLang 提供多种安装方式。你可以根据自己的硬件平台和需求选择最合适的方式。

### 2.1 Docker 安装（推荐）

```shell Command
docker pull lmsysorg/sglang:latest
```

**优势：**

- 开箱即用，无需手动配置环境
- 避免依赖冲突问题
- 在不同环境之间迁移方便

### 2.2 从源码构建

如果你需要使用最新的开发版本，或需要自定义修改，可以从源码构建：

```bash Command
# Install SGLang using UV (recommended)
git clone https://github.com/sgl-project/sglang.git
cd sglang
uv venv
source .venv/bin/activate
uv pip install -e "python[all]" --index-url=https://pypi.org/simple
pip install nvidia-cudnn-cu12==9.16.0.29
# Install ffmpeg to support video input
sudo apt update
sudo apt install ffmpeg
```

**适用场景：**

- 需要定制和修改 SGLang 源码
- 想使用最新的开发特性
- 参与 SGLang 项目开发

一般安装说明还可以参考[官方 SGLang 安装指南](../../../docs/get-started/install)。

### 3.2 配置技巧
- **TTFT 优化**：设置 `SGLANG_USE_CUDA_IPC_TRANSPORT=1`，用 CUDA IPC 传输多模态特征，可显著改善 TTFT。这会额外消耗显存，可能需要调整 `--mem-fraction-static` 和/或 `--max-running-requests`。（额外显存与「图像大小 × 当前运行请求中的图像数量」成正比。）
- **TP=8 配置**：使用张量并行（TP）度为 8 时，视觉注意力的 12 个头无法被整除。可以通过添加 `--mm-enable-dp-encoder` 解决（上面的生成器会自动处理）。
- **快速加载模型**：对大型模型（如 106B 版本），可以用 `--model-loader-extra-config='{"enable_multithread_load": "true","num_threads": 64}'` 加快模型加载。
- **硬件注意事项：**
  - **H100（FP8）**：使用 FP8 检查点可获得最佳显存效率。
  - **A100 / H100（BF16）**：使用标准多模态参数，在吞吐量与显存占用之间取得平衡。
  - **H200 / B200**：开箱即用，支持完整上下文长度以及图像 + 视频并发处理。
- **其它多模态参数：**
  - `--mm-attention-backend fa3`：指定多模态注意力后端（Flash Attention 3）。
  - `--keep-mm-feature-on-device`：处理完成后把多模态特征张量保留在 GPU 上，避免 D2H 内存拷贝。
  - `SGLANG_USE_CUDA_IPC_TRANSPORT=1`：用 CUDA IPC 共享内存传输多模态数据，可显著改善端到端延迟。

**完整多模态优化示例：**
```bash Command
SGLANG_USE_CUDA_IPC_TRANSPORT=1 \
SGLANG_VLM_CACHE_SIZE_MB=0 \
python -m sglang.launch_server \
  --model-path zai-org/GLM-4.6V \
  --host 0.0.0.0 \
  --port 30000 \
  --trust-remote-code \
  --tp-size 8 \
  --enable-cache-report \
  --log-level info \
  --max-running-requests 64 \
  --mem-fraction-static 0.65 \
  --chunked-prefill-size 8192 \
  --attention-backend fa3 \
  --mm-attention-backend fa3 \
  --mm-enable-dp-encoder \
  --enable-metrics
```

#### 4.2.2 思考模式

GLM-4.6V 支持思考模式。部署时启用推理解析器：

```shell Command
python -m sglang.launch_server \
  --model zai-org/GLM-4.6V \
  --reasoning-parser glm45 \
  --tp 8 \
  --host 0.0.0.0 \
  --port 30000
```

**带思考过程的流式输出：**

```python Example
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:30000/v1",
    api_key="EMPTY"
)

# Enable streaming to see the thinking process in real-time
response = client.chat.completions.create(
    model="zai-org/GLM-4.6V",
    messages=[
        {"role": "user", "content": "Solve this problem step by step: What is 15% of 240?"}
    ],
    temperature=0.7,
    max_tokens=2048,
    stream=True
)

# Process the stream
has_thinking = False
has_answer = False
thinking_started = False

for chunk in response:
    if chunk.choices and len(chunk.choices) > 0:
        delta = chunk.choices[0].delta

        # Print thinking process
        if hasattr(delta, 'reasoning_content') and delta.reasoning_content:
            if not thinking_started:
                print("=============== Thinking =================", flush=True)
                thinking_started = True
            has_thinking = True
            print(delta.reasoning_content, end="", flush=True)

        # Print answer content
        if delta.content:
            # Close thinking section and add content header
            if has_thinking and not has_answer:
                print("\n=============== Content =================", flush=True)
                has_answer = True
            print(delta.content, end="", flush=True)

print()
```

**输出示例：**

```text Output
=============== Thinking =================
To solve this problem, I need to calculate 15% of 240.
Step 1: Convert 15% to decimal: 15% = 0.15
Step 2: Multiply 240 by 0.15
Step 3: 240 × 0.15 = 36
=============== Content =================

The answer is 36. To find 15% of 240, we multiply 240 by 0.15, which equals 36.
```

**注意：** 推理解析器会捕获模型逐步的思考过程，让你看到模型是如何得出结论的。

#### 4.2.3 工具调用 {#4-2-3-tool-calling}

GLM-4.6V 支持带视觉能力的工具调用。在 API 请求中传入 tools：

```python Example
from openai import OpenAI

openai_api_key = "EMPTY"
openai_api_base = "http://127.0.0.1:30000/v1"
client = OpenAI(api_key=openai_api_key, base_url=openai_api_base)



tools = [
    {
        "type": "function",
        "function": {
            "name": "get_weather",
            "description": "Get current temperature for a given location.",
            "parameters": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "City and country e.g. Beijing, China",
                    }
                },
                "required": ["location"],
                "additionalProperties": False,
            },
        },
    }
]


messages = [
    {
        "role": "user",
        "content": "Please help me check today's weather in Beijing, and tell me whether the tool returned an image."
    },
    {
        "role": "assistant",
        "tool_calls": [
            {
                "id": "call_bk32t88BGpSdbtDgzT044Rh4",
                "type": "function",
                "function": {
                    "name": 'get_weather',
                    "arguments": '{"location":"Beijing, China"}'
                }
            }
        ]
    },
    {
        "role": "tool",
        "tool_call_id": "call_bk32t88BGpSdbtDgzT044Rh4",
        "content": [
            {
                "type": "text",
                "text": "Weather report generated: Beijing, November 7, 2025, sunny, temperature 2°C."
            },
            {
                "type": "image_url",
                "image_url": {
                     "url": "https://github.com/sgl-project/sglang/blob/main/examples/assets/example_image.png?raw=true"
                }
            }
        ]
    },
]

response = client.chat.completions.create(
    model="zai-org/GLM-4.6V",
    messages=messages,
    timeout=900,
    tools=tools
)
print(response.choices[0].message.content.strip())
```

**输出示例：**

```text Output
The weather in Beijing today (November 7, 2025) is sunny with a temperature of 2°C.

Yes, the tool returned an image (the SGL logo).
```

#### 4.2.4 思考预算

除了推理解析器，你还可以用 `CustomLogitProcessor` 限制思考 token 的数量。启动时加上 `--enable-custom-logit-processor`，并在请求中传入 `Glm4MoeThinkingBudgetLogitProcessor`——与 [GLM-4.6 文本模型的做法](./GLM-4.6#4-2-3-thinking-budget) 相同：

```python Example
import openai
from sglang.srt.sampling.custom_logit_processor import Glm4MoeThinkingBudgetLogitProcessor

client = openai.Client(base_url="http://127.0.0.1:30000/v1", api_key="*")
response = client.chat.completions.create(
    model="zai-org/GLM-4.6V",
    messages=[{"role": "user", "content": "Describe this image briefly."}],
    max_tokens=1024,
    extra_body={
        "custom_logit_processor": Glm4MoeThinkingBudgetLogitProcessor().to_str(),
        "custom_params": {"thinking_budget": 512},
    },
)
print(response)
```
