本指南介绍 SGLang 模型配置中使用的并行配置字段，以及它们如何对应到 SGLang 服务端的命令行参数。

<Note>
💡 AI Infra 学习笔记：张量并行（TP）把单层权重切分到多张 GPU 上共同计算；数据并行（DP）复制整份模型，不同副本处理不同请求；专家并行（EP）用于 MoE 模型，把各专家分布到不同 GPU。理解这三种并行的组合方式（例如 enable_dp_attention 让 Attention 走 DP、FFN 走 TP）是配置多卡推理服务的核心。
</Note>
