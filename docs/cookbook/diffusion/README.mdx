# SGLang 扩散模型食谱库

<div style={{display: 'flex', gap: '8px'}}>

为 SGLang 打造一份全面的扩散模型食谱库，展示 SGLang 在图像与视频生成负载上的性能优势。

## 🎯 你能在这里找到什么

这份食谱库汇集了经过实战检验的 SGLang 食谱，涵盖：

- **模型**：主流的图像与视频生成模型
- **用例**：推理服务化、部署策略
- **硬件**：GPU 与 CPU 配置、面向不同加速器的优化
- **最佳实践**：配置模板、性能调优、故障排查指南

每份食谱都提供分步说明，帮助你针对自己的具体需求快速落地 SGLang 方案。

<Note>
💡 AI Infra 学习笔记：食谱库目录按模型系列组织（每个厂商/系列一个子目录），同一系列下的不同版本（如 Wan2.1/Wan2.2）各自成页。各食谱的正文结构通常一致——先讲部署参数，再讲调用方式、性能调优和故障排查，方便横向对比。
</Note>

## 🚀 快速开始

1. 在上面的食谱索引中找到你的模型
2. 按每份指南的分步说明操作
3. 根据你的具体硬件和需求调整配置
4. 加入社区，分享反馈和改进建议

sglang 扩散模型食谱库的目录结构如下：

```text Example
docs/cookbook/diffusion/
├── README.mdx             # Main cookbook (this file)
├── Qwen-Image/            # Qwen-Image series docs
│   ├── Qwen-Image.mdx
│   └── Qwen-Image-Edit.mdx
├── Wan/                   # Wan series docs
│   ├── Wan2.1.mdx
│   └── Wan2.2.mdx
├── Z-Image/               # Z-Image series docs
│   └── Z-Image-Turbo.mdx
├── Ernie-Image/           # ERNIE-Image series docs
│   └── Ernie-Image.mdx
└── ...
```

## 🤝 参与贡献

我们相信最好的文档来自实践者。无论你是针对某个模型优化过 SGLang、解决过棘手的部署难题，还是发现了性能改进点，都欢迎贡献你的食谱！

**💪 如何贡献**

- 感兴趣就在下方留言（说明你负责哪个部分）
- 参与实现细节的讨论
- fork 仓库并处理分配给你的部分
- 按照 SGLang 食谱库的标准提交 PR
- 根据评审反馈迭代

**贡献步骤：**

```shell Command
# Fork the repo and clone locally
git clone https://github.com/YOUR_USERNAME/sglang.git
cd sglang

# Create a new branch
git checkout -b add-my-recipe

# Add your recipe under docs/cookbook/diffusion/
# Submit a PR!
```
